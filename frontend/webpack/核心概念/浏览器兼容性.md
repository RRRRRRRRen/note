# 浏览器兼容性

*类型：knowledge ｜ 难度：基础 ｜ 标签：webpack、浏览器兼容、ES5、polyfill*

**Webpack 支持所有符合 ES5 标准的浏览器（不支持 IE8 及以下版本）。** webpack 自身产物以 ES5 为基线，但它提供的动态导入能力对运行环境有额外要求：`import()` 和 `require.ensure()` 需要 `Promise`。如果要支持旧版本浏览器，需要在使用这些表达式之前提前加载 polyfill。

## 支持范围

- 支持所有符合 ES5 标准的浏览器。
- 不支持 IE8 及以下版本。

## 动态导入的额外要求

webpack 的 `import()` 与 `require.ensure()` 依赖 `Promise` 实现：

- 目标浏览器原生支持 Promise（ES2015+）时可直接使用。
- 需要兼容不支持 Promise 的旧浏览器时，必须在使用这些表达式之前提前加载 polyfill（如 core-js 提供的 Promise 补丁）。

```js
// 入口最早的位置引入 polyfill，保证后续 import()/require.ensure() 可用
import 'core-js/features/promise';
```
