# 入口起点

*类型：knowledge ｜ 难度：基础 ｜ 标签：webpack、entry、多页应用*

**入口起点（entry point）指示 webpack 使用哪个模块，来作为构建其内部依赖图（dependency graph）的开始：进入入口起点后，webpack 会找出有哪些模块和库是入口起点直接和间接依赖的。** `entry` 支持单入口字符串、字符串数组（multi-main entry）与对象语法；对象语法可为每个 chunk 命名，并通过 `dependOn`、`runtime` 等字段描述入口间关系。多入口的两大典型诉求是「分离 vendor 以长期缓存」与「多页面各自独立加载」，配合 `output.filename` 占位符即可各走各的产物。

## 单个入口语法

用法：`entry: string | [string]`。

```js
// 单字符串写法，webpack 自动把 chunk 命名为 main
module.exports = {
  entry: './path/to/my/entry/file.js',
};
// 等同于显式命名 main
module.exports = {
  entry: {
    main: './path/to/my/entry/file.js',
  },
};
```

也可以把文件路径数组传给 `entry`，创建所谓的 **multi-main entry**：想在一次注入中合并多个依赖文件、并把它们的依赖关系绘制在同一个 chunk 中时很有用。

```js
module.exports = {
  entry: ['./src/file_1.js', './src/file_2.js'],
  output: {
    filename: 'bundle.js',
  },
};
```

一般情况下项目只有一个入口文件即可，Vue2 项目中入口通常为 `src/main.js`。

## 对象语法

用法：`entry: { <entryChunkName> string | [string] }`，为每个入口 chunk 指定名称：

```js
module.exports = {
  entry: {
    app: './src/app.js',
    adminApp: './src/adminApp.js',
  },
};
```

入口对象的描述字段：

| 字段 | 作用 |
| --- | --- |
| `dependOn` | 当前入口所依赖的入口，必须在该入口被加载前加载；不能循环引用 |
| `filename` | 指定该入口的输出文件名 |
| `import` | 启动时需加载的模块 |
| `library` | 为当前 entry 构建 library 的选项 |
| `runtime` | 运行时 chunk 名；webpack 5.43.0+ 可设 `false` 避免新运行时 chunk；与 `dependOn` 不应同入口混用，且不能指向已存在的入口名称 |
| `publicPath` | 该入口输出文件在浏览器中被引用时的公共 URL 地址 |

## 常见场景

### 分离 app 与 vendor 入口

```js
module.exports = {
  entry: {
    main: './src/app.js',
    vendor: './src/vendor.js',
  },
  output: {
    // 生产环境：内容哈希参与文件名，vendor 内容不变则 hash 不变
    filename: '[name].[contenthash].bundle.js',
  },
};
```

把未做修改的必要 library 或文件（例如 Bootstrap、jQuery、图片等）存入 `vendor.js`，打包为单独 chunk：内容哈希保持不变，浏览器可以独立缓存它们，从而减少加载时间。

### 多页面应用程序

```js
module.exports = {
  entry: {
    pageOne: './src/pageOne/index.js',
    pageTwo: './src/pageTwo/index.js',
    pageThree: './src/pageThree/index.js',
  },
};
```

多页应用中 server 每次拉取一个新的 HTML 文档，页面重新加载并重新下载资源。这给了我们特殊的机会：使用 `optimization.splitChunks` 为页面间共享的应用代码创建 bundle——入口起点越多，多页应用能复用的公共代码/模块越多，从这些技术中获得的收益越大。
