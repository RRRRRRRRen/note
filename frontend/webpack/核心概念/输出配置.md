# 输出配置

*类型：knowledge ｜ 难度：基础 ｜ 标签：webpack、output、filename、占位符*

**配置 `output` 选项可以控制 webpack 如何向硬盘写入编译文件；即使可以存在多个 `entry` 起点，也只能指定一个 `output` 配置。** 最低要求是设置一个输出文件名（`filename`）；一旦配置创建了多个 chunk（例如多个入口起点），就必须使用占位符（如 `[name]`、`[hash]`）保证每个文件名唯一。`output` 的其余选项大致分五类：命名类、hash 类、library 类、热更新类、source map 类。

## 基本用法

单个入口，输出为静态文件名：

```js
module.exports = {
  output: {
    filename: 'bundle.js',
  },
};
// 将一个单独的 bundle.js 文件输出到 dist 目录
```

多个 chunk 时用占位符区分文件名：

```js
module.exports = {
  entry: {
    app: './src/app.js',
    search: './src/search.js',
  },
  output: {
    filename: '[name].js',
    path: __dirname + '/dist',
  },
};
// 写入到硬盘：./dist/app.js, ./dist/search.js
```

## 打包为 CDN 地址

`path` 与 `publicPath` 合理设置并保持一致，方便产物上传后直接使用：

```js
module.exports = {
  // ...
  output: {
    path: '/home/proj/cdn/assets/[fullhash]',
    publicPath: 'https://cdn.example.com/assets/[fullhash]/',
  },
};
```

生成的 HTML 中资源引用会带上完整 CDN 前缀：

```html
<script
  defer="defer"
  src="https://cdn.example.com/assets/73a430b561791b4a094c/main.js"
></script>
```

## filename 占位符

`output.filename` 决定每个输出 bundle 的名称，bundle 写入 `output.path` 指定的目录。多个入口起点、代码拆分或插件都会创建多个 bundle，此时用占位符命名：

```js
module.exports = {
  // ...
  output: {
    filename: '[name].bundle.js',           // 使用入口名称
    // filename: '[id].bundle.js',          // 使用内部 chunk id
    // filename: '[name].[hash].bundle.js', // 模块标识符的 hash 值
    // filename: '[chunkhash].bundle.js',   // 生成 chunk 的 hash 值
    // filename: '[contenthash].bundle.js', // 文件内容的 hash 值
  },
};
```

也支持函数自定义命名：

```js
module.exports = {
  output: {
    // main 入口平铺输出，其余入口按子目录输出
    filename: (chunkData) => {
      return chunkData.chunk.name === 'main' ? '[name].js' : '[name]/[name].js';
    },
  },
};
```

## 常用配置项速查

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| `output.chunkFilename` | 非入口（non-entry）chunk 文件的名称 | — |
| `output.chunkLoadTimeout` | chunk 请求到期之前的毫秒数 | 120000 |
| `output.crossOriginLoading` | target 为 web 且用 JSONP 按需加载 chunk 时的 crossorigin 属性：`false` 禁用（默认）/ `anonymous` 不带凭据 / `use-credentials` 带凭据 | false |
| `output.jsonpScriptType` | 注入 DOM 下载异步 chunk 的 script 类型：`text/javascript` / `module`（与 ES6 就绪代码一起使用） | text/javascript |
| `output.hashFunction` | 生成 hash 使用的算法 | md4 |
| `output.hashDigest` | 生成 hash 时使用的编码方式 | hex |
| `output.hashDigestLength` | 生成的 hash 长度 | 20 |
| `output.hashSalt` | 可选的加盐值 | — |
| `output.jsonpFunction` | target 为 web 时按需加载 chunk 的 JSONP 函数 | — |
| `output.globalObject` | 跨环境运行时的全局对象指向（如 umd 产物中 `this`/`self` 的选择） | — |

## 热更新与 source map 相关

```js
module.exports = {
  output: {
    // 热更新 chunk 的文件名，占位符只能是 [id] 和 [hash]
    hotUpdateChunkFilename: '[id].[hash].hot-update.js',
    // 热更新主文件名
    hotUpdateMainFilename: '[hash].hot-update.json',
  },
};
```

- `output.hotUpdateFunction`：target 为 web 时，用于加载热更新（hot update）的 JSONP 函数。
- `output.devtoolModuleFilenameTemplate`：仅在 devtool 使用了需要模块名称的选项时生效，自定义每个 source map 的 `sources` 数组中使用的名称，可传模板字符串或函数。
- `output.devtoolFallbackModuleFilenameTemplate`：当上面的模板字符串或函数产生重复时使用的备用内容。
- `output.devtoolNamespace`：`devtoolModuleFilenameTemplate` 使用的模块名称空间，未指定时默认为 `output.library`；加载多个 webpack 构建的 library 时防止 source map 中源文件路径冲突——例如两个 library 各自有 `./src/index.js`，会分别暴露为 `webpack://library1/./src/index.js` 与 `webpack://library2/./src/index.js`。
- `output.devtoolLineToLine`（即将弃用）：对所有或某些模块启用「行到行映射」——生成资源的每一行映射到原始资源的同一行，属于性能优化，只在输入行与生成行匹配时使用，默认 `false`。

```js
module.exports = {
  output: {
    // 对 src/utilities 目录下所有 js 文件启用行到行映射
    devtoolLineToLine: { test: /\.js$/, include: 'src/utilities' },
  },
};
```

## library 相关输出

- `output.library`：暴露从入口导出的内容，其行为取决于 `output.libraryTarget` 选项的值。
- `output.auxiliaryComment`：与 `library` / `libraryTarget` 一起使用时，向导出容器（export wrapper）中插入注释；传字符串为每种类型插入相同注释，传对象可按 `root`、`commonjs`、`commonjs2`、`amd` 分别控制。

```js
module.exports = {
  output: {
    library: 'someLibName',
    libraryTarget: 'umd',
    filename: 'someLibName.js',
    auxiliaryComment: 'Test Comment',
  },
};
```

产物中每个模块规范分支前都会插入该注释：

```js
(function webpackUniversalModuleDefinition(root, factory) {
  // Test Comment
  if (typeof exports === 'object' && typeof module === 'object')
    module.exports = factory(require('lodash'));
  // Test Comment
  else if (typeof define === 'function' && define.amd)
    define(['lodash'], factory);
  // Test Comment
  else if (typeof exports === 'object')
    exports['someLibName'] = factory(require('lodash'));
  // Test Comment
  else root['someLibName'] = factory(root['_']);
})(this, function (__WEBPACK_EXTERNAL_MODULE_1__) {
  // ...
});
```
