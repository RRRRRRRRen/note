# 内容安全策略

*类型：knowledge ｜ 难度：进阶 ｜ 标签：webpack、CSP、安全、devServer*

**CSP（Content Security Policy）是一种浏览器安全机制，用于限制文档中可以加载和执行的资源：浏览器将加载的资源与白名单比对，只允许符合白名单要求的资源被加载和执行，从而有效减少 XSS（跨站脚本攻击）等攻击。** CSP 通过 HTTP 头或 `<meta>` 标签实现；webpack/devServer 侧的 `contentSecurityPolicy` 配置只负责生成策略内容，真正生效仍以 HTTP 头或 meta 标签为准。

## 白名单可以指定什么

- 指定允许加载的资源类型：只允许加载脚本、样式表、图片等特定类型的资源。
- 指定允许加载的域名：只允许从特定域名加载资源，或允许从特定域名加载特定类型的资源。
- 禁止 `eval()` 和 inline 脚本：禁止在文档中执行内联脚本和通过 `eval()` 执行的脚本。

## 工作方式

浏览器加载文档时，会检查文档中每个资源的来源是否在 CSP 白名单中：资源来源不在白名单中，浏览器将拒绝加载该资源，从而有效减少恶意代码的注入和执行。

## 在 webpack 中配置

在 Webpack 中可以通过 `contentSecurityPolicy` 配置项设置 CSP 策略，它接受一个字符串或对象，用于指定策略的具体内容。例如启用 CSP 策略，允许加载所有类型的资源、但只允许从当前域名加载：

```js
module.exports = {
  // ...
  devServer: {
    contentSecurityPolicy: {
      directives: {
        // default-src 'self'：默认只允许同源资源
        defaultSrc: ["'self'"],
      },
    },
  },
};
```

注意：为了使 CSP 生效，必须在 HTTP 头或 `<meta>` 标签中设置 CSP 策略，Webpack 的 `contentSecurityPolicy` 配置项只是用于生成 CSP 策略内容。
