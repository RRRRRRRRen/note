# 代码分离

*类型：practice ｜ 难度：进阶 ｜ 标签：webpack、代码分离、splitChunks、动态导入、prefetch*

**代码分离能把代码拆到不同 bundle 中，按需加载或并行加载，用于获取更小的 bundle、控制资源加载优先级——使用合理会极大影响加载时间。** 常用方法三种：入口起点手动分离、Entry dependencies / SplitChunksPlugin 防止重复、动态导入内联拆分；再配合 `webpackPrefetch` / `webpackPreload` 资源提示控制加载时机。

## 入口起点

设置多个入口自动分离代码为多个块：

```js
const path = require('path');

module.exports = {
  mode: 'development',
  entry: {
    index: './src/index.js',
    another: './src/another-module.js',
  },
  output: {
    filename: '[name].bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
};
```

问题：两个入口如果引用了同一个库（如 lodash），它会被重复打包进两个 bundle。

## 防止重复：dependOn

配置 `dependOn` 选项，在多个 chunk 之间共享模块。注意：在一个 HTML 页面上使用多个入口时，还需设置 `optimization.runtimeChunk: 'single'`，否则会遇到变量穿透等问题：

```js
const path = require('path');

module.exports = {
  mode: 'development',
  entry: {
    index: {
      import: './src/index.js',
      dependOn: 'shared', // 加载 index 前先加载 shared
    },
    another: {
      import: './src/another-module.js',
      dependOn: 'shared',
    },
    // lodash 单独成为共享 chunk
    shared: 'lodash',
  },
  output: {
    filename: '[name].bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
  optimization: {
    runtimeChunk: 'single',
  },
};
```

## 防止重复：SplitChunksPlugin

`SplitChunksPlugin` 可以将公共的依赖模块提取到已有的入口 chunk 中，或者提取到一个新生成的 chunk。开启 `chunks: "all"` 后不需要 `dependOn` 配置，直接提取公共模块：

```js
const path = require('path');

module.exports = {
  mode: 'development',
  entry: {
    index: './src/index.js',
    another: './src/another-module.js',
  },
  output: {
    filename: '[name].bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
  optimization: {
    splitChunks: {
      // all：同步、异步模块都参与公共模块提取
      chunks: 'all',
    },
  },
};
```

## 动态导入（dynamic import）

动态代码拆分的推荐方式是使用符合 ECMAScript 提案的 `import()` 语法：

```js
async function getComponent() {
  const element = document.createElement('div');
  // import() 返回 Promise，lodash 会被拆成单独的 chunk 按需加载
  const { default: _ } = await import('lodash');

  element.innerHTML = _.join(['Hello', 'webpack'], ' ');

  return element;
}

getComponent().then((component) => {
  document.body.appendChild(component);
});
```

使用 `import()` 会自动拆分代码形成单独的模块。

## 预获取/预加载模块（prefetch/preload）

在声明 import 时使用内置指令，可以让 webpack 输出「resource hint（资源提示）」告知浏览器：

- **prefetch**（预获取）：将来某些导航下可能需要的资源，浏览器空闲时拉取。
- **preload**（预加载）：当前导航下可能需要的资源，与主资源并行加载。

```js
async function getComponent() {
  const element = document.createElement('div');
  const { default: _ } = await import('lodash');

  element.innerHTML = _.join(['Hello', 'webpack'], ' ');

  element.onclick = () => {
    // webpackPrefetch: true 会生成一个 link 标签用于预获取该模块
    import(/* webpackPrefetch: true */ './print').then((module) => {
      const print = module.default;
      print();
    });
  };
  return element;
}

getComponent().then((component) => {
  document.body.appendChild(component);
});
```

使用 prefetch 后会生成一个 link 用于预获取模块。
