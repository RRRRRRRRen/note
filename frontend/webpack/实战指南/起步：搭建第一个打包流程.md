# 起步：搭建第一个打包流程

*类型：practice ｜ 难度：基础 ｜ 标签：webpack、安装、配置文件、npm scripts*

**搭建 webpack 最小工作流只需三步：初始化 npm 项目并安装 `webpack` + `webpack-cli`、创建默认会被读取的 `webpack.config.js`（声明 entry 与 output）、在 package.json 中注册 `build` 脚本后 `npm run build` 执行打包。** 顺手做两件防事故配置：声明 `"private": true` 防止意外发布、移除 `"main"` 入口。

## 基本安装

先创建一个目录，初始化 npm，并把 webpack 安装为开发依赖：

```bash
# 新建目录
mkdir webpack-demo
# 进入目录
cd webpack-demo
# 使用默认参数初始化 npm 项目
npm init -y
# 安装 webpack webpack-cli 作为开发依赖
npm install webpack webpack-cli --save-dev
```

## 配置文件

webpack 会默认读取根目录下的 `webpack.config.js` 文件作为配置项：

```js
// webpack.config.js
// 引入 path 函数做路径转化
const path = require('path');

// 导出一个配置对象
module.exports = {
  // 入口文件路径
  entry: './src/index.js',
  // 输出选项
  output: {
    // 输出文件名称
    filename: 'main.js',
    // 输出目录地址（resolve 成绝对路径）
    path: path.resolve(__dirname, 'dist'),
  },
};
```

## npm 脚本

使用 npm 脚本快速启动构建命令：

```diff
 {
   "name": "webpack-demo",
   "version": "1.0.0",
   "description": "",
-  "main": "index.js",
+  "private": true,
   "scripts": {
+   "build": "webpack"
   },
   // ...
 }
```

- 声明 npm 项目为私有项目：`"private": true`。
- 移除 npm 包 main 入口，防止意外发布：删掉 `"main": "index.js"`。
- 使用 `npm run build` 执行打包命令，产物输出到 `dist/main.js`。
