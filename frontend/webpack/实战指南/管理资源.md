# 管理资源

*类型：practice ｜ 难度：基础 ｜ 标签：webpack、loader、asset modules、静态资源*

**webpack 天生只理解 JavaScript 和 JSON，管理其余资源（CSS、图片、字体、CSV、XML、TOML 等）靠两条路径：给 `module.rules` 配 loader 做转换，或使用 webpack 5 内置的 asset modules（`type: 'asset/resource'` 等）原样输出。** 下面的配置是一份「全资源类型」参考：css 用 `style-loader` + `css-loader`、图片字体用内置 resource、csv/xml 用社区 loader 转 JSON、toml/yaml/json5 借 `type: 'json'` 的自定义 parser 解析。

## 完整配置

```js
const path = require('path');
// 用于将 toml、yaml、json5 转化为 json 格式引入
// npm 包：toml、yaml、json5
const toml = require('toml');
const yaml = require('yamljs');
const json5 = require('json5');

module.exports = {
  mode: 'production',
  entry: {
    main: path.resolve(__dirname, './src/main.js'),
  },
  output: {
    filename: 'bundle.js',
    path: path.resolve(__dirname, 'dist'),
  },
  module: {
    rules: [
      // npm 包：style-loader、css-loader
      // 用于识别 css 文件，并使用 js 插入到页面
      {
        test: /\.css$/i,
        use: ['style-loader', 'css-loader'],
      },
      // 内置 asset/resource 功能引入静态资源
      // 用于处理图片资源
      {
        test: /\.(png|svg|jpg|jpeg|gif)$/i,
        type: 'asset/resource',
      },
      // 内置 asset/resource 功能引入静态资源
      // 用于处理字体资源
      {
        test: /\.(woff|woff2|eot|ttf|otf)$/i,
        type: 'asset/resource',
      },
      // npm 包：csv-loader
      // 用于将 csv 文件转化为 json 文件
      {
        test: /\.(csv|tsv)$/i,
        use: ['csv-loader'],
      },
      // npm 包：xml-loader
      // 用于将 xml 文件转化为 json 文件
      {
        test: /\.xml$/i,
        use: ['xml-loader'],
      },
      // 使用自定义 parser 来解析文件，将其识别为 json
      {
        test: /\.toml$/i,
        type: 'json',
        parser: {
          parse: toml.parse,
        },
      },
      {
        test: /\.yaml$/i,
        type: 'json',
        parser: {
          parse: yaml.parse,
        },
      },
      {
        test: /\.json5$/i,
        type: 'json',
        parser: {
          parse: json5.parse,
        },
      },
    ],
  },
};
```

## 要点解析

- **loader 顺序**：css 一条规则中 `style-loader` 在前、`css-loader` 在后，实际执行从右到左——先由 `css-loader` 解析 `@import` 与 `url()`，再由 `style-loader` 把结果以 style 标签插入页面。
- **asset modules vs loader**：图片、字体这类「只需拿到 URL」的资源，用 webpack 5 内置的 `type: 'asset/resource'` 即可，不必再装 `file-loader` / `url-loader`。
- **自定义 parser**：`type: 'json'` 表示按 JSON 模块处理，配合 `parser.parse` 可以把任意文本格式（toml/yaml/json5）挂进去，之后 `import data from './data.toml'` 直接得到对象。
