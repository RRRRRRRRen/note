# 环境变量

*类型：practice ｜ 难度：基础 ｜ 标签：webpack、env、CLI、配置函数*

**webpack 命令行 `--env` 参数允许传入任意数量的环境变量，但要在配置中消费它们，必须把 `module.exports` 从配置对象转换为函数——`env` 会作为该函数的第一个参数传入。** `--env production` 这类无值写法默认把 `env.production` 设为 `true`。

## CLI 中使用环境变量

webpack 命令行环境配置的 `--env` 参数，可以传入任意数量的环境变量，例如 `--env production` 或 `--env goal=local`：

```bash
npx webpack --env goal=local --env production --progress
```

- `--env goal=local`：传入键值对，配置中读到 `env.goal === 'local'`。
- `--env production`：只设变量不赋值，默认表示将 `env.production` 设置为 `true`。

## 接受环境变量

通常 `module.exports` 直接指向配置对象；要使用 `env` 变量，必须将其转换成一个函数：

```js
const path = require('path');

// 导出函数而不是对象：webpack 会把 --env 传的变量注入 env 参数
module.exports = (env) => {
  // 在这里使用 env.<YOUR VARIABLE>
  console.log('Goal: ', env.goal); // 'local'
  console.log('Production: ', env.production); // true

  // 根据环境变量返回不同的配置对象
  return {
    entry: './src/index.js',
    output: {
      filename: 'bundle.js',
      path: path.resolve(__dirname, 'dist'),
    },
  };
};
```
