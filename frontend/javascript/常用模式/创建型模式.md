# 创建型模式

*类型：knowledge ｜ 难度：进阶 ｜ 标签：设计模式、创建型、单例、工厂、建造者、原型、构造器*

**结论：创建型模式把「对象怎么创建」从使用方代码中解耦，核心收益是——换实现不动调用方、复杂构建过程被封装、全局唯一有保证。JS 高频的五个：构造器模式（原型上共享方法避免每个实例复制一份）；原型模式（`Object.create` 克隆已有对象）；工厂模式（一个入口按类型产出对象，消除 new 分支判断）；建造者模式（链式分步构建复杂对象，`return this` 支持链式调用）；单例模式（静态属性或闭包保证全应用唯一实例，全局状态管理与弹窗管理器的标准解法）。**

## 构造器模式（Constructor Pattern）

用于创建对象并初始化属性和方法。

```js
// ES5 构造函数
function Person(name, age) {
  this.name = name;
  this.age = age;
  this.sayHello = function() { // 缺点：每个实例都复制一份方法
    console.log(`Hello, I'm ${this.name}`);
  };
}

// ES6 Class：同一逻辑的语法糖
class Person {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }
  sayHello() {
    console.log(`Hello, I'm ${this.name}`);
  }
}
```

改进：方法挂到原型上，所有实例共享一份。

```js
function Person(name, age) {
  this.name = name;
  this.age = age;
}
Person.prototype.sayHello = function() { // 定义在原型上，实例间共享
  console.log(`Hello, I'm ${this.name}`);
};

const person1 = new Person('Alice', 25);
const person2 = new Person('Bob', 30);
console.log(person1.sayHello === person2.sayHello); // true
```

## 原型模式（Prototype Pattern）

通过克隆现有对象创建新对象，而不是实例化类。

```js
// 原型对象：包含默认状态与行为
const carPrototype = {
  wheels: 4,
  engine: 'V6',
  color: 'white',

  start() {
    console.log('The car is starting...');
  },
  stop() {
    console.log('The car is stopping...');
  },
  getInfo() {
    return `Color: ${this.color}, Engine: ${this.engine}, Wheels: ${this.wheels}`;
  }
};

// Object.create 克隆：myCar 的 __proto__ 指向 carPrototype
// 未覆盖的属性沿原型链读取，覆盖的属性成为自有属性
const myCar = Object.create(carPrototype);
myCar.color = 'blue';

const yourCar = Object.create(carPrototype);
yourCar.color = 'red';

console.log(myCar.getInfo());  // "Color: blue, Engine: V6, Wheels: 4"
console.log(yourCar.getInfo()); // "Color: red, Engine: V6, Wheels: 4"
```

配套的深拷贝工具（克隆含嵌套的对象原型时使用）：

```js
function deepClone(obj, hash = new WeakMap()) {
  if (obj === null || typeof obj !== 'object') return obj; // 基准条件
  if (hash.has(obj)) return hash.get(obj);                 // 循环引用截断

  const cloneObj = Array.isArray(obj) ? [] : {};
  hash.set(obj, cloneObj); // 先登记再递归

  for (let key in obj) {
    if (obj.hasOwnProperty(key)) {
      cloneObj[key] = deepClone(obj[key], hash);
    }
  }
  return cloneObj;
}
```

## 工厂模式（Factory Pattern）

封装对象的创建过程，使用方只报「要什么」，不关心「怎么造」。

```js
// 产品类
class LineChart { render() { console.log('渲染折线图'); } }
class BarChart { render() { console.log('渲染柱状图'); } }
class PieChart { render() { console.log('渲染饼图'); } }

// 简单工厂：创建逻辑集中到一处
class ChartFactory {
  static createChart(type) {
    switch (type) {
      case 'line': return new LineChart();
      case 'bar':  return new BarChart();
      case 'pie':  return new PieChart();
      default:     throw new Error(`不支持的图表类型: ${type}`);
    }
  }
}

const lineChart = ChartFactory.createChart('line');
lineChart.render(); // '渲染折线图'
```

工厂方法模式：把「实例化哪个类」下放到子类，新增产品不改工厂父类（符合开放封闭原则）。

```js
class ChartFactory {
  createChart() {
    throw new Error('子类必须实现 createChart 方法');
  }
}

class LineChartFactory extends ChartFactory {
  createChart() { return new LineChart(); }
}

class BarChartFactory extends ChartFactory {
  createChart() { return new BarChart(); }
}

const lineFactory = new LineChartFactory();
lineFactory.createChart().render();
```

## 抽象工厂模式（Abstract Factory Pattern）

提供一个接口，创建一系列**相互配套**的对象——保证「一族产品」不会混搭。

```js
// 抽象产品
class Button { render() { throw new Error('子类必须实现 render 方法'); } }
class Input  { render() { throw new Error('子类必须实现 render 方法'); } }

// 具体产品：同一风格成对出现
class WindowsButton extends Button { render() { console.log('渲染 Windows 风格按钮'); } }
class WindowsInput  extends Input  { render() { console.log('渲染 Windows 风格输入框'); } }
class MacButton     extends Button { render() { console.log('渲染 Mac 风格按钮'); } }
class MacInput      extends Input  { render() { console.log('渲染 Mac 风格输入框'); } }

// 抽象工厂：规定一族产品的创建接口
class UIFactory {
  createButton() { throw new Error('子类必须实现 createButton 方法'); }
  createInput()  { throw new Error('子类必须实现 createInput 方法'); }
}

// 具体工厂：每个风格一个工厂，产出配套的一族
class WindowsFactory extends UIFactory {
  createButton() { return new WindowsButton(); }
  createInput()  { return new WindowsInput(); }
}
class MacFactory extends UIFactory {
  createButton() { return new MacButton(); }
  createInput()  { return new MacInput(); }
}

// 客户端只依赖抽象工厂，换主题只换工厂
function renderUI(factory) {
  factory.createButton().render();
  factory.createInput().render();
}

renderUI(new WindowsFactory());
// 渲染 Windows 风格按钮
// 渲染 Windows 风格输入框
renderUI(new MacFactory());
// 渲染 Mac 风格按钮
// 渲染 Mac 风格输入框
```

## 建造者模式（Builder Pattern）

把复杂对象的构建拆成多个步骤，逐步设置、最后一次性 build。每个 setter 返回 `this` 即可支持链式调用。

```js
// 产品类
class Computer {
  constructor() {
    this.cpu = '';
    this.memory = '';
    this.storage = '';
    this.gpu = '';
  }
  showSpecs() {
    console.log(`
      CPU: ${this.cpu}
      内存: ${this.memory}
      存储: ${this.storage}
      显卡: ${this.gpu}
    `);
  }
}

// 建造者：每个 set 方法返回 this，支持链式调用
class ComputerBuilder {
  constructor() {
    this.computer = new Computer();
  }
  setCPU(cpu)          { this.computer.cpu = cpu;      return this; }
  setMemory(memory)    { this.computer.memory = memory; return this; }
  setStorage(storage)  { this.computer.storage = storage; return this; }
  setGPU(gpu)          { this.computer.gpu = gpu;      return this; }
  build()              { return this.computer; } // 终点：交付产品
}

const computer = new ComputerBuilder()
  .setCPU('Intel i7')
  .setMemory('16GB')
  .setStorage('512GB SSD')
  .setGPU('NVIDIA RTX 3060')
  .build();

computer.showSpecs();
```

实际应用——HTML 构建器，同一套路构建字符串产物：

```js
class HTMLBuilder {
  constructor() {
    this.html = '';
  }

  addTag(tag, content, attributes = {}) {
    const attrs = Object.entries(attributes)
      .map(([key, value]) => `${key}="${value}"`)
      .join(' ');
    this.html += `<${tag}${attrs ? ' ' + attrs : ''}>${content}</${tag}>`;
    return this;
  }

  addDiv(content, className)  { return this.addTag('div', content, { class: className }); }
  addParagraph(content)       { return this.addTag('p', content); }
  addLink(text, href)         { return this.addTag('a', text, { href }); }
  build()                     { return this.html; }
}

const html = new HTMLBuilder()
  .addDiv('标题', 'header')
  .addParagraph('这是一段文字')
  .addLink('点击这里', 'https://example.com')
  .build();
```

## 单例模式（Singleton Pattern）

保证一个类只有一个实例，并提供全局访问点。

### 静态属性实现

```js
class Singleton {
  constructor() {
    // 二次 new 直接返回已有实例
    if (Singleton.instance) {
      return Singleton.instance;
    }
    this.data = [];
    Singleton.instance = this;
  }

  addData(item) { this.data.push(item); }
  getData() { return this.data; }

  static getInstance() {
    if (!Singleton.instance) {
      Singleton.instance = new Singleton();
    }
    return Singleton.instance;
  }
}

const instance1 = new Singleton();
const instance2 = new Singleton();
console.log(instance1 === instance2); // true

instance1.addData('item1');
console.log(instance2.getData()); // ['item1']（同一份数据）
```

### 闭包实现

```js
const Singleton = (function() {
  let instance; // 闭包私有，外部无法直接触碰

  function createInstance() {
    return {
      data: [],
      addData(item) { this.data.push(item); },
      getData() { return this.data; }
    };
  }

  return {
    getInstance() {
      if (!instance) {
        instance = createInstance();
      }
      return instance;
    }
  };
})();

const instance1 = Singleton.getInstance();
const instance2 = Singleton.getInstance();
console.log(instance1 === instance2); // true
```

### 实际应用：全局状态管理

```js
class Store {
  constructor() {
    if (Store.instance) return Store.instance; // 全局唯一
    this.state = {};
    this.listeners = [];
    Store.instance = this;
  }

  getState() {
    return this.state;
  }

  setState(newState) {
    this.state = { ...this.state, ...newState };
    this.notify(); // 状态变化后广播
  }

  subscribe(listener) {
    this.listeners.push(listener);
    return () => { // 返回取消订阅函数
      this.listeners = this.listeners.filter(l => l !== listener);
    };
  }

  notify() {
    this.listeners.forEach(listener => listener(this.state));
  }

  static getInstance() {
    if (!Store.instance) Store.instance = new Store();
    return Store.instance;
  }
}

const store = Store.getInstance();
store.subscribe(state => console.log('状态更新:', state));
store.setState({ user: 'Alice' });
store.setState({ count: 1 });
```

### 实际应用：弹窗管理器

```js
class ModalManager {
  constructor() {
    if (ModalManager.instance) return ModalManager.instance;
    this.modals = [];
    this.currentModal = null;
    ModalManager.instance = this;
  }

  register(modal) {
    this.modals.push(modal);
  }

  show(modalId) {
    // 单例管理器保证「同一时刻只有一个弹窗」的逻辑集中在一处
    if (this.currentModal) {
      this.currentModal.hide();
    }
    const modal = this.modals.find(m => m.id === modalId);
    if (modal) {
      modal.show();
      this.currentModal = modal;
    }
  }

  hide() {
    if (this.currentModal) {
      this.currentModal.hide();
      this.currentModal = null;
    }
  }

  static getInstance() {
    if (!ModalManager.instance) ModalManager.instance = new ModalManager();
    return ModalManager.instance;
  }
}

class Modal {
  constructor(id, content) {
    this.id = id;
    this.content = content;
    this.visible = false;
  }
  show() {
    this.visible = true;
    console.log(`显示弹窗: ${this.id}`);
  }
  hide() {
    this.visible = false;
    console.log(`隐藏弹窗: ${this.id}`);
  }
}

const manager = ModalManager.getInstance();
manager.register(new Modal('login', '登录表单'));
manager.register(new Modal('register', '注册表单'));

manager.show('login');
manager.show('register'); // 自动隐藏 login，显示 register
```

## 模式选择速查

| 场景 | 推荐模式 |
|------|---------|
| 全局唯一实例（store、连接池、弹窗管理器） | 单例 |
| 按类型创建相似对象（图表、组件） | 工厂 |
| 一族配套产品（跨平台 UI、主题） | 抽象工厂 |
| 多步骤构建复杂对象（配置、HTML） | 建造者 |
| 基于已有对象派生新对象 | 原型（Object.create） |

## 实践要点

- 单例的本质是「用一处受控的全局状态换多份重复实例」，代价是测试时需要重置——保留 `destroy`/`reset` 能力更友好
- 工厂模式与策略模式经常配合：工厂产出策略对象，消除调用方的 if/else
- JS 中「类」不是创建对象的唯一途径，`Object.create`、工厂函数、闭包同样能实现全部创建型模式
