# 函数基础

*类型：knowledge ｜ 难度：基础 ｜ 标签：函数、函数声明、函数表达式、默认参数、arguments*

**结论：函数是 JavaScript 的一等公民，可以像值一样被赋值、传参、返回，这是高阶函数与函数式编程的地基。四种定义方式的核心差异在「是否提升」与「this 绑定」：函数声明整体提升、表达式不提升、箭头函数词法 this 且不能当构造函数、`new Function` 性能差且不安全应禁用。参数系统靠默认参数、剩余参数、解构参数三层能力覆盖绝大多数场景；`arguments` 是类数组对象而非真数组，箭头函数中没有它，新代码统一用剩余参数 `...args` 替代。**

## 函数的定义方式

### 函数声明与函数表达式

函数声明会被整体提升（hoisting），声明前即可调用；函数表达式按普通变量规则处理（`const` 存在暂时性死区），声明前访问抛 `ReferenceError`。

```js
// 函数声明：整个函数体被提升到作用域顶部，声明前可以调用
console.log(multiply(2, 3)); // 6
function multiply(a, b) {
  return a * b;
}

function add(a, b) {
  return a + b;
}
```

```js
// 匿名函数表达式
const subtract = function(a, b) {
  return a - b;
};

// 具名函数表达式：函数名 div 只在函数体内部可见（可用于递归、报错栈）
const divide = function div(a, b) {
  if (b === 0) {
    throw new Error('Cannot divide by zero');
  }
  return a / b;
};

console.log(subtract(5, 3)); // 2
// console.log(test()); // ReferenceError：表达式不会提升
// const test = function() { return 1; };
```

### 箭头函数

```js
const square = (x) => x * x; // 单表达式函数体：隐式返回
const add = (a, b) => a + b;

// 多行函数体：需要花括号并显式 return
const complexFunc = (x, y) => {
  const result = x * y;
  return result + 10;
};

// 返回对象字面量必须用括号包裹，否则 {} 被解析为函数体
const createPerson = (name, age) => ({ name, age });
```

箭头函数不是普通函数的「语法糖」，它没有自己的 `this`、`arguments`、`prototype`，也不能作为构造函数，详见「箭头函数与普通函数的差异」。

### 构造函数方式（不推荐）

```js
// 参数是字符串形式的代码，等价于 eval：性能差、不安全、引擎难以优化
const sum = new Function('a', 'b', 'return a + b');
console.log(sum(2, 3)); // 5
```

### 四种方式对比

| 方式 | 提升 | this | 可作构造函数 | 典型场景 |
|------|------|------|--------------|----------|
| 函数声明 | 是 | 调用时确定 | 可以 | 顶层工具函数 |
| 函数表达式 | 否 | 调用时确定 | 可以 | 回调、条件定义 |
| 箭头函数 | 否 | 定义时继承 | 不可以 | 回调、保持外层 this |
| new Function | 否 | 全局 | 可以 | 动态执行代码（避免） |

## 函数参数

### 默认参数

```js
// ES6 之前：无法区分「没传」与「传了假值」，传 0、'' 会被误替换
function greet(name) {
  name = name || 'Guest';
  return 'Hello, ' + name;
}

// ES6 默认参数：只在实参为 undefined 时生效
function greet(name = 'Guest') {
  return `Hello, ${name}`;
}
console.log(greet());        // 'Hello, Guest'
console.log(greet('Alice')); // 'Hello, Alice'

// 默认值表达式惰性求值、从左到右计算，可以引用前面的参数
function createUser(name, role = 'user', id = name.toLowerCase()) {
  return { name, role, id };
}
```

### 剩余参数

```js
function sum(...numbers) {
  // numbers 是真正的数组，可直接使用数组方法
  return numbers.reduce((total, num) => total + num, 0);
}
console.log(sum(1, 2, 3, 4, 5)); // 15

// 剩余参数必须是最后一个参数
function logInfo(title, ...details) {
  console.log(`${title}:`, details);
}
logInfo('User Info', 'Alice', 25, 'Engineer');
// User Info: ['Alice', 25, 'Engineer']
```

### 解构参数

```js
// 对象解构：参数签名即文档，role 支持默认值
function createUser({ name, age, role = 'user' }) {
  return { name, age, role };
}
createUser({ name: 'Alice', age: 25 });

// 数组解构：同样支持默认值
function getCoordinates([x, y, z = 0]) {
  return { x, y, z };
}
getCoordinates([10, 20]); // { x: 10, y: 20, z: 0 }
```

## arguments 对象

`arguments` 是所有非箭头函数内部可用的类数组对象，包含实参列表。

```js
function showArgs() {
  console.log(arguments);        // [Arguments] { '0': 1, '1': 2, '2': 3 }
  console.log(arguments.length); // 3
  console.log(arguments[0]);     // 1

  // 类数组而非真数组
  console.log(Array.isArray(arguments)); // false

  // 三种常见转真数组的方式
  const a1 = Array.from(arguments);
  const a2 = [...arguments];
  const a3 = Array.prototype.slice.call(arguments);
}
showArgs(1, 2, 3);

// 箭头函数没有自己的 arguments：引用到的是外层函数的，顶层则直接报错
const arrowFunc = () => {
  console.log(arguments); // ReferenceError（或访问到外层的 arguments）
};
```

## 手动实现 call 与 apply

call 与 apply 都是显式绑定 this 并立即执行，区别只在参数形式：call 逐个传，apply 传数组。手写思路一致：把函数临时挂到目标对象上——借「`对象.方法()`」的隐式绑定让 this 指向该对象，调用完删掉临时属性。属性名用 `Symbol` 生成，保证不覆盖对象已有属性。

### myCall：参数逐个传递

```js
Function.prototype.myCall = function(context, ...args) {
  // context 为 null 或 undefined 时，非严格模式指向全局对象
  context = context || window;

  // 用 Symbol 创建唯一属性名，避免覆盖对象原有属性
  const fnSymbol = Symbol();

  // 函数被挂为 context 的方法，调用时 this 自然指向 context
  context[fnSymbol] = this;

  // 以方法调用形式执行，参数逐个展开
  const result = context[fnSymbol](...args);

  // 删除临时属性，不留下痕迹
  delete context[fnSymbol];

  return result;
};

// 测试
function greet(greeting) {
  console.log(`${greeting}, I'm ${this.name}`);
}

const person = { name: 'Alice' };
greet.myCall(person, 'Hello'); // "Hello, I'm Alice"
```

### myApply：参数以数组传递

```js
Function.prototype.myApply = function(context, args) {
  context = context || window;
  const fnSymbol = Symbol();
  context[fnSymbol] = this;

  // 与 myCall 唯一的差异：args 是数组，先判断有无再展开
  const result = args ? context[fnSymbol](...args) : context[fnSymbol]();

  delete context[fnSymbol];
  return result;
};
```

## 使用建议

- 优先函数声明或箭头函数，避免 `new Function` 与 `eval`
- 需要收集不定长参数时用剩余参数，不要再依赖 `arguments`
- 对象参数配合解构与默认值，避免「参数顺序地狱」
- 函数只做一件事，参数尽量少（超过 3 个考虑收敛为对象）
