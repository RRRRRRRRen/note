# 箭头函数与普通函数的差异

*类型：question ｜ 难度：进阶 ｜ 标签：箭头函数、this、arguments、构造函数、prototype*

**结论：箭头函数不是普通函数的语法糖，而是「语法层写死的函数」——它没有自己的 this、arguments、prototype，不能作为构造函数，也不能做 Generator。this 在定义时通过作用域链静态确定，call/apply/bind 均无法改变。因此选择标准只有一条：需要「词法 this」（继承外层 this）就选箭头函数；需要「动态 this」（对象方法、原型方法、事件处理器）就必须用普通函数。在对象方法里写箭头函数是最常见的 this 事故来源。**

## 六个核心差异

### 没有自己的 this

箭头函数不创建 `this`，它捕获定义时所在词法作用域的 `this` 并永久固化——普通函数的 `this` 由调用方式决定，箭头函数的由书写位置决定。

```js
const obj = {
  name: 'Alice',

  // 普通函数：this 由「谁调用」决定
  regularFunc: function() {
    console.log('Regular:', this.name);
  },

  // 箭头函数：this 在定义时继承外层（这里是模块/全局作用域）
  arrowFunc: () => {
    console.log('Arrow:', this.name);
  },

  // 嵌套场景对比
  nested: function() {
    // 普通函数包着箭头函数：箭头函数继承 nested 的 this（obj）
    setTimeout(() => {
      console.log('Nested arrow:', this.name); // 'Nested arrow: Alice'
    }, 100);

    // 普通函数包着普通函数：回调的 this 退回默认绑定（全局）
    setTimeout(function() {
      console.log('Nested regular:', this.name); // 'Nested regular: undefined'
    }, 100);
  }
};

obj.regularFunc(); // 'Regular: Alice'
obj.arrowFunc();   // 'Arrow: undefined'（this 指向全局对象）
```

### call、apply、bind 无法改变 this

由于箭头函数没有 `this` 绑定槽位，三个显式绑定方法全部失效，第一个参数被忽略。

```js
const obj = { name: 'Alice' };
const arrowFunc = () => {
  console.log(this.name);
};

arrowFunc.call(obj);          // undefined（this 未变）
arrowFunc.apply(obj);         // undefined
const boundFunc = arrowFunc.bind(obj);
boundFunc();                  // undefined
```

### 不能作为构造函数

箭头函数没有 `[[Construct]]` 内部方法，`new` 调用直接抛 `TypeError`。

```js
const Person = (name) => {
  this.name = name;
};

// const alice = new Person('Alice'); // TypeError: Person is not a constructor
```

### 没有 prototype 属性

没有构造能力自然不需要原型对象；普通函数的 `prototype` 是 `new` 时挂到实例 `__proto__` 上的那个对象。

```js
const arrowFunc = () => {};
console.log(arrowFunc.prototype); // undefined

function regularFunc() {}
console.log(regularFunc.prototype); // { constructor: f }
```

### 没有 arguments 对象

箭头函数体内引用的 `arguments` 沿作用域链向外查找，拿到的是外层函数的；顶层则直接报错。需要收集参数时用剩余参数。

```js
function regularFunc() {
  console.log(arguments); // [Arguments] { '0': 1, '1': 2 }

  const arrowFunc = () => {
    console.log(arguments); // 访问的是外层 regularFunc 的 arguments
  };
  arrowFunc();
}
regularFunc(1, 2);

// 正确做法：剩余参数
const sum = (...args) => {
  console.log(args); // [1, 2, 3]
};
sum(1, 2, 3);
```

### 不能用作 Generator

箭头函数没有 `function*` 形式，无法使用 `yield`。

```js
// const generatorArrow = * () => { yield 1; }; // SyntaxError

// 正确：普通函数
function* generator() {
  yield 1;
  yield 2;
}
```

## 差异总览

| 特性 | 普通函数 | 箭头函数 |
|------|----------|----------|
| this | 调用时确定（四种绑定规则） | 定义时继承外层，永久固定 |
| call/apply/bind 改 this | 可以 | 不可以 |
| 作为构造函数 | 可以 | 不可以（TypeError） |
| prototype | 有 | 无 |
| arguments | 有自己的 | 无（沿作用域链查找） |
| Generator | 可以（function*） | 不可以 |
| 适合场景 | 对象方法、原型方法、事件处理 | 回调、需要保持外层 this 的场景 |

## 适用场景

### 适合使用箭头函数

```js
// 1. 数组方法回调：简短且无需 this
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map(n => n * 2);
const evens = numbers.filter(n => n % 2 === 0);

// 2. 定时器回调
setTimeout(() => {
  console.log('Delayed execution');
}, 1000);

// 3. Promise 链
fetch('/api/data')
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error(error));

// 4. 需要保持外层 this：类方法中的异步回调
class Counter {
  constructor() {
    this.count = 0;
  }
  start() {
    // 箭头函数继承 start 的 this，即实例本身
    setInterval(() => {
      this.count++;
      console.log(this.count);
    }, 1000);
  }
}
```

### 不适合使用箭头函数

```js
// 1. 对象方法：需要动态 this（谁调用指向谁），箭头函数会指向全局
const obj = {
  name: 'Alice',
  greet: () => {
    console.log(`Hello, ${this.name}`); // this 不指向 obj
  }
};

// 2. 原型方法：this 需要指向实例
Person.prototype.greet = () => {
  console.log(this.name); // this 不指向实例
};

// 3. 事件处理器：需要访问 event.target / DOM 元素自身
button.addEventListener('click', () => {
  console.log(this); // this 不指向 button
});

// 4. 需要使用 arguments 的场景
const sum = () => {
  // arguments 不可用（除非外层恰好有）
};
```

## 实践要点

- 判断标准一句话：**this 要「向外」就箭头，要「向调用者」就普通函数**
- 类字段语法 `handleClick = () => {}` 是「用箭头函数绑定实例 this」的正向应用（React 事件处理常用）
- 回调函数中的 `const that = this` 旧技巧在箭头函数普及后已无必要
