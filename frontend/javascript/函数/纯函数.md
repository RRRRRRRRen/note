# 纯函数

*类型：knowledge ｜ 难度：基础 ｜ 标签：纯函数、副作用、函数式编程、可测试性、Memoization*

**结论：纯函数是函数式编程的最小单元，判据只有两条：相同输入永远产生相同输出（确定性），执行过程不产生副作用（不修改外部状态）。它带来的收益是乘法式的——可测试（无需 mock 环境）、可缓存（Memoization 的前提）、可组合（管道拼装的安全保证）、可并行（无共享状态即无竞态）。写代码时优先把「计算」抽成纯函数，把「副作用」（IO、DOM、网络）集中推到系统边界，是函数式编程最具性价比的一条实践。**

## 什么是纯函数

纯函数满足两个条件：

- **确定性**：相同输入永远得到相同输出，结果只由输入决定
- **无副作用**：执行过程中不修改外部状态，也不读取可变的外部状态

```js
// 纯函数：输出只依赖输入
function add(a, b) {
  return a + b;
}
console.log(add(2, 3)); // 5
console.log(add(2, 3)); // 5（永远相同）

// 纯函数：不修改原数组，返回新数组
function multiply(arr, factor) {
  return arr.map(item => item * factor);
}
const numbers = [1, 2, 3];
console.log(multiply(numbers, 2)); // [2, 4, 6]
console.log(numbers);              // [1, 2, 3]（原数组未被修改）
```

典型的非纯函数形态：

```js
// 非纯：依赖外部可变变量
let count = 0;
function increment() {
  return ++count; // 同样无参调用，结果每次不同
}

// 非纯：修改传入的参数（副作用）
function addToArray(arr, item) {
  arr.push(item);
  return arr;
}

// 非纯：输出不确定（依赖系统时钟）
function getCurrentTime() {
  return new Date().getTime();
}

// 非纯：产生副作用（打印日志）
function logAndReturn(value) {
  console.log(value);
  return value;
}
```

## 纯函数的优势

### 可测试性强

测试不需要 mock 环境、不需要清理状态，断言输入输出即可。

```js
function calculateTotal(items) {
  return items.reduce((sum, item) => sum + item.price, 0);
}

console.assert(calculateTotal([{ price: 10 }, { price: 20 }]) === 30);
console.assert(calculateTotal([]) === 0);
```

### 可缓存性（Memoization）

确定性保证了「缓存结果必然正确」，这是记忆化技术成立的前提。

```js
function memoize(fn) {
  const cache = {};

  return function(...args) {
    const key = JSON.stringify(args); // 以参数为缓存键

    if (cache[key]) {
      console.log('From cache');
      return cache[key];
    }

    const result = fn(...args);
    cache[key] = result;
    return result;
  };
}

// 斐波那契是纯函数，缓存安全
const fibonacci = memoize(function(n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
});

console.log(fibonacci(10)); // 计算
console.log(fibonacci(10)); // From cache
```

### 可组合性

纯函数可以放心地互相拼接，前一个的输出作为后一个的输入。

```js
const double = x => x * 2;
const square = x => x * x;
const addOne = x => x + 1;

// compose：从右往左执行
const compose = (...fns) => x => fns.reduceRight((acc, fn) => fn(acc), x);

const calculate = compose(addOne, square, double);
console.log(calculate(3)); // ((3 * 2)^2) + 1 = 37
```

### 并行处理安全

没有共享状态就没有竞态，纯函数可以安全地在多个 Worker 中执行而不互相干扰。

```js
const processData = data => data.map(item => item * 2);

// Worker 1: processData([1, 2, 3])
// Worker 2: processData([4, 5, 6])
// 互不干扰
```

## 副作用（Side Effects）

副作用指函数在执行过程中对外部环境产生的影响。常见副作用：

- 修改全局变量或外部变量
- 修改传入的参数
- 发起 HTTP 请求
- 操作 DOM
- 打印日志
- 读写文件
- 修改数据库

关键不是「消灭副作用」——程序终究要做 IO——而是**把副作用收敛到边界，让核心计算保持纯净**：

```js
// 有副作用：直接改写传入对象
function updateUser(user) {
  user.lastUpdated = new Date();
  return user;
}

// 无副作用：返回新对象，原对象不变
function updateUser(user) {
  return {
    ...user,
    lastUpdated: new Date()
  };
}

// 有副作用：隐式修改外部变量
let total = 0;
function addToTotal(value) {
  total += value;
}

// 无副作用：状态通过参数显式进出
function addToTotal(total, value) {
  return total + value;
}
```

## 实践要点

- 判据口诀：**不看时钟、不掷骰子、不动外面的东西**
- 数据更新优先「创建新值」而非「修改旧值」（不可变数据思想）
- 副作用不禁止，只隔离：日志、网络、DOM 操作放在管道两端
- `Math.random()`、`Date.now()` 使函数失去确定性，从参数注入时间/随机源可恢复纯度
