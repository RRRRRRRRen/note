# 递归函数与优化

*类型：knowledge ｜ 难度：进阶 ｜ 标签：递归、尾递归、栈溢出、深拷贝、树遍历*

**结论：递归是函数调用自身的编程技巧，成立只靠两个要素——基准条件（终止递归）与递归条件（函数调用自身且向基准条件收敛）。JS 每次函数调用都要压栈，深度过大直接栈溢出；把「递归后还有计算」改写成「递归是最后一步操作」即尾递归，理论上可优化为循环，但 V8 并不支持，所以工程上要么尾递归 + 累加器写法（小深度），要么直接改循环/迭代（大深度）。递归的天然主场是树形结构：深拷贝、DFS 遍历、扁平化嵌套数组。**

## 什么是递归

递归函数的两个要素：

- **基准条件（Base Case）**：递归终止的条件，必须有且必然可达
- **递归条件（Recursive Case）**：函数调用自身，且问题规模逐步缩小

```js
// 经典示例：阶乘
function factorial(n) {
  if (n <= 1) return 1;      // 基准条件：n 到 1 停止
  return n * factorial(n - 1); // 递归条件：问题规模缩小
}
console.log(factorial(5)); // 120（5 * 4 * 3 * 2 * 1）

// 斐波那契数列
function fibonacci(n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}
console.log(fibonacci(7)); // 13
```

缺失或不可达的基准条件是栈溢出的头号来源；斐波那契朴素写法还叠加了重复子问题（同一 n 被反复计算），可用记忆化进一步优化。

## 尾递归优化

尾递归指递归调用是函数的**最后一个操作**，返回值不再需要任何后续计算，因此当前栈帧可以复用，理论上可优化为循环。

```js
// 非尾递归：递归返回后还有乘法操作，栈帧必须保留
function factorial(n) {
  if (n <= 1) return 1;
  return n * factorial(n - 1); // 乘法等在递归之后
}

// 尾递归：用累加器把「中间计算」提前到参数中，递归是最后一步
function factorial(n, acc = 1) {
  if (n <= 1) return acc;
  return factorial(n - 1, n * acc); // 无后续计算
}
console.log(factorial(5)); // 120

// 斐波那契的尾递归改写：a、b 即滚动状态
function fibonacci(n, a = 0, b = 1) {
  if (n === 0) return a;
  return fibonacci(n - 1, b, a + b);
}
console.log(fibonacci(7)); // 13
```

注意：尾递归优化（TCO）在 ECMAScript 规范中定义，但 V8（Chrome/Node）并未实现；写尾递归形式可读性尚可、又表达了迭代语义，但大深度场景仍应改写为显式循环。

## 递归的实际应用

### 深度遍历对象：深拷贝

```js
function deepClone(obj, hash = new WeakMap()) {
  // 基准条件：非对象类型直接返回
  if (obj === null || typeof obj !== 'object') {
    return obj;
  }

  // 处理循环引用：已拷贝过的对象直接复用，避免无限递归
  if (hash.has(obj)) {
    return hash.get(obj);
  }

  // 特殊类型：按对应构造器重建
  if (obj instanceof Date) return new Date(obj);
  if (obj instanceof RegExp) return new RegExp(obj);

  const cloneObj = Array.isArray(obj) ? [] : {};
  hash.set(obj, cloneObj); // 先登记再递归，循环引用才能被截断

  for (let key in obj) {
    if (obj.hasOwnProperty(key)) {
      cloneObj[key] = deepClone(obj[key], hash); // 递归复制每个属性
    }
  }
  return cloneObj;
}

const original = {
  name: 'Alice',
  hobbies: ['reading', 'coding'],
  address: { city: 'Beijing' }
};

const cloned = deepClone(original);
cloned.address.city = 'Shanghai';
console.log(original.address.city); // 'Beijing'（互不影响）
```

### 树形结构遍历与查找

```js
const tree = {
  value: 1,
  children: [
    {
      value: 2,
      children: [
        { value: 4, children: [] },
        { value: 5, children: [] }
      ]
    },
    {
      value: 3,
      children: [ { value: 6, children: [] } ]
    }
  ]
};

// 深度优先遍历
function dfs(node, callback) {
  callback(node.value);
  node.children.forEach(child => dfs(child, callback));
}
dfs(tree, value => console.log(value));
// 输出: 1, 2, 4, 5, 3, 6

// 查找节点：命中返回，否则递归查找每棵子树
function findNode(node, target) {
  if (node.value === target) return node;

  for (let child of node.children) {
    const found = findNode(child, target);
    if (found) return found;
  }
  return null;
}

console.log(findNode(tree, 5)); // { value: 5, children: [] }
```

### 扁平化数组

```js
// 递归扁平化：是数组就摊开，否则直接收
function flatten(arr) {
  const result = [];
  arr.forEach(item => {
    if (Array.isArray(item)) {
      result.push(...flatten(item));
    } else {
      result.push(item);
    }
  });
  return result;
}

const nested = [1, [2, [3, [4, 5]]], 6];
console.log(flatten(nested)); // [1, 2, 3, 4, 5, 6]

// reduce 写法：逻辑相同，聚合过程更紧凑
function flattenByReduce(arr) {
  return arr.reduce((acc, item) => {
    return acc.concat(Array.isArray(item) ? flattenByReduce(item) : item);
  }, []);
}
```

## 实践要点

- 写递归先写终止条件，再确认「每层递归都让问题规模变小」
- 尾递归写法 + 累加器适合表达迭代语义；V8 不做 TCO，深递归改循环
- 树形数据（嵌套对象、DOM、菜单树）递归前先想清楚循环引用的可能，用 `WeakMap` 记录已处理节点
- 重复子问题明显的递归（如朴素斐波那契）叠加记忆化，复杂度从指数级降到线性级
