# 严格模式

*类型：knowledge ｜ 难度：入门 ｜ 标签：严格模式、use strict、语法*

**严格模式是在代码顶部或函数体内加 `'use strict'` 声明的一套更严格的语法约束：把静默错误变成显式报错、禁止不安全操作，且 ES6 模块和类体自动启用——现代 JS 代码几乎总运行在严格模式下。**

## 开启方式

```js
// 1. 全局开启
'use strict';
var x = 10;

// 2. 函数内开启
function foo() {
  'use strict';
  // 函数内代码使用严格模式
}

// 3. 模块和类自动开启
// ES6 模块和类默认使用严格模式
```

## 主要限制

### 变量相关

```js
'use strict';

// 未声明变量直接赋值
x = 10;  // ReferenceError

// 删除变量
var y = 20;
delete y;  // SyntaxError

// 只能删除对象属性
const obj = { a: 1 };
delete obj.a;  // OK
```

### 函数相关

```js
'use strict';

// 参数重名
function foo(a, a, b) {  // SyntaxError
  return a + b;
}

// arguments.callee
function foo() {
  arguments.callee();  // TypeError
}

// 普通函数调用的 this 指向 undefined
function foo() {
  console.log(this);  // undefined（非严格模式是 window）
}
foo();
```

### 对象相关

```js
'use strict';

// 对只读属性赋值
const obj = {};
Object.defineProperty(obj, 'x', { value: 1, writable: false });
obj.x = 2;  // TypeError

// 删除不可删除的属性
delete Object.prototype;  // TypeError

// 对象属性重名（ES5 报错，ES6 已允许）
const obj = { a: 1, a: 2 };  // SyntaxError (ES5)
```

### 其他限制

```js
'use strict';

// 八进制字面量
const num = 0123;  // SyntaxError

// with 语句
with (obj) {  // SyntaxError
  // ...
}

// eval 作用域隔离
eval('var x = 10');
console.log(x);  // ReferenceError - x 不会泄漏到外层作用域
```

## 严格模式的好处

- **消除不合理语法**：禁止一些不安全的操作
- **提高安全性**：`this` 不会意外指向全局对象
- **提升性能**：便于引擎优化
- **为未来铺路**：保留关键字（`class`、`let`、`const` 等）

## 自动开启严格模式的情况

```js
// 1. ES6 模块
// module.js
export const x = 10;  // 自动严格模式

// 2. ES6 类
class MyClass {
  constructor() {
    // 自动严格模式
  }
}
```
