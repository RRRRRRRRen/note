# 尾调用优化

*类型：knowledge ｜ 难度：进阶 ｜ 标签：尾调用、递归、调用栈*

**尾调用指函数的最后一步是调用另一个函数；严格模式下引擎可复用外层栈帧、让调用栈始终只有一层，从而避免深递归导致的栈溢出——但该优化只在严格模式下生效，且写法上必须「调用后无任何后续操作」。**

## 尾调用的定义

**尾调用**：函数的最后一步是调用另一个函数。

```js
// 是尾调用：返回值就是调用结果本身
function f(x) {
  return g(x);
}

// 不是尾调用：调用 g 之后还有后续操作
function f(x) {
  const y = g(x);
  return y;  // 调用后还有操作
}

function f(x) {
  return g(x) + 1;  // 调用后还有操作
}
```

## 优化原理

正常函数调用会保留调用栈，每一层递归都要占用一层栈帧：

```js
function factorial(n) {
  if (n === 1) return 1;
  return n * factorial(n - 1);  // 不是尾调用，需要保留 n 以便乘法
}
// 调用栈：factorial(5) → factorial(4) → factorial(3) → ...
```

尾调用是函数的最后一步，外层函数的上下文不再被需要，引擎可以复用栈帧：

```js
function factorial(n, total = 1) {
  if (n === 1) return total;
  return factorial(n - 1, n * total);  // 尾调用，可以优化
}
// 调用栈始终只有一层
```

## 限制条件

- **只在严格模式下生效**
- 函数必须是尾调用（最后一步）
- 不能引用外层函数的变量

```js
'use strict';

// 可以优化：严格模式下的尾递归
function sum(n, acc = 0) {
  if (n === 0) return acc;
  return sum(n - 1, acc + n);
}
```

## 实际应用

尾递归优化主要用于避免深递归导致的栈溢出：

```js
// 普通递归 - 深度大时可能栈溢出，且存在重复计算
function fibonacci(n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}

// 尾递归写法 - 调用栈 O(1)，用参数携带中间结果
function fibonacci(n, a = 0, b = 1) {
  if (n === 0) return a;
  return fibonacci(n - 1, b, a + b);
}
```
