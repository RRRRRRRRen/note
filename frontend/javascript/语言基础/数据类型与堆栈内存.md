# 数据类型与堆栈内存

*类型：knowledge ｜ 难度：入门 ｜ 标签：数据类型、堆栈、内存*

**JavaScript 数据类型分为基本类型与引用类型两大类：基本类型按值存储在栈中，引用类型实体存储在堆中、栈里只保存指针——这决定了变量复制时「复制值」还是「复制引用」的根本差异。**

## 数据类型

### 基本数据类型（7 种）

存储在**栈**中，按值访问，大小固定。

- `undefined` - 未定义
- `null` - 空对象指针
- `boolean` - 布尔值
- `number` - 数字
- `string` - 字符串
- `symbol` - 唯一标识符（ES6）
- `bigInt` - 大整数（ES2020）

### 引用数据类型

存储在**堆**中，栈中存储指针，按引用访问。

- `object` - 对象（包括 Array、Function、Date、RegExp 等）

### 特殊类型说明

**Symbol** - 创建唯一不可变的值，解决全局变量冲突。

```js
// 直接调用，不使用 new
const sym1 = Symbol();
const sym2 = Symbol('foo');
const sym3 = Symbol('foo');
console.log(sym2 === sym3); // false - 每次都是唯一的
```

**BigInt** - 表示超过安全整数范围的大整数。

```js
const bigNum = 9007199254740991n; // 字面量末尾加 n
const bigNum2 = BigInt(9007199254740991); // 或使用 BigInt() 构造
```

## 堆栈内存

### 数据结构概念

- **栈（Stack）**：先进后出（LIFO），类似叠盘子
- **堆（Heap）**：优先队列，按优先级排序

### JavaScript 中的存储方式

| 类型 | 存储位置 | 特点 | 访问方式 |
|------|---------|------|---------|
| 基本类型 | 栈 | 大小固定，直接存值 | 按值访问 |
| 引用类型 | 堆 | 大小不固定，栈中存指针 | 按引用访问 |

### 复制行为差异

**重点理解**：基本类型复制的是值，引用类型复制的是引用（指针）。

```js
// 基本类型 - 复制值
let a = 10;
let b = a;  // 复制值
b = 20;
console.log(a); // 10 - a 不受影响

// 引用类型 - 复制引用
let obj1 = { name: 'Alice' };
let obj2 = obj1;  // 复制引用（指针）
obj2.name = 'Bob';
console.log(obj1.name); // 'Bob' - obj1 也被修改了
```
