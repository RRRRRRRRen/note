# Unicode 与编码

*类型：knowledge ｜ 难度：入门 ｜ 标签：Unicode、UTF-16、字符编码*

**Unicode 是字符集，为每个字符分配唯一码点；UTF-8/UTF-16/UTF-32 是编码方式，规定码点如何存储——JavaScript 字符串内部使用 UTF-16 编码，这解释了为什么某些字符的 `length` 是 2。**

## 基本概念

- **Unicode**：字符集，为每个字符分配唯一编号（码点）
- **UTF-8/UTF-16/UTF-32**：编码方式，规定如何存储 Unicode 字符

## 常见编码方式

| 编码 | 特点 | 使用场景 |
|------|------|---------|
| UTF-8 | 变长编码（1-4 字节），ASCII 兼容 | 网页、文件存储 |
| UTF-16 | 变长编码（2 或 4 字节） | JavaScript 内部编码 |
| UTF-32 | 定长编码（4 字节） | 内存占用大，少用 |

## JS 中的体现

JavaScript 字符串使用 UTF-16 编码，`length` 统计的是**码元**（16 位编码单元）个数，而不是字符个数。超出基本多文种平面（BMP）的字符需要两个码元（代理对）表示。

```js
// JavaScript 使用 UTF-16
'𝌆'.length;  // 2 - 需要两个码元表示
'你'.length;  // 1
```
