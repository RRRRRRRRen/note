# 包装类型

*类型：knowledge ｜ 难度：入门 ｜ 标签：包装类型、自动装箱、原始值*

**基本类型本身没有属性和方法，但访问 `str.length` 这类操作时，JavaScript 会自动装箱：临时创建对应的包装对象、调用完毕立即销毁——这也是给原始值挂属性不报错但无效的原因。**

## 自动装箱过程

```js
const str = 'hello';
str.length;         // 5
str.toUpperCase();  // 'HELLO'

// 背后发生的事情：
// 1. 创建 String 对象：new String('hello')
// 2. 调用方法：临时对象.toUpperCase()
// 3. 销毁临时对象
```

## 三种包装类型

String、Number、Boolean 各有对应的包装类型，原始值与包装对象的类型不同。

```js
// String
const s = 'hello';
typeof s;                // "string"
s instanceof String;     // false

const S = new String('hello');
typeof S;                // "object"
S instanceof String;     // true

// Number
const n = 123;
typeof n;                // "number"

const N = new Number(123);
typeof N;                // "object"

// Boolean
const b = true;
typeof b;                // "boolean"

const B = new Boolean(true);
typeof B;                // "object"
```

## 注意事项

```js
// 不要使用 new 创建包装对象
const bool = new Boolean(false);
if (bool) {
  console.log('执行了'); // 会执行！因为对象是真值
}

// 可以不用 new 进行类型转换
String(123);    // "123"
Number('123');  // 123
Boolean(0);     // false
```
