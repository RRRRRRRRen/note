# 类数组对象

*类型：knowledge ｜ 难度：入门 ｜ 标签：类数组、Array.from、arguments*

**类数组对象是拥有 `length` 属性和索引属性、但不能调用数组方法的对象——常见于 `arguments`、NodeList、HTMLCollection 和字符串，转换为真数组的推荐方式是 `Array.from()`。**

## 常见类数组

```js
// 1. arguments 对象
function foo() {
  console.log(arguments);        // [1, 2, 3]
  console.log(arguments.length); // 3
  // arguments.push(4);          // TypeError - 没有数组方法
}
foo(1, 2, 3);

// 2. DOM 查询结果
const divs = document.querySelectorAll('div');  // NodeList
const children = document.body.children;        // HTMLCollection

// 3. 字符串
const str = 'hello';
console.log(str[0]);     // 'h'
console.log(str.length); // 5
```

## 转换为真数组

```js
const arrayLike = { 0: 'a', 1: 'b', 2: 'c', length: 3 };

// 方法 1：Array.from() - 推荐
Array.from(arrayLike);  // ['a', 'b', 'c']

// 方法 2：扩展运算符
[...arrayLike];  // ['a', 'b', 'c']

// 方法 3：Array.prototype.slice.call()
Array.prototype.slice.call(arrayLike);  // ['a', 'b', 'c']

// 转换后可以使用数组方法
const arr = Array.from(arrayLike);
arr.push('d');
arr.map(x => x.toUpperCase());
```
