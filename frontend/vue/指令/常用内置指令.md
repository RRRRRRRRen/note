# 常用内置指令

*类型：knowledge ｜ 难度：基础 ｜ 标签：Vue、指令、v-bind、v-model*

**内置指令是 Vue 模板层最核心的声明式能力：`v-bind` 绑属性、`v-on` 绑事件、`v-model` 双向绑定、`v-if`/`v-show` 控显隐、`v-for` 做列表渲染，另有 `v-pre`、`v-cloak`、`v-once` 等性能与边界指令。** Vue 3 在此之上增强了 `v-model`（多绑定、默认 modelValue）和 `v-on`（对象语法）。指令的核心差异点在于：`v-if` 是真实创建/销毁，`v-show` 只是切换 CSS。

## Vue 2 常用指令

### v-bind：属性绑定

- 作用：动态绑定 HTML 属性、组件 prop 等，可绑定任何合法属性。

```html
<a v-bind:href="url">链接</a>
<!-- 简写 -->
<a :href="url">链接</a>
```

常见使用（class、style 的对象语法）：

```html
<div :class="{ active: isActive }"></div>
<div :style="{ color: textColor }"></div>
```

### v-on：事件绑定

- 作用：绑定事件监听器。

```html
<button v-on:click="doSomething">点击</button>
<!-- 简写 -->
<button @click="doSomething">点击</button>
```

修饰符：

- `.stop`：阻止事件冒泡。
- `.prevent`：阻止默认事件。
- `.once`：只触发一次。
- `.capture`：使用捕获模式。
- `.self`：仅自身触发时触发事件。

```html
<form @submit.prevent="onSubmit"></form>
<div @click.stop="onDivClick"></div>
```

### v-model：双向绑定

- 作用：实现表单控件与数据的双向绑定。
- 适用控件：`<input>`、`<textarea>`、`<select>` 等。

```html
<input v-model="message">
<select v-model="selected">
  <option>选项A</option>
</select>
```

### v-if / v-else-if / v-else：条件渲染

- 作用：条件控制组件或元素是否创建、销毁。

```html
<p v-if="score > 90">优秀</p>
<p v-else-if="score >= 60">及格</p>
<p v-else>不及格</p>
```

- 注意：`v-if` 是真实的 DOM 创建/销毁，切换开销大，适合条件较少变动的场景。

### v-show：显示隐藏

- 作用：通过 CSS 的 `display` 属性控制显示/隐藏。

```html
<p v-show="isVisible">这段内容可见</p>
```

特点：

- 元素始终存在于 DOM 中。
- 仅切换 `display: none`。
- 初始渲染开销小、切换开销小，适合频繁切换。

### v-for：列表渲染

- 作用：基于数组、对象、字符串、数字进行列表渲染。

```html
<li v-for="(item, index) in items" :key="index">
  {{ item }}
</li>
```

对象遍历：

```html
<div v-for="(value, key, index) in obj" :key="key">
  {{ key }}: {{ value }}
</div>
```

- 注意：必须提供唯一的 `:key`，以优化渲染性能。

### v-pre：跳过编译

- 作用：跳过该元素和子元素的编译过程，提升性能或展示原始 Mustache。

```html
<span v-pre>{{ 未编译 }}</span>
```

### v-cloak：防止闪烁

- 作用：防止 Vue 未挂载前模板闪烁。

```html
<div v-cloak>{{ msg }}</div>
```

结合 CSS 隐藏：

```css
[v-cloak] { display: none; }
```

### v-once：只渲染一次

- 作用：只渲染一次，数据变化不再更新。

```html
<h1 v-once>{{ title }}</h1>
```

- 适合：展示静态数据，节省性能消耗。

### 其他内置指令

| 指令 | 功能简述 |
| --- | --- |
| `v-html` | 输出 HTML 字符串并渲染 |
| `v-text` | 替代 Mustache 输出纯文本 |

```html
<div v-html="htmlContent"></div>
<div v-text="plainText"></div>
```

## Vue 3 指令新特性

### v-model 的增强

- 支持多个 `v-model` 绑定，配合 `v-model:propName` 使用。
- 默认绑定的是 `modelValue` 和 `update:modelValue`。

父组件写法：

```vue
<MyForm v-model:title="bookTitle" v-model:author="bookAuthor" />
```

子组件写法：

```ts
const props = defineProps(['title', 'author'])
const emit = defineEmits(['update:title', 'update:author'])
```

### v-on 支持对象绑定

- `v-on` 可绑定整个事件对象，适合封装组件、统一处理事件。

```html
<button v-on="{ click: handleClick, mouseenter: handleHover }">按钮</button>
```

### 组件事件修饰符增强

- Vue 3 中组件的 `v-on` 事件绑定支持更细的控制：`.once`、`.number`、`.trim` 修饰符仍然支持，自定义组件上的绑定也可以直接传入修饰符。

```html
<MyInput @update:modelValue.once="handleChange" />
```

## 选用速查

| 场景 | 指令选择 | 关键理由 |
| --- | --- | --- |
| 绑定属性/prop | `v-bind`（`:`） | 任意合法属性皆可动态化 |
| 绑定事件 | `v-on`（`@`） | 配合修饰符替代手写 preventDefault 等 |
| 表单双向绑定 | `v-model` | 语法糖，等价 value/checked + 事件回写 |
| 条件少变、含销毁语义 | `v-if` | 真实创建销毁，初始条件为假时不渲染 |
| 频繁切换显隐 | `v-show` | 只切 display，无销毁开销 |
| 列表渲染 | `v-for` | 必须配唯一 `:key` |
| 静态内容 | `v-once` / `v-pre` | 跳过更新或编译，节省性能 |
