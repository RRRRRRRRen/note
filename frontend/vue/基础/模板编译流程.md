# 模板编译流程

*类型：knowledge ｜ 难度：进阶 ｜ 标签：Vue、模板编译、AST、render 函数*

**Vue 的模板编译是把模板语法（HTML 结构 + 指令）转换为渲染函数 render 的过程，分为三个阶段：Parse 解析模板生成 AST，Optimize 遍历 AST 标记静态节点做优化，Generate 把 AST 转成 render 函数代码字符串并经 `new Function` 变成可执行函数。** 运行时 render 函数返回 VNode 树，交给 diff 算法 patch 更新真实 DOM。

## 1. Parse：生成 AST 抽象语法树

- 输入：HTML 模板字符串。
- 输出：AST（Abstract Syntax Tree）对象结构。
- 工作：解析 HTML 标签、属性、指令（如 `v-if`、`v-for`）、插值 `{{}}`。

## 2. Optimize：标记静态节点

- Vue 会遍历 AST，判断哪些节点是静态节点，做静态提升优化。
- 静态节点标记：`static: true`、`staticRoot: true`。

## 3. Generate：生成 render 函数

1. 步骤一：将 AST 转换成 JS 代码字符串，即 render 函数源码。
2. 步骤二：运行时通过 `new Function(code)` 变成真正的可执行函数。

## 4. Render：配合 diff 算法渲染

render 函数每次组件更新时会执行，返回 VNode 虚拟 DOM 树，Vue 再通过 diff 算法对比并更新真实 DOM。

```text
template → Parse → AST → Optimize（标记静态节点）→ Generate → render 函数 → VNode → diff → patch
```
