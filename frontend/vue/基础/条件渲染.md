# 条件渲染

*类型：knowledge ｜ 难度：基础 ｜ 标签：Vue、Vue3、v-if、v-show*

**条件渲染的两条路径：`v-if` / `v-else-if` / `v-else` 真实地创建或销毁 DOM，`v-show` 永远保留 DOM 只切换 `display` CSS。** 频繁切换选 `v-show`，条件很少变动且含「不存在」语义选 `v-if`；`v-show` 不能用在 `<template>` 上，同一元素上 `v-if` 优先于 `v-for` 执行。

## v-if / v-else-if / v-else

- 作用：条件控制组件或元素是否创建、销毁，切换时生命周期钩子随之触发/销毁。
- 链式规则：`v-else-if` 表示 v-if 的「else if 块」，可以链式调用；`v-else` 是条件收尾语句，必须紧跟在 `v-if` 或 `v-else-if` 之后。

```html
<p v-if="score > 90">优秀</p>
<p v-else-if="score >= 60">及格</p>
<p v-else>不及格</p>
```

## v-show

- 作用：通过 CSS 的 `display` 属性控制显示/隐藏，元素始终被渲染。

```html
<p v-show="isVisible">这段内容可见</p>
```

特点：

- 元素始终存在于 DOM 中。
- 仅切换 `display: none`。
- 初始无论真假都会渲染，切换时无创建/销毁开销，适合频繁切换。

## v-if 与 v-show 的选择

| 维度 | v-if | v-show |
| --- | --- | --- |
| 实现方式 | 真实创建/销毁 DOM 节点 | 仅切换 display CSS |
| 初始渲染 | 条件为假时不渲染（惰性） | 无论真假都渲染 |
| 切换开销 | 高（销毁重建、触发生命周期） | 低（只改样式） |
| `<template>` 支持 | 支持 | 不支持 |
| 适用场景 | 条件少变、初始为假、需要销毁语义 | 频繁切换显隐 |

## 注意事项

- `v-show` 不支持在 `<template>` 元素上使用（`<template>` 本身不产出 DOM，无处应用 display）。
- 当 `v-if` 和 `v-for` 同时存在于一个元素上时，`v-if` 会首先执行（Vue 3 中 `v-if` 无法访问 `v-for` 的作用域，官方不推荐两者用在同一元素，应在外层包裹 `<template v-for>` 后再判断）。
