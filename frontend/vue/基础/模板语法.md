# 模板语法

*类型：knowledge ｜ 难度：基础 ｜ 标签：Vue、Vue3、模板语法、插值、指令*

**Vue 模板语法的三块基石是：文本插值（`{{ }}`）、Attribute 绑定（`v-bind` / `:`）和指令（`v-` 前缀的特殊 attribute）。** 插值内是受沙盒限制的 JavaScript 表达式，每次组件更新都会重新求值；指令则把条件渲染、事件、双向绑定等行为声明在模板上。注意两个执行顺序陷阱：`v-show` 不能用于 `<template>`，同一元素上 `v-if` 先于 `v-for` 执行。

## 文本插值

- 模板中的表达式将被沙盒化，仅能访问有限的全局对象列表（如 `Math` 和 `Date` 等常用内置全局对象）。
- 绑定在表达式中的方法在组件每次更新时都会被重新调用（无缓存，区别于计算属性）。

```vue
<template>
  <!-- script 声明的顶级变量 -->
  <div>{{ message }}</div>

  <!-- 表达式 -->
  <div>{{ message == 0 ? '我是小满0' : '我不是小满other' }}</div>
  <div>{{ message + 1 }}</div>
  <div>{{ message.split('，') }}</div>

  <!-- 调用函数 -->
  <div>{{ formatDate(date) }}</div>
</template>

<script setup lang="ts">
const message = "我是小满"
</script>
```

## Attribute 绑定

- Mustache 语法不能用在 HTML attribute 上，绑定 attribute 要用 `v-bind`（简写 `:`）。

```vue
<!-- 完整写法 -->
<div v-bind:id="dynamicId"></div>

<!-- 省略写法 -->
<div :id="dynamicId"></div>

<!-- 布尔值：isButtonDisabled 为假值时省略 disabled 属性 -->
<button :disabled="isButtonDisabled">Button</button>

<!-- 绑定函数返回值 -->
<time :title="toTitleDate(date)" :datetime="date"></time>

<!-- 动态参数：属性名本身由变量决定 -->
<a :[attributeName]="url"> ... </a>
```

## 指令

注意事项：

- `v-show` 不支持在 `<template>` 元素上使用（`<template>` 本身不渲染 DOM）。
- 当 `v-if` 和 `v-for` 同时存在于一个元素上时，`v-if` 会首先执行（Vue 3 中 `v-if` 无法访问 `v-for` 的作用域变量，官方也不推荐两者同用）。

指令列表：

```text
v-text： 用来显示文本
v-html： 用来展示富文本
v-if： 用来控制元素的显示隐藏（切换真假DOM）
v-else-if： 表示 v-if 的"else if 块"。可以链式调用
v-else： v-if条件收尾语句
v-show： 用来控制元素的显示隐藏（display none block Css切换）
v-on： 简写@ 用来给元素添加事件
v-bind： 简写:  用来绑定元素的属性Attr
v-model： 双向绑定
v-for： 用来遍历元素
```
