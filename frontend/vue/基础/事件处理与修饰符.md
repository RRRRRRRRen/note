# 事件处理与修饰符

*类型：knowledge ｜ 难度：基础 ｜ 标签：Vue、Vue3、事件处理、修饰符*

**Vue 用 `@`（`v-on`）绑定事件，内联处理器通过 `$event` 或箭头函数访问原生事件对象；修饰符（`.stop`、`.prevent`、`.self` 等）把 preventDefault / stopPropagation 这类命令式操作声明在模板里。** 修饰符按书写顺序生成代码，`@click.prevent.self` 与 `@click.self.prevent` 语义不同；按键与鼠标修饰符（`.enter`、`.ctrl`、`.exact` 等）进一步约束触发的按键条件。

## 事件对象 event

向处理器方法传入特殊的 `$event` 变量，或者使用内联箭头函数：

```vue
<!-- 使用特殊的 $event 变量 -->
<button @click="warn('Form cannot be submitted yet.', $event)">
  Submit
</button>

<!-- 使用内联箭头函数 -->
<button @click="(event) => warn('Form cannot be submitted yet.', event)">
  Submit
</button>
```

```js
function warn(message, event) {
  // 这里可以访问原生事件
  if (event) {
    event.preventDefault()
  }
  alert(message)
}
```

## 事件修饰符

注意：使用修饰符时需要注意调用顺序，因为相关代码是以相同的顺序生成的：

- `@click.prevent.self` 会阻止元素及其子元素的所有点击事件的默认行为。
- `@click.self.prevent` 则只会阻止对元素本身的点击事件的默认行为。

常见修饰符：

```text
@click.stop： 停止冒泡
@submit.prevent: 阻止默认事件
@click.self: 仅当 event.target 是元素本身时才会触发事件处理器
@click.capture: 捕获模式
@click.once: 仅触发一次
@scroll.passive: 提前告诉浏览器不拦截默认事件
```

基本用法：

```vue
<!-- 单击事件将停止传递 -->
<a @click.stop="doThis"></a>

<!-- 提交事件将不再重新加载页面 -->
<form @submit.prevent="onSubmit"></form>

<!-- 修饰语可以使用链式书写 -->
<a @click.stop.prevent="doThat"></a>

<!-- 也可以只有修饰符（不绑定处理器） -->
<form @submit.prevent></form>

<!-- 仅当 event.target 是元素本身时才会触发事件处理器 -->
<!-- 例如：事件处理器不来自子元素 -->
<div @click.self="doThat">...</div>
```

capture、once 与 passive：

```vue
<!-- 添加事件监听器时，使用 capture 捕获模式 -->
<!-- 例如：指向内部元素的事件，在被内部元素处理前，先被外部处理 -->
<div @click.capture="doThis">...</div>

<!-- 点击事件最多被触发一次 -->
<a @click.once="doThis"></a>

<!-- 滚动事件的默认行为 (scrolling) 将立即发生而非等待 onScroll 完成 -->
<!-- 以防其中包含 event.preventDefault() -->
<!-- .passive 一般用于触摸事件的监听器，可以用来改善移动端设备的滚屏性能 -->
<div @scroll.passive="onScroll">...</div>
```

## 按键修饰符

可用别名：

```text
.enter
.tab
.delete（捕获删除和退格键）
.esc
.space
.up
.down
.ctrl
.alt
.shift
.meta
.exact（系统修饰符精确控制）
```

```vue
<!-- 仅在 key 为 Enter 时调用 submit -->
<input @keyup.enter="submit" />

<!-- Alt + Enter -->
<input @keyup.alt.enter="clear" />

<!-- Ctrl + 点击 -->
<div @click.ctrl="doSomething">Do something</div>
```

`.exact` 控制系统修饰键的组合精度：

```vue
<!-- 当按下 Ctrl 时，即使同时按下 Alt 或 Shift 也会触发 -->
<button @click.ctrl="onClick">A</button>

<!-- 仅当按下 Ctrl 且未按任何其他键时才会触发 -->
<button @click.ctrl.exact="onCtrlClick">A</button>

<!-- 仅当没有按下任何系统按键时触发 -->
<button @click.exact="onClick">A</button>
```

## 鼠标按键修饰符

```text
.left： 鼠标左键
.right： 鼠标右键
.middle： 鼠标中键
```

## 修饰符速查

| 分类 | 修饰符 | 作用 |
| --- | --- | --- |
| 事件流程 | `.stop` | 停止冒泡 |
| 事件流程 | `.capture` | 捕获模式，外层先处理 |
| 默认行为 | `.prevent` | 阻止默认行为 |
| 触发次数 | `.once` | 仅触发一次 |
| 目标过滤 | `.self` | 仅 event.target 为自身时触发 |
| 性能 | `.passive` | 不拦截默认行为，改善滚动性能 |
| 按键 | `.enter` / `.ctrl` / `.exact` 等 | 限定按键与修饰键组合 |
| 鼠标 | `.left` / `.right` / `.middle` | 限定鼠标按键 |
