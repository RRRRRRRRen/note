# 表单输入绑定

*类型：knowledge ｜ 难度：基础 ｜ 标签：Vue、Vue3、v-model、表单*

**`v-model` 是表单双向绑定的语法糖：它在底层根据控件类型自动选择属性与事件的配对——文本类控件绑 `value` + 监听 `input`，复选/单选绑 `checked` + 监听 `change`，下拉绑 `value` + 监听 `change`。** 复选框绑定数组实现多选，`lazy` / `number` / `trim` 三个修饰符分别处理同步时机、类型转换与去空格。

## 原理

- 文本类型的 `<input>` 和 `<textarea>` 元素会绑定 `value` property 并侦听 `input` 事件。
- `<input type="checkbox">` 和 `<input type="radio">` 会绑定 `checked` property 并侦听 `change` 事件。
- `<select>` 会绑定 `value` property 并侦听 `change` 事件。

## 示例

复选框（绑定到数组即为多选）：

```vue
<!-- 复选框 -->
<div>Checked names: {{ checkedNames }}</div>

<input type="checkbox" id="jack" value="Jack" v-model="checkedNames">
<label for="jack">Jack</label>

<input type="checkbox" id="john" value="John" v-model="checkedNames">
<label for="john">John</label>

<input type="checkbox" id="mike" value="Mike" v-model="checkedNames">
<label for="mike">Mike</label>
```

单选按钮：

```vue
<!-- 单选 -->
<div>Picked: {{ picked }}</div>

<input type="radio" id="one" value="One" v-model="picked" />
<label for="one">One</label>

<input type="radio" id="two" value="Two" v-model="picked" />
<label for="two">Two</label>
```

下拉选择（单选与多选）：

```vue
<!-- 下拉选择 -->
<div>Selected: {{ selected }}</div>

<select v-model="selected">
  <option disabled value="">Please select one</option>
  <option>A</option>
  <option>B</option>
  <option>C</option>
</select>
```

```vue
<!-- 下拉多选：multiple 绑定数组 -->
<div>Selected: {{ selected }}</div>

<select v-model="selected" multiple>
  <option>A</option>
  <option>B</option>
  <option>C</option>
</select>
```

## 修饰符

- `lazy`：把同步时机从 `input` 改为在每次 `change` 事件后更新数据（失焦或回车时才同步）。
- `number`：让用户输入自动转换为数字。
- `trim`：默认自动去除用户输入内容中两端的空格。

```vue
<input v-model.lazy="msg" />
<input v-model.number="age" />
<input v-model.trim="username" />
```

## 控件与绑定速查

| 控件 | 绑定属性 | 监听事件 | 值类型 |
| --- | --- | --- | --- |
| text / textarea | `value` | `input` | 字符串 |
| checkbox（单个） | `checked` | `change` | 布尔 |
| checkbox（多个） | `checked` | `change` | 数组 |
| radio | `checked` | `change` | 选中项的 value |
| select（单选） | `value` | `change` | option 的 value |
| select（多选） | `value` | `change` | 数组 |
