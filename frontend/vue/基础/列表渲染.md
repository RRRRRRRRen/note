# 列表渲染

*类型：knowledge ｜ 难度：基础 ｜ 标签：Vue、Vue3、v-for、key*

**`v-for` 不仅能遍历数组，还能用 `(value, key, index)` 的形式遍历对象的全部属性。** 无论遍历什么，都必须提供唯一的 `:key`，让 diff 算法把每个节点和它的状态对上号，这是列表渲染性能与正确性的共同前提。

## 遍历对象

可以使用 `v-for` 来遍历一个对象的所有属性，第二个参数是键名，第三个参数是索引：

```js
const myObject = reactive({
  title: 'How to do lists in Vue',
  author: 'Jane Doe',
  publishedAt: '2016-04-10'
})
```

```html
<li v-for="(value, key, index) in myObject">
  {{ index }}. {{ key }}: {{ value }}
</li>
```

- 渲染结果依次为：`0. title: How to do lists in Vue`、`1. author: Jane Doe`、`2. publishedAt: 2016-04-10`。

## 数组遍历

```html
<li v-for="(item, index) in items" :key="item.id">
  {{ item.name }}
</li>
```

## key 的要点

- 必须提供唯一的 `:key`，以优化渲染性能：key 是 diff 算法判断「节点能否复用」的依据，key 稳定则只移动/更新，key 缺失则按位置就地修补。
- 推荐使用数据自身的唯一标识（id）作为 key，避免使用 index：列表中间插入/删除时，index 会导致节点错位复用，输入类组件的状态会串行。
- 同一列表内 key 不可重复，否则渲染结果不可预期。

## 遍历形式速查

| 目标 | 语法 | 参数含义 |
| --- | --- | --- |
| 数组 | `v-for="(item, index) in items"` | 项、索引 |
| 对象 | `v-for="(value, key, index) in obj"` | 值、键名、索引 |
| 数字 | `v-for="n in 10"` | 1 到 10 |
| 字符串 | `v-for="ch in str"` | 每个字符 |
