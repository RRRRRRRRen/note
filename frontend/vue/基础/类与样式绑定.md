# 类与样式绑定

*类型：knowledge ｜ 难度：基础 ｜ 标签：Vue、Vue3、class 绑定、style 绑定*

**`v-bind` 绑定 `class` 与 `style` 时支持对象和数组语法：对象按「键名生效、布尔值开关」聚合类名，数组合并多个绑定结果，且都能与静态 `class` attribute 共存。** 绑定到组件上时遵循透传规则：根节点唯一则自动落到根节点，根节点不唯一需在子组件中用 `$attrs.class` 显式声明接收。

## 绑定 style

对象语法支持小驼峰与连字符两种键名，数组语法会把多个样式对象合并：

```vue
<!-- 绑定对象：小驼峰命名 -->
<div :style="{ color: activeColor, fontSize: fontSize + 'px' }"></div>

<!-- 绑定对象：连字符命名 -->
<div :style="{ 'font-size': fontSize + 'px' }"></div>

<!-- 绑定对象数组：解析的时候会合并对象 -->
<div :style="[baseStyles, overridingStyles]"></div>
```

## 绑定 class

```vue
<!-- 绑定对象：属性值为布尔值，true 时类名生效 -->
<div :class="{ active: isActive }"></div>

<!-- 绑定数组：可以使用表达式赋空串 -->
<div :class="[isActive ? activeClass : '', errorClass]"></div>

<!-- 绑定对象数组：多个对象或者字符串混合 -->
<div :class="[{ active: isActive }, errorClass]"></div>

<!-- :class 指令也可以和一般的 class attribute 共存 -->
<div
  class="static"
  :class="{ active: isActive, 'text-danger': hasError }"
></div>
```

## 组件上绑定 class

### 根节点唯一

不需要在子组件中声明接受，class 直接赋值到根节点：

```vue
<!-- 子组件模板 -->
<p class="foo bar">Hi!</p>
<!-- 在使用组件时 -->
<MyComponent class="baz boo" />
<!-- 渲染出的 HTML -->
<p class="foo bar baz boo">Hi</p>
```

### 根节点不唯一

需要在子组件中使用 `$attrs.class` 声明接受，指定 class 落到哪个节点：

```vue
<!-- 子组件模板 -->
<p :class="$attrs.class">Hi!</p>
<span>This is a child component</span>
<!-- 在使用组件时 -->
<MyComponent class="baz" />
<!-- 渲染出的 HTML -->
<p class="baz">Hi!</p>
<span>This is a child component</span>
```

## 语法速查

| 场景 | 写法 | 说明 |
| --- | --- | --- |
| 单类名开关 | `:class="{ active: isActive }"` | 对象：键为类名，值为布尔 |
| 多类名组合 | `:class="[{ active: isActive }, errorClass]"` | 对象数组混合 |
| 条件选择 | `:class="[isActive ? a : '', b]"` | 数组元素可用表达式 |
| 多样式合并 | `:style="[baseStyles, overridingStyles]"` | 数组自动合并对象 |
| 静态共存 | `class="static" :class="..."` | 静态与动态类名合并 |
