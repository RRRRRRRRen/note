# 组件间通信方式

*类型：knowledge ｜ 难度：进阶 ｜ 标签：Vue、组件通信、props、provide、mitt*

**Vue 组件通信按距离选型：父子用 props / emit，兄弟提升到父组件或走事件总线（Vue2 Event Bus、Vue3 mitt），跨层级用 provide / inject，任意层级用全局状态管理（Vuex / Pinia），需要直接调用子组件方法时用 ref 拿实例（Vue3 需配合 `defineExpose`）。**

## 父子通信

### 1. Vue 2

- 父传子：props。
- 子传父：`$emit`。

```vue
<!-- 父组件 -->
<Child :msg="message" @child-click="handleClick" />

<!-- 子组件 -->
<script>
export default {
  props: ['msg'],
  methods: {
    handleClick() {
      this.$emit('child-click', data)
    }
  }
}
</script>
```

### 2. Vue 3

- 父传子：`defineProps`。
- 子传父：`defineEmits`。

```vue
<script setup>
const props = defineProps(['msg'])
const emit = defineEmits(['childClick'])

function onClick() {
  emit('childClick', 'hello')
}
</script>
```

### 3. 父传子：props 的完整定义

JS 定义方式：

```vue
<!-- Child -->
<script setup>
const props = defineProps({
  title: {
    type: String,
    default: 'renguoqiang',
    required: true
  },
  arr: {
    type: Array,
    default: [2, 3, 4],
    required: false
  }
})
</script>
```

TS 定义方式（配合 `withDefaults` 给默认值）：

```js
const props = withDefaults(
  defineProps<{
    title: string,
    arr?: number[]
  }>(),
  {
    title: () => 'renguoqiang',
    arr: () => [2, 3, 4]
  }
)
```

补充：`useAttrs` 可以接受未被 props 声明的标签属性与事件：

```js
const attrs = useAttrs()
```

### 4. 子传父：emit 的完整定义

```vue
<!-- Father -->
<template>
  <div>Father</div>
  <ChildVue @on-click="getPayload" @on-input="getPayload" />
</template>

<script setup lang="ts">
import ChildVue from './Child.vue'

const getPayload = (payload: string) => {
  console.log('payload :>> ', payload)
}
</script>
```

```vue
<!-- Child -->
<template>
  <div>Child</div>
  <input type="text" @click="onClick" @input="onInput" />
</template>

<script setup lang="ts">
// js 声明
const emit = defineEmits(['on-click', 'on-input'])
// ts 声明：可约束事件名与载荷类型
const emit = defineEmits<{
  (e: 'on-click', payload: string): void
  (e: 'on-input', payload: string): void
}>()
const onClick = () => {
  emit('on-click', 'payload-click')
}
const onInput = () => {
  emit('on-input', 'payload-input')
}
</script>
```

## 兄弟通信

### 1. Vue 2

- 把值或方法提升到父组件，再通过 props 传下去。
- 借助 Event Bus（`new Vue()` 作为事件中心）。

### 2. Vue 3

- 把值或方法提升到父组件，再通过 props 传下去。
- 借助 mitt 库（Vue 3 移除了 `$on` / `$off`，官方实例不再能当总线用）。

## provide / inject（祖孙通信）

### 1. Vue 2

使用 `provide` / `inject`（响应性较弱）：

```js
// 祖先组件
provide() {
  return { msg: this.message }
}

// 子孙组件
inject: ['msg']
```

### 2. Vue 3

使用增强了响应式支持的 `provide` / `inject`，传入 ref 即可保持响应性：

```vue
<script setup>
// 父组件
import { ref, provide } from 'vue'
provide('name', ref('张三'))

// 子组件
import { inject } from 'vue'
const name = inject('name')
</script>
```

应用级 provide 也可以在创建应用时注册：

```js
import { createApp } from 'vue'

const app = createApp({})

app.provide(/* 注入名 */ 'message', /* 值 */ 'hello!')
```

## 全局状态管理

- Vue 2：推荐使用 Vuex 3/4。
- Vue 3：推荐使用 Pinia（新一代状态管理）。

## ref 获取子组件实例

### 1. Vue 2

通过 `this.$refs` 获取实例：

```html
<Child ref="child" />

this.$refs.child.someMethod()
```

### 2. Vue 3

定义一个同名 `ref(null)`；且子组件默认封闭，需要在子组件中用 `defineExpose` 显式暴露属性与方法：

```vue
<!-- Father -->
<script setup>
import { ref, onMounted } from 'vue'
import Child from './Child.vue'

const childRef = ref(null)
onMounted(() => {
  childRef.value.someMethod()
})
</script>

<template>
  <Child ref="childRef" />
</template>
```

```vue
<!-- Child -->
<script setup>
import { ref } from 'vue'

const msg = ref('ren')
const func = () => {
  console.log('msg :>> ', msg)
}
// 显式暴露，父组件才能通过 ref 访问
defineExpose({ msg, func })
</script>
```

TS 场景下父组件可用 `InstanceType` 拿到实例类型：

```js
const dom = ref<InstanceType<typeof ChildVue>>()
onMounted(() => {
  dom.value?.func()
})
```

### 3. 子组件访问父组件

子组件可通过 `$parent` 访问父组件暴露的内容（父组件同样需要 `defineExpose`）：

```vue
<!-- Child -->
<template>
  <div @click="handleClick($parent)">Child</div>
</template>

<script setup>
const handleClick = ($parent) => {
  console.log($parent.msg)
}
</script>
```

## 全局总线 mitt

### 1. 注册

方式一：挂载到 Vue 应用实例上（补充 TS 声明后通过 `app.config.globalProperties` 使用）：

```ts
import { createApp } from 'vue'
import App from './App.vue'
import mitt from 'mitt'

const app = createApp(App)

const Mit = mitt()
// 补充 ts 声明
declare module 'vue' {
  export interface ComponentCustomProperties {
    eventBus: typeof Mit
  }
}
// 挂载到 vue 全局变量
app.config.globalProperties.eventBus = Mit

app.mount('#app')
```

方式二：导出单例（更常用，任意模块直接 import）：

```ts
import mitt from 'mitt'

const emitter = mitt()

export default emitter
```

### 2. 使用

发送方用 `emit` 派发事件：

```vue
<template>
  <button @click="changebtn(1)">增加</button>
  <button @click="changebtn(-1)">减少</button>
  <AVue v-for="item in itemNum" :key="item" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
import eventBus from './mitt'
import AVue from './A.vue'

const itemNum = ref(4)
const changebtn = (num: number) => {
  itemNum.value = itemNum.value + num
  // 使用 emit 派发事件
  eventBus.emit('goEmit', itemNum)
}
</script>
```

接收方用 `on` 监听、`off` 解绑（组件卸载前务必 off，防止重复监听与内存泄漏）：

```vue
<template>
  <div>ren</div>
</template>

<script setup lang="ts">
import { onBeforeUnmount } from 'vue'
import eventBus from './mitt'

// 使用 on 触发事件
eventBus.on('goEmit', (payload) => {
  console.log('payload :>> ', payload)
})
// 使用 off 删除事件
onBeforeUnmount(() => {
  eventBus.off('goEmit')
})
</script>
```

## 选型小结

| 场景 | 方案 |
| --- | --- |
| 父传子 | props |
| 子传父 | emit |
| 兄弟 | 提升到父组件 / mitt 事件总线 |
| 跨层级（祖孙） | provide / inject |
| 任意组件 | Vuex（Vue2）/ Pinia（Vue3） |
| 直接调用子组件方法 | ref + defineExpose |
