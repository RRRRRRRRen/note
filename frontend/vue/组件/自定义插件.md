# 自定义插件

*类型：knowledge ｜ 难度：进阶 ｜ 标签：Vue、插件、install、app.use*

**插件是一个拥有 `install()` 方法的对象（或直接是一个安装函数），通过 `Vue.use` / `app.use` 注册时被调用，用于为应用添加全局能力：全局方法、全局指令、全局组件、实例属性等。Vue 2 往 `Vue` 构造函数与 `Vue.prototype` 上挂载，Vue 3 改为通过 `app` 实例的 `config.globalProperties`、`app.directive`、`app.component` 注册。**

## Vue 2 插件开发与使用

### 1. 插件结构

```js
// myPlugin.js
const MyPlugin = {
  install(Vue, options) {
    // 添加全局方法
    Vue.myGlobalMethod = function () {
      console.log('全局方法')
    }

    // 添加全局指令
    Vue.directive('focus', {
      inserted(el) {
        el.focus()
      }
    })

    // 添加实例方法
    Vue.prototype.$hello = function (msg) {
      console.log(`Hello, ${msg}`)
    }
  }
}

export default MyPlugin
```

### 2. 注册插件

```js
import Vue from 'vue'
import MyPlugin from './myPlugin'

Vue.use(MyPlugin, { someOption: true })
```

## Vue 3 插件开发与使用

### 1. 对象插件

```js
const MyPlugin = {
  install(app, options) {
    // 添加全局方法/属性
    app.config.globalProperties.$hello = (msg) => {
      console.log(`Hello, ${msg}`)
    }

    // 注册全局指令
    app.directive('focus', {
      mounted(el) {
        el.focus()
      }
    })

    // 注册全局组件
    app.component('MyButton', {
      template: `<button><slot /></button>`
    })
  }
}
```

### 2. 函数式插件

插件也可以直接是一个安装函数本身：

```js
function MyPlugin(app, options) {
  app.config.globalProperties.$msg = () => alert('Hi')
}
```

### 3. 注册插件

`app.use` 会在 `mount` 之前调用插件的 `install`（或函数本身），并把可选选项传入：

```js
import { createApp } from 'vue'
import App from './App.vue'
import MyPlugin from './myPlugin'

const app = createApp(App)
app.use(MyPlugin, { option: true })
app.mount('#app')
```

## 要点

- `install` 的第一个参数是 Vue（Vue 2）或 app 实例（Vue 3），第二个参数是 `use` 时传入的选项。
- 注册插件必须在 `app.mount()` 之前完成。
