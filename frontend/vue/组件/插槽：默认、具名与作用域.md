# 插槽：默认、具名与作用域

*类型：knowledge ｜ 难度：进阶 ｜ 标签：Vue、插槽、slot*

**插槽是子组件给父组件预留的「内容出口」：默认插槽对应单个无名出口，具名插槽用 `name` 声明多个出口、父组件用 `#name` 填充，作用域插槽把子组件内部数据通过 slot props 反向传给父组件的填充内容——三者可以组合使用。**

## 子组件声明插槽

```vue
<!-- 默认插槽 -->
<slot></slot>
<!-- 具名插槽 -->
<slot name="xxx"></slot>
<!-- 作用域插槽：通过属性向外传数据 -->
<slot name="xxx" :value="msg"></slot>
```

## 父组件填充插槽

```vue
<!-- 默认插槽 -->
<Child>
  <template>123</template>
</Child>
<!-- 具名插槽：# 是 v-slot 的简写 -->
<Child>
  <template #xxx>123</template>
</Child>
<!-- 作用域插槽：接收子组件传出的数据 -->
<Child>
  <template #xxx="slotProps">{{ slotProps.value }}</template>
  <!-- 也可直接解构 -->
  <template #xxx="{ value }">{{ value }}</template>
</Child>
```

## 完整示例

子组件声明三个出口，其中 footer 是作用域插槽：

```vue
<!-- Child -->
<template>
  <div class="header">
    <slot name="header"></slot>
  </div>
  <div class="main">
    <slot></slot>
  </div>
  <div class="footer">
    <slot name="footer" :data="data" :obj="obj"></slot>
  </div>
</template>

<script setup lang="ts">
import { ref, reactive } from 'vue'
const data = ref('AAA')
const obj = reactive({ a: 123 })
</script>
```

父组件填充，支持动态插槽名（`v-slot:[slotName]`）：

```vue
<!-- Father -->
<template>
  <AVue>
    <template #header>头部插槽</template>
    <template v-slot>默认插槽</template>
    <template v-slot:[slotName]="{ data, obj }">尾部插槽{{ data }}{{ obj }}</template>
  </AVue>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import AVue from './A.vue'
const slotName = ref('footer')
</script>
```

## 要点

- `v-slot` 只能写在 `<template>` 上（默认插槽可简写为 `#default`）。
- 作用域插槽的数据流向是「子 → 父」的内容级传参：数据是子组件的，模板结构由父组件决定。
- 具名插槽与作用域插槽可同时使用：`<template #footer="{ data }">`。
