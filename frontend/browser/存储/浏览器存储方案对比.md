# 浏览器存储方案对比

*类型：knowledge ｜ 难度：入门 ｜ 标签：浏览器、存储、Cookie、LocalStorage*

**三种方案按「容量 × 生命周期 × 是否随请求发送」区分：Cookie 仅 4KB 且每次同源请求自动携带，是唯一为服务端读写设计的存储；LocalStorage 约 5MB、永久持久化、不随请求发送，适合长期本地数据；SessionStorage 同为 5MB 但会话级——窗口关闭即清除，且只能被同一窗口的同源页面访问。Cookie 记得配 `HttpOnly` 和 `Secure`，LocalStorage 是同步 API、大容量读写可能阻塞主线程。**

## Cookie

- 由服务端设置，存储在客户端
- 每次同源 HTTP 请求自动携带
- 大小限制：单个 4KB，每域名约 20 个
- 生命周期由 `expires` 或 `max-age` 决定
- 缺点：容量小，增加请求流量，安全性较低（建议设置 `HttpOnly` 和 `Secure`）

## LocalStorage

- 容量约 5MB
- 持久存储，不会过期，除非主动清除
- 不随 HTTP 请求发送
- 同步操作，可能阻塞主线程

```js
localStorage.setItem('key', 'value');
const value = localStorage.getItem('key');
localStorage.removeItem('key');
localStorage.clear();
```

## SessionStorage

- 容量约 5MB
- 会话级存储，窗口关闭后自动清除，刷新不清除
- 只能被同一窗口的同源页面访问

```js
sessionStorage.setItem('key', 'value');
const value = sessionStorage.getItem('key');
sessionStorage.removeItem('key');
sessionStorage.clear();
```

## 三者对比

| 特性 | Cookie | LocalStorage | SessionStorage |
| --- | --- | --- | --- |
| 容量 | 4KB | 5MB | 5MB |
| 生命周期 | 可设置过期时间 | 永久 | 窗口关闭即清除 |
| 随请求发送 | 是 | 否 | 否 |
| 作用域 | 同源 | 同源所有页面 | 同一窗口同源页面 |
