# 移动端下拉刷新与上拉加载

*类型：practice ｜ 难度：入门 ｜ 标签：移动端、滚动、touch 事件*

**上拉加载的核心是触底判断 `scrollTop + clientHeight >= scrollHeight`，下拉刷新的核心是 touch 三事件（touchstart 记录起点、touchmove 计算距离、touchend 判断阈值）——现代方案可改用 IntersectionObserver 监听哨兵元素。**

## 上拉加载（触底加载）

### 关键属性

```js
// 元素高度属性
element.clientHeight;   // 可见区域高度（不含边框）
element.offsetHeight;   // 可见区域高度（含边框）
element.scrollHeight;   // 内容总高度（含滚动部分）
element.scrollTop;      // 已滚动的高度
```

### 触底判断

触底条件：`scrollTop + clientHeight >= scrollHeight`。

```js
// 实现示例
window.addEventListener('scroll', () => {
  const { scrollTop, clientHeight, scrollHeight } = document.documentElement;

  // 距离底部 50px 时触发，提前加载减少等待感
  if (scrollTop + clientHeight >= scrollHeight - 50) {
    loadMore();
  }
});

function loadMore() {
  console.log('加载更多数据...');
  // 发送请求获取更多数据
}
```

## 下拉刷新

### 实现步骤

- **touchstart**：记录初始触摸位置
- **touchmove**：计算下拉距离，显示刷新提示
- **touchend**：判断是否达到刷新阈值，执行刷新

### 实现示例

```js
let startY = 0;
let isPulling = false;

const container = document.querySelector('.container');

// 1. 记录初始位置
container.addEventListener('touchstart', (e) => {
  // 只在顶部时允许下拉，避免干扰正常滚动
  if (container.scrollTop === 0) {
    startY = e.touches[0].pageY;
    isPulling = true;
  }
});

// 2. 计算下拉距离
container.addEventListener('touchmove', (e) => {
  if (!isPulling) return;

  const currentY = e.touches[0].pageY;
  const distance = currentY - startY;

  // 只处理向下拉
  if (distance > 0) {
    e.preventDefault();  // 阻止默认滚动

    // 使用 transform 移动元素，不触发重排
    container.style.transform = `translateY(${distance}px)`;

    // 显示刷新提示
    if (distance > 80) {
      showRefreshHint('释放刷新');
    } else {
      showRefreshHint('下拉刷新');
    }
  }
});

// 3. 判断是否刷新
container.addEventListener('touchend', (e) => {
  if (!isPulling) return;

  const currentY = e.changedTouches[0].pageY;
  const distance = currentY - startY;

  // 达到阈值，执行刷新
  if (distance > 80) {
    refresh();
  }

  // 重置状态
  container.style.transform = 'translateY(0)';
  isPulling = false;
  hideRefreshHint();
});

function refresh() {
  console.log('刷新数据...');
  // 发送请求刷新数据
}
```

## 现代方案

```js
// 使用 Intersection Observer API 实现上拉加载：
// 监听列表底部的哨兵元素，进入视口即触发加载
const observer = new IntersectionObserver((entries) => {
  if (entries[0].isIntersecting) {
    loadMore();
  }
});

const sentinel = document.querySelector('.sentinel');
observer.observe(sentinel);
```
