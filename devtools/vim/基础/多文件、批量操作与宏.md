# 多文件、批量操作与宏

*类型：practice ｜ 难度：入门 ｜ 标签：Vim、分屏、批量编辑、宏、列模式*

**单文件编辑只是 Vim 的一半能力：`split`/`vsplit` 分屏对照多文件，`Ctrl+v` 列模式批量插入，`行范围+命令` 精准批删批复制，宏把「重复 N 次的编辑序列」压缩成一次录制多次回放。核心心法：发现自己在重复同一组按键，就该停下来用宏或列模式。**

## 多文件操作

| 命令 | 功能 |
| --- | --- |
| `:split 文件名` | 水平分屏打开另一个文件 |
| `:vsplit 文件名` | 垂直分屏打开文件 |
| `Ctrl + w + 方向键` | 切换分屏窗口 |
| `:tabnew 文件名` | 在新标签页打开文件 |

分屏适合「对照修改」（如左边接口定义、右边实现）；标签页适合「多文件轮换」，两者可以叠加使用。

## 批量操作

### 行范围命令

命令模式支持「起始行,结束行 + 命令」的批量语法：

| 命令 | 功能 |
| --- | --- |
| `:10,20d` | 删除第 10 到 20 行 |
| `:10,20co30` | 将 10-20 行复制到第 30 行后 |

范围写法可组合：`%` 代表全文件（如 `:%d` 清空），`.` 代表当前行，`$` 代表最后一行。

### 列编辑模式（块插入）

多行同一位置插入相同内容的标准做法：

1. 按 `Ctrl + v` 进入可视块模式。
2. 用 `j`/`k` 选中多行的同一列区域。
3. 按 `I`（大写）进入插入，输入内容。
4. 按 `Esc`，内容会自动补到选中的每一行。

## 宏录制

把一组重复操作录进寄存器，之后按名回放：

1. 按 `q` + 寄存器名（如 `qa`）开始录制。
2. 执行操作（如删除行、插入文本等）。
3. 按 `q` 结束录制。
4. 按 `@a` 回放一次；`@@` 重复上一次回放。

批量回放可在范围命令里执行：如 `:5,10normal! @a` 对第 5 到 10 行逐行回放宏 a。

## 典型场景

- 给多行行首统一加注释符：`Ctrl+v` 选中行首列 → `I` 输入 `#` → `Esc`。
- 十处相似修改：改好第一处后录宏，`@a` + 数字前缀（如 `10@a`）批量回放。
- 两个文件对照改：`:vsplit 文件` 分屏后 `Ctrl+w` 系列切窗。

## 常见误区

- 录宏前不先规范光标起点：宏是按键序列的回放，起点不一致结果就错位——录制第一步通常是 `0` 或 `^` 归位。
- 用列模式插入了内容却没按 `Esc`：块插入要等退出插入模式才统一生效。
- 长宏一录到底：宏里步骤越少越稳，复杂操作拆成多个小宏分别回放更可控。
