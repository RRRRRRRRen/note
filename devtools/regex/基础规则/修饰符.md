# 修饰符

*类型：knowledge ｜ 难度：入门 ｜ 标签：正则、修饰符、全局匹配、多行模式*

**修饰符写在正则字面量末尾（如 `/abc/g`），控制整个匹配过程的全局行为：是否区分大小写、是否全局匹配、`^` `$` 是否按行生效、`.` 是否包含换行符。四个常用修饰符一句话记忆：i 管大小写，g 管次数，m 管行，s 管点。**

## 修饰符一览

| 修饰符 | 全称 | 说明 |
| --- | --- | --- |
| `i` | ignore case | 不区分大小写 |
| `g` | global | 全局匹配，找出所有匹配而非第一个 |
| `m` | multi line | 多行模式，使 `^` `$` 在每一行都生效 |
| `s` | single line | 单行模式，使 `.` 包含换行符 |

## 用法示例

```js
// i：大小写不敏感
/a/i.test("A"); // true

// g：全局匹配
"abab".match(/ab/g); // => ["ab", "ab"]，不带 g 只返回第一个 ["ab"]

// m：多行模式
// 不带 m 时 ^ 只匹配整个字符串开头；带 m 后每一行的开头都算
"I\nlove\njavascript".replace(/^|$/gm, '#');
// => "#I#\n#love#\n#javascript#"

// s：dotAll 模式
// 默认 . 不匹配换行符；加 s 后可以跨行
/a.b/s.test("a\nb"); // true
```

## 修饰符可组合

修饰符按需叠加，顺序无关：

```js
// 全局 + 不区分大小写：常用于统计与替换
"Foo foo FOO".match(/foo/gi); // => ["Foo", "foo", "FOO"]
```

## 常见误区

- 忘记 `g` 导致替换/统计只处理第一处：`replace` 带 `g` 才会替换全部。
- 以为 `m` 影响所有锚点：`m` 只让 `^` `$` 按行生效，`\b` 与环视不受它影响。
- 把 `s` 记成「单行匹配一次」：`s` 是 dotAll，指 `.` 把整个文本当单行看待（`.` 可匹配换行符），匹配几次仍由 `g` 决定。
