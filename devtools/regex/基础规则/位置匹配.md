# 位置匹配

*类型：knowledge ｜ 难度：进阶 ｜ 标签：正则、位置、锚点、零宽断言*

**正则要么匹配字符，要么匹配位置；位置是相邻字符之间的空隙，本身不消耗字符。掌握 `^` `$`、单词边界 `\b` 以及环视 `(?=p)` `(?!p)` `(?<=p)` `(?<!p)` 四组锚点，就能实现「在什么地方插入、什么位置校验」这类不碰字符本身的操作。**

## 什么是位置

位置是相邻字符之间的空隙，比如 `hello` 共有 6 个位置：h 之前、h 与 e 之间、e 与 l 之间……o 之后。匹配位置的正则匹配结果为空字符串，只是「锚定」了一个坐标。

## 位置锚点一览

| 字符 | 含义 | 说明 |
| --- | --- | --- |
| `^` | 脱字符 | 匹配行的开头 |
| `$` | 美元符 | 匹配行的结尾 |
| `\b` | 单词边界 | `\w` 与 `\W` 之间、`^` 与 `\w` 之间、`\w` 与 `$` 之间的位置 |
| `\B` | 非单词边界 | `\w` 与 `\w`、`\W` 与 `\W`、`^` 与 `\W`、`\W` 与 `$` 之间的位置 |
| `(?=p)` | 正向先行断言 | p 子模式前面的位置 |
| `(?!p)` | 负向先行断言 | 非 p 子模式前面的位置 |
| `(?<=p)` | 正向后行断言 | p 子模式后面的位置 |
| `(?<!p)` | 负向后行断言 | 非 p 子模式后面的位置 |

## `^` 和 `$`

`^` 匹配开头，`$` 匹配结尾；配合多行修饰符 `m` 时对每一行生效。

```js
var result = "hello".replace(/^|$/g, '#');
result; // => "#hello#"
```

```js
var result = "I\nlove\njavascript".replace(/^|$/gm, '#');
// =>
// #I#
// #love#
// #javascript#
```

## `\b` 和 `\B`

`\b` 是单词边界：`\w`（字母数字下划线）与 `\W` 相邻之处，也包括字符串首尾与 `\w` 相邻之处。

```js
var result = "[JS] Lesson_01.mp4".replace(/\b/g, '#');
result; // => "[#JS#] #Lesson_01#.#mp4#"
```

注意 `Lesson_01` 整体是 `\w`，下划线不打断单词；而 `.` 两侧都是边界。

`\B` 是非单词边界，正好取补集：

```js
var result = "[JS] Lesson_01.mp4".replace(/\B/g, '#');
result; // => "#[J#S]# L#e#s#s#o#n#_#0#1.m#p#4"
```

## 环视断言

先行断言看「这个位置右边」是否满足子模式，后行断言看「左边」。

```js
// (?=l)：l 前面的位置
var result = "hello".replace(/(?=l)/g, '#');
result; // => "he#l#lo"

// (?!l)：非 l 前面的位置
var result = "hello".replace(/(?!l)/g, '#');
result; // => "#h#ell#o#"

// (?<=l)：l 后面的位置
var result = "hello".replace(/(?<=l)/g, '#');
result; // => "hel#l#o"

// (?<!l)：非 l 后面的位置
var result = "hello".replace(/(?<!l)/g, '#');
result; // => "h#e#llo#"
```

环视只占位不消费字符，所以 `(?!l)` 能在 h 前、h 与 e 之间等处连续命中。

## 常见误区

- 把 `\b` 理解成空格：它是 `\w` 与 `\W` 的交界，下划线属于 `\w`，不打断单词。
- 以为环视会「吃掉」匹配的字符：断言零宽，替换后原字符原样保留。
- 混淆先行与后行方向：`(?=p)` 锚在 p 左侧，`(?<=p)` 锚在 p 右侧。
