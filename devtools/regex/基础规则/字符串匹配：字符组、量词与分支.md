# 字符串匹配：字符组、量词与分支

*类型：knowledge ｜ 难度：进阶 ｜ 标签：正则、字符组、量词、贪婪匹配、分支*

**正则是匹配模式，要么匹配字符，要么匹配位置；字符串匹配的核心是两种模糊匹配——横向模糊（量词控制长度不定）与纵向模糊（字符组控制某一位可多选），再配合贪婪/惰性两种匹配策略与分支多选，就构成了字符匹配的全部基础。**

## 两种模糊匹配

- 横向模糊：一个正则可匹配的字符串长度不固定，用量词实现，如 `ab{2,5}c` 匹配 2 到 5 个 b。
- 纵向模糊：具体到某一位字符时可有多种可能，用字符组实现，如 `a[123]b` 匹配 a1b、a2b、a3b。

```js
var regex = /ab{2,5}c/g;
var string = "abc abbc abbbc abbbbc abbbbbc abbbbbbc";
string.match(regex); // => ["abbc", "abbbc", "abbbbc", "abbbbbc"]
```

```js
var regex = /a[123]b/g;
var string = "a0b a1b a2b a3b a4b";
string.match(regex); // => ["a1b", "a2b", "a3b"]
```

## 字符组

字符组（字符类）虽然叫「组」，但只匹配其中一个字符：`[abc]` 表示匹配一个字符，它可以是 a、b、c 之一。

### 范围表示法

- 可能性太多时用连字符 `-` 简写：`[123456abcdefGHIJKLM]` 可写成 `[1-6a-fG-M]`。
- 要匹配连字符本身时，放在开头 `[-az]`、放在结尾 `[az-]` 或转义 `[a\-z]`，总之不能让引擎误认为是范围表示法。

### 排除字符组

- 第一位放脱字符 `^` 表示求反：`[^abc]` 匹配除 a、b、c 之外的任意一个字符。

### 简写形式

| 字符 | 含义 | 等价 | 说明 |
| --- | --- | --- | --- |
| `.` | 通配符 | `[^\n\r]` | 匹配换行符之外的所有字符 |
| `\w` | word | `[A-Za-z0-9_]` | 字母、数字、下划线 |
| `\W` | | `[^A-Za-z0-9_]` | 非字母、数字、下划线 |
| `\d` | digit | `[0-9]` | 数字 |
| `\D` | | `[^0-9]` | 非数字 |
| `\s` | space | `[ \t\v\n\r\f]` | 空白符 |
| `\S` | | `[^ \t\v\n\r\f]` | 非空白符 |
| `[^]` | 任意字符 | | 也可用 `[\d\D]`、`[\w\W]`、`[\s\S]` |

| 字符 | 含义 |
| --- | --- |
| `\f` | 换页符 |
| `\n` | 换行符 |
| `\r` | 回车符 |
| `\t` | 制表符 |
| `\v` | 垂直制表符 |

## 量词

量词也称重复，掌握 `{m,n}` 的准确含义后记住简写即可。

| 字符 | 记忆方式 | 等价 | 说明 |
| --- | --- | --- | --- |
| `*` | 任意次数 | `{0,}` | 出现 0 次或多次 |
| `+` | 追加 | `{1,}` | 出现 1 次或多次 |
| `?` | 有还是没有 | `{0,1}` | 出现 0 次或 1 次 |
| `{n}` | | | 出现 n 次 |
| `{n,}` | | | 至少出现 n 次 |
| `{n,m}` | | | 出现 n 到 m 次 |

### 贪婪匹配

量词匹配的默认模式：在满足条件的前提下尽可能多地匹配。

```js
var regex = /\d{2,5}/g;
var string = "123 1234 12345 123456";
string.match(regex); // => ["123", "1234", "12345", "12345"]
```

最后一个 `123456` 中，`12345` 满足条件且是能取到的最大值，再取一位就超出 `{2,5}` 上限，所以匹配到 `12345` 为止。

### 惰性模式

与贪婪相对：在量词后加 `?`，尽可能少地匹配。

```js
var regex = /\d{2,5}?/g;
var string = "123 1234 12345 123456";
string.match(regex); // => ["12", "12", "34", "12", "34", "12", "34", "56"]
```

遇到 `12345` 时惰性匹配取到下限 `12` 即停；全局 `g` 模式下继续往后扫，`34` 又满足一次，以此类推。

## 分支多选

形式为 `(p1|p2|p3)`，用管道符 `|` 分隔子模式，表示其中任何之一。

```js
var regex = /good|nice/g;
var string = "good idea, nice try.";
string.match(regex); // => ["good", "nice"]
```

分支按声明顺序匹配，命中即停，不会继续尝试更长或更后的分支：

```js
var regex = /good|goodbye/g;
var string = "goodbye";
string.match(regex); // => ["good"]

var regex = /goodbye|good/g;
var string = "goodbye";
string.match(regex); // => ["goodbye"]
```

想匹配更长的词，就要把长分支写在前面。

## 常见误区

- 以为 `[abc]` 匹配 "abc" 整串：字符组永远只匹配一个字符。
- 以为 `?` 是可选标记不会影响贪婪：`\d{2,5}?` 的 `?` 是惰性开关，不是量词 `?`。
- 忘记分支命中即停：把短分支写在前面会「吞掉」长分支的匹配机会。
