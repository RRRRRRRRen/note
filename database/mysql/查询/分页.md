# 分页

*类型：knowledge ｜ 难度：基础 ｜ 标签：MySQL、LIMIT、SQL ｜ 更新：2026-09-22*

**分页的目标是只查询当前页需要的数据：LIMIT 控制返回条数，OFFSET（或「偏移量, 条数」双参数写法）控制跳过多少行。第 N 页每页 size 条的偏移量是 (N-1)*size。分页必须配合 ORDER BY 使用，否则页与页之间可能出现重复或遗漏；完整分页器还需要一条 COUNT(*) 查询总数来计算总页数。**

## 语法

```sql
SELECT * FROM 表名
LIMIT 偏移量, 每页条数;

-- 或者显式 OFFSET 写法
SELECT * FROM 表名
LIMIT 每页条数 OFFSET 偏移量;
```

| 参数 | 含义 |
| --- | --- |
| 偏移量 | 从第几条数据开始（从 0 开始计数） |
| 每页条数 | 一页显示多少条数据 |

```sql
-- 第 1 页
SELECT * FROM products
ORDER BY id ASC
LIMIT 0, 10;  -- 或者 LIMIT 10 OFFSET 0

-- 第 2 页：跳过前 10 条
SELECT * FROM products
ORDER BY id ASC
LIMIT 10, 10;

-- 第 N 页的通式
SELECT * FROM products
ORDER BY id ASC
LIMIT (N-1)*10, 10;
```

## 分页 + 排序

分页几乎总是需要配合排序一起使用，确保分页结果稳定：

```sql
-- 第 3 页，每页 20 条
SELECT id, name, price
FROM products
ORDER BY id ASC
LIMIT 20 OFFSET 40;
```

- 关键词顺序：FROM -> WHERE -> ORDER BY -> LIMIT。

## 分页 + 总数查询

分页器要展示「第几页 / 共几页」，还需要查询总条数：

```sql
SELECT COUNT(*) FROM products WHERE category = '电子产品';
```

用总数和 pageSize 算出总页数，返回给前端展示。
