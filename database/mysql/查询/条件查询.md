# 条件查询

*类型：knowledge ｜ 难度：基础 ｜ 标签：MySQL、WHERE、SQL ｜ 更新：2026-09-22*

**WHERE 子句负责过滤数据，只返回满足条件的行，是 SELECT、UPDATE、DELETE 中最核心的部分：比较运算与逻辑组合（AND / OR / NOT）处理单值条件，IN 处理多值匹配，BETWEEN 处理含边界的范围，LIKE 用 % 与 _ 做模糊匹配，IS NULL / IS NOT NULL 是判空的唯一正确方式。判空不能用 = NULL，因为与 NULL 的任何比较结果都是 NULL，行不会被返回。**

## 基本语法

```sql
SELECT 字段列表
FROM 表名
WHERE 条件;
```

## 示例数据

users 表：

| id | name | age | gender |
| --- | --- | --- | --- |
| 1 | 张三 | 25 | male |
| 2 | 李四 | 30 | female |
| 3 | 王五 | 22 | male |
| 4 | 赵六 | 28 | female |

## 常见条件写法

### 基础条件

```sql
-- 返回年龄大于 25 岁的用户
SELECT * FROM users
WHERE age > 25;
```

### 多条件查询（AND / OR）

```sql
-- 多个条件必须都满足（AND）或满足其一（OR）
SELECT * FROM users
WHERE age > 20 AND gender = 'male';
```

### IN：匹配多个值

```sql
SELECT * FROM users
WHERE name IN ('张三', '王五');
```

### BETWEEN：范围查询

```sql
-- 包含边界：20 <= age <= 28
SELECT * FROM users
WHERE age BETWEEN 20 AND 28;
```

### LIKE：模糊匹配

```sql
-- % 表示任意长度的任意字符
SELECT * FROM users
WHERE name LIKE '张%';
```

### IS NULL / IS NOT NULL

```sql
-- 判断字段是否为空值，这是唯一正确的判空方式
SELECT * FROM users
WHERE gender IS NOT NULL;
```

### NOT：逻辑取反

```sql
-- 等价于 age >= 25
SELECT * FROM users
WHERE NOT (age < 25);
```

## WHERE 的适用范围

WHERE 不只用于查询，也用于限定更新和删除的范围：

| 类型 | 示例 |
| --- | --- |
| SELECT | 过滤查询结果 |
| UPDATE | 限定更新范围 |
| DELETE | 限定删除范围 |

```sql
DELETE FROM users WHERE age < 18;

UPDATE users SET age = age + 1 WHERE gender = 'male';
```
