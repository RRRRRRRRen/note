# 函数

*类型：knowledge ｜ 难度：基础 ｜ 标签：MySQL、函数、GROUP BY ｜ 更新：2026-09-22*

**MySQL 函数按处理对象分为字符串、数值、日期时间、控制流、聚合等类别；其中聚合函数（COUNT/SUM/AVG/MAX/MIN）是分水岭——它们作用于分组后的整组数据，必须搭配 GROUP BY 使用，而过滤聚合结果要用 HAVING（WHERE 在分组前过滤行、不能用聚合函数）。另两个高频坑：COUNT(*) 统计行数含 NULL，COUNT(列) 忽略 NULL；LENGTH 数字节、CHAR_LENGTH 数字符，中文场景用后者。**

## 字符串函数

| 函数名 | 说明 | 示例 |
| --- | --- | --- |
| CONCAT(a, b, ...) | 字符串拼接 | CONCAT('Hello', 'World') -> HelloWorld |
| LENGTH(str) | 字节长度 | LENGTH('abc') -> 3 |
| CHAR_LENGTH(str) | 字符长度（中文场景推荐） | CHAR_LENGTH('你好') -> 2 |
| LOWER(str) | 转小写 | LOWER('AbC') -> abc |
| UPPER(str) | 转大写 | UPPER('AbC') -> ABC |
| TRIM(str) | 去除前后空格 | TRIM(' abc ') -> 'abc' |
| LEFT(str, n) | 从左取 n 位 | LEFT('hello', 2) -> he |
| RIGHT(str, n) | 从右取 n 位 | RIGHT('hello', 3) -> llo |
| SUBSTRING(str, start, len) | 截取子串 | SUBSTRING('abcdef', 2, 3) -> bcd |
| REPLACE(str, a, b) | 替换字符串 | REPLACE('abcabc', 'a', 'x') -> xbcxbc |
| INSTR(str, substr) | 查找子串位置 | INSTR('hello', 'e') -> 2 |

```sql
-- LENGTH 返回字节数：emoji 占 4 字节，utf8 下一个汉字占 3 字节
SELECT LENGTH('😄') FROM DUAL;  -- 4
SELECT LENGTH('abc') FROM DUAL; -- 3
SELECT LENGTH('我们') FROM DUAL; -- 6

-- CONCAT 拼接字段
SELECT CONCAT(first_name, ' ', last_name) AS fullName
FROM employees;

-- CONCAT_WS 用指定符号连接
SELECT CONCAT_WS('_', first_name, last_name) AS fullName
FROM employees;

-- LOWER 做忽略大小写的筛选（MySQL 默认比较本身大小写不敏感）
SELECT last_name
FROM employees
WHERE LOWER(last_name) = 'king';
```

## 控制流函数

在 SQL 语句中做条件判断与分支处理，适用于条件列展示、动态赋值等场景。

| 函数名 | 说明 | 示例 |
| --- | --- | --- |
| IF(cond, t, f) | cond 为真返回 t，否则返回 f | IF(1 < 2, 'yes', 'no') -> yes |
| IFNULL(expr, alt) | expr 为 NULL 返回 alt | IFNULL(NULL, 'N/A') -> N/A |
| NULLIF(a, b) | a = b 返回 NULL，否则返回 a | NULLIF(1,1) -> NULL；NULLIF(1,2) -> 1 |
| CASE WHEN ... END | 多条件判断 | 见下 |

```sql
-- IF：类似三目运算符 condition ? a : b
SELECT name,
       IF(score >= 60, '及格', '不及格') AS result
FROM students;

-- IFNULL：处理 NULL 值展示
SELECT name,
       IFNULL(nickname, '无昵称') AS display_name
FROM users;

-- 简单 CASE：按字段值分支
SELECT name,
       CASE gender
         WHEN 'M' THEN '男'
         WHEN 'F' THEN '女'
         ELSE '未知'
       END AS gender_text
FROM employees;

-- 搜索 CASE：按条件分支
SELECT name, score,
       CASE
         WHEN score >= 90 THEN '优秀'
         WHEN score >= 60 THEN '及格'
         ELSE '不及格'
       END AS result
FROM students;
```

## 聚合函数

对一列数据做汇总计算，常用于 GROUP BY 分组、统计分析、报表场景。

| 函数名 | 作用 |
| --- | --- |
| COUNT() | 统计数量 |
| SUM() | 求和 |
| AVG() | 平均值 |
| MAX() / MIN() | 最大值 / 最小值 |
| GROUP_CONCAT() | 同组数据拼接成字符串 |

### COUNT / SUM / AVG / MAX / MIN

```sql
SELECT COUNT(*) FROM employees;
-- COUNT(*)：统计总行数（包括 NULL）
-- COUNT(column)：统计该列非 NULL 的数量，会忽略 NULL 行
SELECT COUNT(salary) FROM employees;

-- SUM 求和，NULL 被忽略
SELECT SUM(salary) FROM employees;

-- AVG 平均值（= SUM / COUNT），NULL 被忽略
SELECT AVG(salary) FROM employees;

-- MAX / MIN 适用于数值、字符串、日期时间类型
SELECT MAX(salary), MIN(salary) FROM employees;
```

### 配合 GROUP BY 分组

```sql
-- 每个部门的平均薪资
SELECT department_id, AVG(salary)
FROM employees
GROUP BY department_id;

-- 多个分组条件：每个部门中每个岗位的平均薪资
SELECT department_id, job_id, AVG(salary)
FROM employees
GROUP BY department_id, job_id;
```

注意事项：

- 支持多维度分组。
- SELECT 中出现未包含在 GROUP BY 里的字段会报错。
- GROUP BY 字段的顺序不影响结果，只影响中间过程的分组方式。

### GROUP_CONCAT 分组拼接

```sql
-- 把同一部门的员工名字拼接起来，默认逗号分隔
SELECT department_id, GROUP_CONCAT(last_name)
FROM employees
GROUP BY department_id;

-- 自定义分隔符
SELECT department_id, GROUP_CONCAT(last_name SEPARATOR ' | ')
FROM employees
GROUP BY department_id;
```

- 有最大长度限制，默认 1024 字节，可调整：

```sql
SET SESSION group_concat_max_len = 10000;
```

### HAVING 过滤分组

```sql
SELECT department_id,
       COUNT(*) AS num_employees,
       SUM(salary) AS total_salary,
       AVG(salary) AS avg_salary
FROM employees
GROUP BY department_id
HAVING total_salary > 100000;
```

- 过滤条件中使用了聚合函数时，必须用 HAVING 而不是 WHERE。
- HAVING 必须放在 GROUP BY 之后，通常与 GROUP BY 成对出现。
- 极不推荐把普通过滤条件写进 HAVING，普通条件应保持用 WHERE 过滤。

### WHERE 对比 HAVING

- WHERE 在分组/聚合之前过滤行；HAVING 在分组/聚合之后过滤组。

```sql
SELECT department_id, COUNT(*) AS emp_count
FROM employees
WHERE salary > 5000             -- 先筛选行（此时还不能用聚合函数）
GROUP BY department_id
HAVING emp_count > 3;           -- 再筛选组（可以使用聚合结果）
```
