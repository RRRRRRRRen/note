# 排序

*类型：knowledge ｜ 难度：基础 ｜ 标签：MySQL、ORDER BY、SQL ｜ 更新：2026-09-22*

**ORDER BY 对查询结果排序，ASC 升序（默认）、DESC 降序，可按多列、别名、表达式排序。执行顺序上它位于 SELECT 之后，因此可以使用 SELECT 里定义的别名（WHERE 则不行）；MySQL 中升序时 NULL 排最前、降序排最后，需要固定 NULL 位置要用 ISNULL 或 CASE 手动控制。排序是典型的资源消耗操作，先筛选再排序，表达式排序无法使用索引。**

## 基础语法

ORDER BY 用来对查询结果排序，默认升序。

```sql
SELECT column1, column2
FROM table_name
ORDER BY column1 [ASC|DESC], column2 [ASC|DESC], ...;
```

- WHERE 需要声明在 FROM 之后、ORDER BY 之前。

## 升序与降序

| 关键词 | 说明 |
| --- | --- |
| ASC | 升序（默认） |
| DESC | 降序 |

```sql
-- 按价格升序
SELECT * FROM products
ORDER BY price;

-- 按价格降序
SELECT * FROM products
ORDER BY price DESC;

-- 先按价格降序，价格相同时再按库存升序
SELECT * FROM products
ORDER BY price DESC, stock ASC;
```

## 使用别名排序

列的别名只能在 ORDER BY 中使用，不能在 WHERE 中使用。

```sql
SELECT name, price * 10 total, stock
FROM products
ORDER BY total DESC;
```

## 多列排序

- 多个排序条件用逗号隔开。
- 先按第一列排序，只有第一列值相同时才会按第二列排序；若第一列值全部唯一，第二列排序不会生效。

```sql
SELECT name, price * 10 total, stock
FROM products
ORDER BY total DESC, stock;
```

## 配合函数与表达式排序

可以直接在排序中使用表达式、函数：

```sql
-- 按折扣价排序（price * 0.9）
SELECT *, price * 0.9 AS discount_price
FROM products
ORDER BY discount_price ASC;

-- 按名称长度排序
SELECT * FROM products
ORDER BY LENGTH(name) DESC;
```

## NULL 值的排序位置

默认排序时 NULL 的位置依数据库而异，在 MySQL 中：

- 升序：NULL 排最前面。
- 降序：NULL 排最后面。

手动控制 NULL 排在最后：

```sql
-- 将 NULL 视为最大值，排在最后
ORDER BY ISNULL(some_column), some_column ASC;

-- 或者用 CASE 显式标记
ORDER BY CASE WHEN some_column IS NULL THEN 1 ELSE 0 END, some_column;
```

## 结合 LIMIT

```sql
-- 查询价格最高的前 3 个商品
SELECT * FROM products
ORDER BY price DESC
LIMIT 3;

-- 每页 10 条，取第 2 页
SELECT * FROM products
ORDER BY id ASC
LIMIT 10 OFFSET 10;
```

## 注意事项

- 未使用排序时，查询结果默认按数据添加顺序显示（不应依赖这一行为）。
- 大结果集排序很耗资源：最好先 WHERE 筛选、再 LIMIT 截取，最后排序。
- 对文本字段做 `LIKE '%xx%'` 再排序的性能极差，应避免。
- 排序字段如果是表达式或函数，无法使用该列的索引。
