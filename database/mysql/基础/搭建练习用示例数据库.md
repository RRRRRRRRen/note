# 搭建练习用示例数据库

*类型：practice ｜ 难度：入门 ｜ 标签：MySQL、环境搭建、练习数据 ｜ 更新：2026-09-22*

**练习 SQL 需要一个可控的数据环境：小场景用自建的 dbtest 库（一张 employees 表即可跑通建库、建表、插入、查询的完整流程）；要练多表连接、聚合、排序，就导入开源的 test_db（employees 示例库，含部门、员工、薪资等多张关联表，数据量足够支撑真实查询）。**

## 准备：连接 MySQL

```shell
# 将 mysql 客户端加入 PATH（macOS 官方安装包默认位于 /usr/local/mysql/bin）
export PATH=${PATH}:/usr/local/mysql/bin

# 登录：-p 后可不明文写密码，回车后按提示输入
mysql -uroot -pmysql123456
# 等价于显式指定主机与端口
mysql -u root -P 3306 -h localhost -pmysql123456

# 验证版本
select version();
```

## 创建测试库 dbtest

```sql
-- 创建一个名为 dbtest 的数据库
create database dbtest;

-- 使用 dbtest 数据库
use dbtest;

-- 创建一个叫做 employees 的表，并设置两个字段
create table employees(id int, name varchar(15));

-- 插入数据
insert into employees values (1001, 'tom');
insert into employees values (1002, '张伟');

-- 查询数据
select * from employees;
```

## 导入开源测试数据库 test_db

```shell
# 克隆开源数据项目
git clone git@github.com:datacharmer/test_db.git

# 进入文件夹
cd ~/Github/test_db

# 导入数据（-t 表示以表格形式输出执行过程）
mysql -t -uroot -p < employees.sql
```

## 验证导入结果

```sql
use employees;

-- 应能看到 departments、dept_emp、employees、salaries 等表
show tables;

-- 确认数据量
select count(*) from employees;
```

## 认识四个系统库

登录后执行 `show databases;`，除了自建的库，还能看到四个系统库：

```text
+--------------------+
| Database           |
+--------------------+
| information_schema |
| mysql              |
| performance_schema |
| sys                |
+--------------------+
```

| 数据库 | 类型 | 用途 | 是否可删 |
| --- | --- | --- | --- |
| information_schema | 虚拟库 | 提供数据库元数据，可查询所有库的表、列、索引、视图、权限等结构信息 | 不可删 |
| mysql | 实体库 | 核心系统信息：系统账户、权限、系统设置 | 不可删 |
| performance_schema | 实体库 | 性能统计与监控数据 | 不可删（可选择不开启） |
| sys | 虚拟视图 | 对 performance_schema 的友好封装，让性能数据更易读 | 不可删 |

- information_schema 是虚拟库，里面没有真实的表数据，只是结构信息的视图。
