# 数据的增删改

*类型：practice ｜ 难度：基础 ｜ 标签：MySQL、DML、INSERT、UPDATE、DELETE ｜ 更新：2026-09-22*

**数据的增删改由 INSERT / UPDATE / DELETE 三个 DML 语句承担：INSERT 推荐显式指明字段名（省略字段名会绑定列顺序，改表即出错），批量插入用多值 VALUES，冲突处理按需选 IGNORE（跳过）、REPLACE INTO（删旧插新）或 ON DUPLICATE KEY UPDATE（转更新）；UPDATE 和 DELETE 必须带 WHERE，否则作用全表，改前先用 SELECT 确认影响范围、必要时套事务。DML 在提交前都可以 ROLLBACK，这是它们与 DDL 的本质区别。**

## 插入数据（INSERT）

### 基本语法

方式一：不指明字段。

```sql
INSERT INTO 表名 VALUES (值1, 值2, ...);

INSERT INTO users VALUES (1, '张三', 25);
```

- 必须按声明字段的顺序添加值。
- 不推荐省略字段名：字段顺序改变时容易出错。

方式二：指明字段（推荐）。

```sql
INSERT INTO 表名 (字段1, 字段2, ...) VALUES (值1, 值2, ...);

INSERT INTO users (id, name, age) VALUES (1, '张三', 25);
```

- 未指定的字段按约束和默认值处理。

### 批量插入多条数据

```sql
INSERT INTO users (id, name, age) VALUES
(3, '王五', 28),
(4, '赵六', 22),
(5, '钱七', 35);
```

### 将查询结果插入

```sql
INSERT INTO new_users (id, name, age)
SELECT id, name, age FROM users WHERE age > 30;
```

- 查询结果的字段数量必须与目标字段一一对应。
- 需确认数据类型和范围，防止溢出或截断。

### 处理重复（主键 / 唯一键冲突）

```sql
-- 1. INSERT IGNORE：冲突时跳过这一行，其他行继续插入
INSERT IGNORE INTO users (id, name, age) VALUES (1, '重复', 20);

-- 2. REPLACE INTO：冲突时先删除旧数据再插入新数据（会触发删除和插入）
REPLACE INTO users (id, name, age) VALUES (1, '替换', 26);

-- 3. ON DUPLICATE KEY UPDATE：冲突时转为更新指定字段
INSERT INTO users (id, name, age)
VALUES (1, '张三', 25)
ON DUPLICATE KEY UPDATE age = 26;
```

### 显式指定 DEFAULT 与 NULL

```sql
INSERT INTO users (id, name, age) VALUES (6, '吴九', DEFAULT);
INSERT INTO users (id, name, age) VALUES (7, '郑十', NULL);
```

## 更新数据（UPDATE）

### 语法格式

```sql
UPDATE 表名
SET 字段1 = 新值1, 字段2 = 新值2, ...
[WHERE 条件];
```

- 更新可能因约束存在而不成功。

### 基本使用

```sql
UPDATE users
SET age = 28
WHERE name = '张三';

-- 同时更新多个字段
UPDATE users
SET name = '李四', age = 30
WHERE id = 1;
```

### WHERE 条件的重要性

```sql
-- 没有 WHERE 会更新全表：所有用户的 age 全部变为 0
UPDATE users
SET age = 0;
```

- 一定要加 WHERE 限定条件。
- 最好先用 SELECT 查询确认将被影响的行。
- 复杂修改前考虑套事务（START TRANSACTION），确认无误再 COMMIT。

### 特殊更新方法

```sql
-- 基于原值更新
UPDATE users
SET age = age + 1
WHERE id = 1;

-- 结合条件更新多条记录
UPDATE users
SET age = age + 2
WHERE age < 25 AND name LIKE '张%';

-- 配合 ORDER BY 和 LIMIT：定向修改最早的 3 条
UPDATE users
SET age = age + 1
ORDER BY created_at
LIMIT 3;

-- 结合子查询更新
UPDATE users
SET age = (
  SELECT AVG(age) FROM users
)
WHERE id = 1;
```

## 删除数据（DELETE）

```sql
DELETE FROM 表名 WHERE 条件;

-- 只删除 id = 3 的那一行
DELETE FROM users WHERE id = 3;

-- 不加 WHERE 将删除表中所有数据，但表结构保留
DELETE FROM users;
```

- DELETE 是 DML，未提交前可以回滚。
- 清空全表且不需要回滚时，TRUNCATE 更快（区别见「管理数据表」）。

## 计算列（MySQL 8 特性）

计算列（生成列，Generated Columns）由其他字段计算得出，建表时定义好表达式，MySQL 自动维护，无需手动更新。

```sql
列名 数据类型 [GENERATED ALWAYS] AS (表达式) [VIRTUAL | STORED] [UNIQUE | NOT NULL | ...]
```

### VIRTUAL（虚拟列，默认）

不存储，只在读取时动态计算：

```sql
CREATE TABLE products (
  name VARCHAR(50),
  price DECIMAL(10,2),
  quantity INT,
  total_cost DECIMAL(12,2) AS (price * quantity) VIRTUAL
);
```

### STORED（持久列）

计算后存储在磁盘上，提高查询性能：

```sql
CREATE TABLE users (
  first_name VARCHAR(20),
  last_name VARCHAR(20),
  full_name VARCHAR(50) AS (CONCAT(first_name, ' ', last_name)) STORED
);
```

### 给已有表添加计算列

```sql
ALTER TABLE users
ADD full_name VARCHAR(50) AS (CONCAT(first_name, ' ', last_name)) STORED;
```

### 注意事项

- VIRTUAL 一般不能建索引（主键 / 唯一键除外），STORED 可以建索引。
- 生成列不能引用其他生成列（不能套娃）。
- 表达式不能包含子查询、变量及 RAND()、NOW() 等不确定函数。
- VIRTUAL 不占空间但读取时计算开销大，STORED 占空间但读取快；STORED 列在插入或更新行时自动计算并存储。
