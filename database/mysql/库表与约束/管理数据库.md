# 管理数据库

*类型：practice ｜ 难度：基础 ｜ 标签：MySQL、DDL、数据库管理 ｜ 更新：2026-09-22*

**数据库管理是一组 DDL 命令的固定套路：CREATE / SHOW / USE / ALTER / DROP 分别负责建、查、选、改、删。两条实践铁律——创建与删除都带上 IF NOT EXISTS / IF EXISTS 防止报错中断脚本；建库时显式指定 CHARACTER SET（推荐 utf8mb4），避免依赖服务器默认字符集留下乱码隐患。DDL 不可回滚，DROP 前务必确认。**

## 创建数据库

```sql
CREATE DATABASE database_name;
```

指定字符集和排序规则：

```sql
CREATE DATABASE my_database
    CHARACTER SET utf8
    COLLATE utf8_general_ci;
```

- CHARACTER SET 指定字符集（如 utf8）。
- COLLATE 指定排序规则（如 utf8_general_ci）。

最佳实践：

```sql
-- 判断数据库是否存在：存在则不创建且不报错，不存在则创建
CREATE DATABASE
IF NOT EXISTS my_database
CHARACTER SET utf8;
```

## 查看数据库

```sql
-- 查看所有数据库的列表
SHOW DATABASES;

-- 查看指定数据库的创建信息（字符集设置等）
SHOW CREATE DATABASE my_database;
```

## 选择数据库

```sql
USE my_database;
```

## 查看当前使用的数据库

```sql
SELECT DATABASE() FROM DUAL;
```

## 查看数据表

```sql
-- 当前数据库的数据表
SHOW TABLES;

-- 指定数据库的数据表
SHOW TABLES FROM my_database;
```

## 修改数据库

```sql
-- 修改数据库字符集
ALTER DATABASE my_database CHARACTER SET 'utf8';
```

## 查看字符集与排序规则

查看当前数据库相关字符集：

```sql
show variables like 'character_%';
```

```text
+--------------------------+-------------------------------------------------------+
| Variable_name            | Value                                                 |
+--------------------------+-------------------------------------------------------+
| character_set_client     | utf8mb4                                               |
| character_set_connection | utf8mb4                                               |
| character_set_database   | utf8mb4                                               |
| character_set_filesystem | binary                                                |
| character_set_results    | utf8mb4                                               |
| character_set_server     | utf8mb4                                               |
| character_set_system     | utf8mb3                                               |
| character_sets_dir       | /usr/local/mysql-8.0.41-macos15-arm64/share/charsets/ |
+--------------------------+-------------------------------------------------------+
```

查看比较规则（排序规则）：

```sql
show variables like 'collation_%';
```

```text
+----------------------+--------------------+
| Variable_name        | Value              |
+----------------------+--------------------+
| collation_connection | utf8mb4_0900_ai_ci |
| collation_database   | utf8mb4_0900_ai_ci |
| collation_server     | utf8mb4_0900_ai_ci |
+----------------------+--------------------+
```

版本差异：

- 8.0 默认使用 utf8mb4，无需手动设置
- 5.7 默认使用 latin1，需要手动修改字符集设置，否则中文会乱码

## 删除数据库

```sql
-- 基础语法：数据库存在则删除
DROP DATABASE my_database;

-- 推荐做法：存在才删除，不存在不报错
DROP DATABASE IF EXISTS my_database;
```

- DROP 是 DDL，立即生效且不可回滚，生产环境慎用。

## 登录数据库

```shell
mysql -uroot -pmysql123456
# 等价于显式指定主机与端口
mysql -u root -P 3306 -h localhost -pmysql123456
```

- -p 后可以不明文写入密码，回车后根据提示输入密码。
