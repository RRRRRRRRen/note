# 管理数据表

*类型：practice ｜ 难度：基础 ｜ 标签：MySQL、DDL、表结构 ｜ 更新：2026-09-22*

**表结构管理围绕 CREATE / DESC / ALTER / RENAME / DROP / TRUNCATE 六个命令展开：字段的增改删改全走 ALTER TABLE（ADD / MODIFY / CHANGE / DROP COLUMN 四个关键字各有分工——MODIFY 只改类型不改名，CHANGE 改名并可顺便改类型）；清空表用 TRUNCATE 而不是无 WHERE 的 DELETE——它是重建表级别的操作，快但不可回滚、不触发触发器、还会把自增值重置为 1。**

## 创建数据表

方式 1：创建新表。

```sql
CREATE TABLE IF NOT EXISTS test_table (
  id INT,
  emp_name VARCHAR(15),
  hire_date DATE
);
```

方式 2：基于现有表创建，同时导入数据。

```sql
CREATE TABLE test_table
AS
SELECT employee_id a, last_name b
FROM employees;
```

- 用 SELECT 的结果作为新表的数据填充。
- SELECT 中使用别名时，新表会用别名作为字段名。
- 创建表时可以指定表的字符集或字段的字符集。

## 查看表结构

```sql
DESC test_table;
```

## 修改表（ALTER TABLE）

| 操作 | 语法关键词 | 说明 |
| --- | --- | --- |
| 添加字段 | ADD COLUMN | 新增一个字段 |
| 修改字段类型 | MODIFY COLUMN | 改字段类型或约束，不改名 |
| 重命名字段 | CHANGE COLUMN | 改字段名，可以顺便改类型 |
| 删除字段 | DROP COLUMN | 删除指定字段 |

### 添加字段

```sql
ALTER TABLE 表名 ADD COLUMN 字段名 数据类型 [约束] [位置];
```

- 位置可选：FIRST 添加到最前面；AFTER 某字段名添加到指定字段之后。

```sql
ALTER TABLE users
ADD COLUMN age INT
AFTER username;

ALTER TABLE users
ADD COLUMN created_at DATETIME
DEFAULT CURRENT_TIMESTAMP;
```

### 修改字段类型

```sql
ALTER TABLE 表名 MODIFY COLUMN 字段名 新数据类型 [约束];
```

```sql
ALTER TABLE users MODIFY COLUMN age TINYINT UNSIGNED NOT NULL;
```

### 重命名字段

```sql
ALTER TABLE 表名 CHANGE COLUMN 原字段名 新字段名 新数据类型 [约束];
```

- 必须提供新字段名和完整的数据类型。
- 可以同时修改字段名和字段类型。

```sql
ALTER TABLE users CHANGE COLUMN username user_name VARCHAR(100) NOT NULL;
```

### 删除字段

```sql
ALTER TABLE users DROP COLUMN age;
```

## 重命名表

```sql
-- 语法 1
RENAME TABLE 原表名 TO 新表名;

-- 语法 2
ALTER TABLE 原表名 RENAME TO 新表名;
```

```sql
RENAME TABLE users TO members;

-- 或者
ALTER TABLE users RENAME TO members;
```

- 重命名不影响表的数据或结构。
- 重命名后，所有依赖旧表名的 SQL（如外部查询）需要修改。
- 新表名已存在时，重命名会失败。

## 删除表

```sql
DROP TABLE users;

-- 不确定表是否存在时，加上 IF EXISTS
DROP TABLE IF EXISTS users;
```

- 表和数据会被永久删除、不可恢复，慎用。

## 清空表（TRUNCATE）

```sql
TRUNCATE TABLE users;
```

与 DELETE 的区别：

| 特点 | 说明 |
| --- | --- |
| 高速 | TRUNCATE 是重新创建表，删除速度比 DELETE 快 |
| 无日志 | 不记录逐行删除操作，几乎不可恢复 |
| 无触发器 | 不会触发 DELETE 触发器 |
| 自增重置 | AUTO_INCREMENT 的值重置为初始值（通常是 1） |
| 无条件 | 不能带 WHERE，清空就是全部清空 |
