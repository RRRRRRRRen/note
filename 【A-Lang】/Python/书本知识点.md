# 书本知识点

## 字符串

### 引号

字符串支持单引号和双引号，两者等价，可根据内容灵活选择以避免转义。

### f-string 格式化

`f"{}"` 在字符串中嵌入变量或表达式：`print(f"{name} is {age + 1} next year")`。

### 常用方法

- `.title()`：每个单词首字母大写
- `.upper()` / `.lower()`：大小写转换
- `.strip()` / `.rstrip()` / `.lstrip()`：去除两端 / 右侧 / 左侧空白
- `.removeprefix(prefix)`：移除指定前缀（Python 3.9+）

## 数字与运算

### 算数运算符

- `+ - * / **`，其中 `**` 表示幂运算
- 任意两数相除（`/`）结果恒为浮点数
- 操作数中含浮点数则结果为浮点数

### 求模运算符

`%` 返回两数相除的余数：`5 % 2` 结果为 `1`。

### 增强赋值运算符

`+=` `-=` `*=` `/=`：先运算再赋值给自身，`count += 1` 等价于 `count = count + 1`。

### 数字分位

下划线作为数字分隔符提升可读性，不影响数值：`big_num = 1_000_000`。

### 常量约定

Python 无内置常量机制，习惯用全大写加下划线表示常量：`MAX_CONNECTIONS = 100`。

### 类型转换

`int()` 将字符串或浮点数转为整数，失败则报错：`int("42")` → `42`，`int(3.14)` → `3`。

## 变量与注释

### 多变量赋值

逗号分隔同时赋值：`x, y, z = 1, 2, 3`。

### 注释

`#` 表示单行注释，可独立成行或写在行尾。

## 列表

### 声明与访问

方括号 `[]` 声明，支持正向索引（`0` 开始）和负向索引（`-1` 开始）。

### 常用方法

- `.append(x)`：末尾添加元素
- `.insert(i, x)`：指定位置插入元素
- `del list[i]`：删除指定索引元素（无返回值）
- `.pop(i)`：弹出并返回元素，默认弹出最后一个
- `.remove(x)`：删除第一个匹配值（仅删第一个）
- `.sort()`：原地排序，修改原列表，返回 `None`
- `sorted(list)`：返回排序后的新列表，不修改原列表
- `.reverse()`：反转列表
- `len(list)`：返回列表长度

`del` 直接删除无返回值，`pop` 删除的同时返回该元素可继续使用。

`sort()` 与 `sorted()` 均支持 `reverse=True` 倒序。

### 列表推导式

一行完成循环与列表创建，可附加条件过滤：

- `[x**2 for x in range(1, 6)]` — 生成平方列表
- `[x for x in range(10) if x % 2 == 0]` — 带过滤条件

### 切片

语法 `list[start:stop:step]`，左闭右开。

- `nums[1:4]` — 区间切片
- `nums[::2]` — 步长切片
- `nums[::-1]` — 反转
- `nums[:]` — 创建副本（避免引用共享）

## 循环与遍历

### for 循环

`for item in iterable:` 遍历可迭代对象，循环体缩进表示。

### range 生成序列

- `range(stop)`：`0` 到 `stop-1`
- `range(start, stop)`：`start` 到 `stop-1`
- `range(start, stop, step)`：指定步长

### while 循环

条件为真时持续执行：`while n > 0: n -= 1`。

### break 与 continue

- `break`：立即退出当前循环
- `continue`：跳过本轮剩余代码，进入下一轮

### 数值统计

`min(list)` / `max(list)` / `sum(list)` 分别返回最小值、最大值、求和。

## 元组

元组是不可变序列，`()` 声明：`t = (1, 2, 3)`。支持索引和切片，不支持修改。

### 单元素元组

单元素元组须加逗号：`(1,)` 是元组，`(1)` 是整数。

## 代码规范

### PEP 8

- 4 空格缩进，禁用制表符
- 每行不超过 80 字符
- 注释不超过 72 字符

## 条件判断

### 比较运算符

`==` / `!=`（相等 / 不等），`>` / `<` / `>=` / `<=`（大小比较）。

### 逻辑运算符

- `and` / `or`：逻辑与 / 或
- `in` / `not in`：成员检测

### 条件语句

`if` / `if else` / `if elif else` 三种结构。

### 假值判断

以下值在条件中视为 `False`：`0`、`''` / `""`、`[]` / `()` / `{}`、`None`。其他一切为真。

## 字典

### 基本操作

`{}` 声明，键值对 `key: value` 分隔。可直接 `dict[key] = value` 新增或修改，`del dict[key]` 删除。Python 3.7+ 保留插入顺序。

### 访问

- `dict[key]`：直接访问，键不存在报错
- `dict.get(key, default)`：安全访问，键不存在返回默认值（默认 `None`）

### 遍历

- `for k in d` 或 `d.keys()`：遍历键
- `d.values()`：遍历值
- `for k, v in d.items()`：遍历键值对

## 集合

`set(iterable)` 或 `{elem1, elem2}` 创建。自动去重，无序存储。

## 函数

### 函数定义

`def` 定义函数，函数体缩进表示。首行可用 `"""..."""` 编写文档字符串，通过 `help()` 或 `.__doc__` 查看。

```python
def greet(name):
    """返回问候语"""
    return f"Hello, {name}!"
```

### 实参传递

- **位置实参**：按参数顺序一一对应，顺序不可颠倒 — `greet("Tom")`
- **关键字实参**：按参数名传值，顺序无关，须在位置实参之后 — `greet(name="Tom")`

### 列表参数保护

传递列表副本防止原列表被修改：`process_list(my_list[:])` 而非 `process_list(my_list)`。

### 任意数量实参

- `*args`：接收任意数量位置实参，在函数内部为元组 — `def fn(*args):`
- `**kwargs`：接收任意数量关键字实参，在函数内部为字典 — `def fn(**kwargs):`

```python
def make_pizza(*toppings):
    """*toppings 收集所有位置实参为元组"""
    for t in toppings:
        print(f"- {t}")

make_pizza("mushrooms", "pepperoni", "cheese")
```

## 类

### 类定义

`class` 关键字定义类，类名使用大驼峰命名法（PascalCase）。`__init__` 为初始化方法，每次创建实例时自动调用；`self` 指向实例本身，属性通过 `self.属性名` 定义。

```python
class Dog:
    """一次模拟小狗的简单尝试"""

    def __init__(self, name, age):
        self.name = name   # 实例属性
        self.age = age

    def sit(self):
        print(f"{self.name} is now sitting.")
```

### 继承与方法重写

子类继承父类：`class Child(Parent):`。子类定义与父类同名方法即可覆盖父类实现。

`super()` 在子类中调用父类方法，常用于 `__init__` 复用初始化逻辑：

```python
class ElectricCar(Car):
    def __init__(self, make, model, year, battery_size=75):
        super().__init__(make, model, year)   # 调用父类 __init__
        self.battery_size = battery_size
```

### 编码风格

- 类名大驼峰：`ElectricCar`
- 类内方法间一个空行分隔
- 模块中类之间两个空行分隔

## 模块与导入

### import 基本语法

- `import 模块` — 导入模块，调用需前缀：`import math` → `math.sqrt(16)`
- `from 模块 import 名称` — 导入特定函数或类，无需前缀：`from math import sqrt, ceil`

### 别名与批量导入

- `as` 给模块或名称设置别名：`import numpy as np`、`from math import sqrt as sq`
- `from 模块 import *` 导入所有公开名称，可能污染命名空间，不推荐

### 模块级文档字符串

模块文件顶部、`import` 之前使用 `"""..."""` 编写模块文档字符串，描述模块用途。

### 导入类

`from car import Car, ElectricCar` 导入类，`from car import ElectricCar as EC` 给类设置别名。导入语法对函数和类通用。

## 异常处理

### try-except 结构

`try` 块编写可能出错的代码，`except` 捕获指定异常类型。`else` 块在无异常时执行，`pass` 静默忽略错误。

```python
try:
    num = int(input("输入数字: "))
except ValueError:
    print("输入无效")
else:
    print(f"你输入了: {num}")      # 仅无异常时执行
```

`except FileNotFoundError: pass` 可静默跳过文件不存在的情况。

## 文件与路径

### Path 对象

`from pathlib import Path`。相对路径 `Path("data/note.txt")`，绝对路径 `Path("/Users/ren/note.txt")`。

`path.exists()` 检查路径是否存在，返回布尔值：`if path.exists(): content = path.read_text()`。

### 读写文件

- `path.read_text()`：读取全部内容为字符串，文件不存在则报错
- `path.write_text(str)`：写入字符串，文件不存在则自动创建，已存在则覆盖

读取后可配合 `content.splitlines()` 按行分割为列表，或用 `"keyword" in content` 检查子串。

## JSON 数据处理

- `json.dumps(obj)`：Python 对象序列化为 JSON 字符串 — `json.dumps({"name": "Tom"})`
- `json.loads(str)`：JSON 字符串反序列化为 Python 对象 — `json.loads('{"name": "Tom"}')`
