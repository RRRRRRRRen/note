# 书本知识点

## 字符串

### 引号

字符串支持单引号和双引号，两者等价，可根据内部内容灵活选择以避免转义。

### f-string 格式化

使用 `f"{}"` 可以在字符串中嵌入变量或表达式。

```python
print(f"{name} is {age + 1} next year")
```

### 常用方法

- `.title()`：每个单词首字母大写
- `.upper()` / `.lower()`：大小写转换
- `.strip()` / `.rstrip()` / `.lstrip()`：去除两端/右侧/左侧空白
- `.removeprefix()`：移除指定前缀（Python 3.9+）

## 数字与运算

### 算数运算符

- `+ - * / **`，其中 `**` 表示幂运算
- 任意两个数相除（`/`）结果都是浮点数
- 只要操作数中包含浮点数，结果就是浮点数

### 数字分位

可以使用下划线给数字做分位，提升可读性，下划线不影响实际数值。

```python
big_num = 1_000_000
```

### 常量约定

- Python 没有内置的常量机制
- 习惯使用全大写加下划线的命名表示常量，如 `MAX_CONNECTIONS`

### 求模运算符

`%` 返回两数相除的余数。

```python
5 % 2   # 1
```

### 增强赋值运算符

- `+=`、`-=`、`*=`、`/=`：先运算再赋值给自身

```python
count += 1   # 等价于 count = count + 1
```

### 类型转换

`int()` 可将字符串或浮点数转为整数，转换失败会报错。

```python
int("42")    # 42
int(3.14)    # 3
```

## 变量与注释

### 多变量赋值

使用逗号同时给多个变量赋值。

```python
x, y, z = 1, 2, 3
```

### 注释

`#` 表示单行注释，可独立成行或写在行尾。

## 列表

### 声明与访问

列表使用方括号声明，支持正向索引（从 0 开始）和负向索引（从 -1 开始）。

### 常用方法

- `.append(x)`：在末尾添加元素
- `.insert(i, x)`：在指定位置插入元素
- `del list[i]`：删除指定索引的元素，无返回值
- `.pop(i)`：弹出元素并返回，默认弹出最后一个
- `.remove(x)`：删除第一个匹配的指定值
- `.sort()`：原地排序，修改原始数据
- `sorted(list)`：临时排序，返回新列表
- `.reverse()`：反转列表
- `len(list)`：返回长度

### del 与 pop 的区别

- `del` 直接删除，无返回值
- `pop` 删除的同时返回该元素，可继续使用

### remove 的限制

`remove` 只删除第一个匹配的值，若需删除全部需配合循环。

### sort 与 sorted

- `sort` 修改原列表，返回 `None`
- `sorted` 不修改原列表，返回新列表
- 两者都接受 `reverse=True` 实现倒序

## 循环与遍历

### for 循环基本语法

通过 `for ... in ...` 遍历可迭代对象，循环体使用缩进表示。

### range

`range()` 用于生成数字序列。

- `range(stop)`：从 0 到 stop-1
- `range(start, stop)`：从 start 到 stop-1
- `range(start, stop, step)`：可指定步长

### while 循环

通过条件控制循环，条件为真时持续执行。

```python
while n > 0:
    n -= 1
```

### break 与 continue

- `break`：立即退出当前循环
- `continue`：跳过本轮剩余代码，进入下一轮循环

### 数值列表方法

- `min(list)`：最小值
- `max(list)`：最大值
- `sum(list)`：求和

## 列表推导式与切片

### 列表推导式

将循环和创建列表合并为一行，可附加条件过滤。

```python
squares = [x ** 2 for x in range(1, 6)]
evens = [x for x in range(10) if x % 2 == 0]
```

### 切片

切片语法 `list[start:stop:step]`，左闭右开，省略部分有默认值。

```python
nums[1:4]     # 区间切片
nums[::2]     # 步长切片
nums[::-1]    # 反转
```

### 切片复制列表

使用 `[:]` 切片可创建列表副本，避免直接赋值导致的引用共享。

## 元组

### 单元素元组

单个元素的元组需要在元素后添加逗号以区分普通表达式。

```python
single = (1,)  # 元组
not_tuple = (1)  # 整数
```

## 代码规范

### PEP 8 规范

- 使用 4 个空格作为缩进，禁用制表符
- 每行不超过 80 个字符
- 注释不超过 72 个字符

## 条件判断

### 比较运算符

- `==` / `!=`：相等 / 不等
- `>` / `<` / `>=` / `<=`：大于 / 小于 / 大于等于 / 小于等于

### 逻辑运算符

- `and` / `or`：逻辑与 / 逻辑或
- `in` / `not in`：成员检测

### 条件语句

基本语法支持 `if`、`if else`、`if elif else`。

### 假值判断

以下对象在条件判断中为 `False`：

- 数字 `0`
- 空字符串 `''` / `""`
- 空容器 `[]` / `()` / `{}`
- `None`

`if` 后可跟任意表达式，其计算结果为真则执行代码块。

## 字典

### 基本操作

- 使用 `{}` 声明字典，键值对用冒号分隔
- 可直接新增或修改键值对
- 使用 `del` 删除键值对
- 字典保留插入顺序（Python 3.7+）

### 访问字典

- `dict[key]`：直接访问，键不存在时报错
- `dict.get(key, default)`：安全访问，键不存在时返回默认值（默认为 `None`）

### 遍历字典

- `.keys()`：返回所有键
- `.values()`：返回所有值
- `.items()`：返回键值对
- 直接遍历字典等价于遍历 `.keys()`

```python
for key in user_dict:        # 遍历键
for key, val in user_dict.items():  # 遍历键值对
```

## 集合

### 创建集合

- `set(iterable)`：从可迭代对象创建集合
- `{elem1, elem2}`：使用花括号直接创建

### 集合特性

- 自动去重，存储唯一元素
- 无序存储，不保证顺序

## 函数

### 函数定义

使用 `def` 关键字定义函数，函数体缩进表示。

```python
def greet(name):
    """返回问候语"""
    return f"Hello, {name}!"
```

### 文档字符串

函数体首行使用三引号 `"""..."""` 编写文档字符串，描述函数用途，可通过 `help()` 或 `.__doc__` 查看。

### 位置实参

调用时按参数顺序一一对应传值，顺序不可颠倒。

### 关键字实参

调用时按参数名传值，顺序无关紧要，但关键字实参必须在位置实参之后。

```python
greet("Tom")              # 位置实参
greet(name="Tom")         # 关键字实参
```
