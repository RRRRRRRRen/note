# 关机、重启与计划任务

*类型：practice ｜ 难度：入门 ｜ 标签：CentOS、shutdown、定时关机、系统操作*

**Linux 关机重启统一走 `shutdown` 命令：`-h` 关机、`-r` 重启、`-c` 取消计划；时间参数支持 `now` 立即、`+m` 延迟分钟、`hh:mm` 定时，还能附带广播消息通知所有在线用户。关键认知：关机是可以「预约并反悔」的操作，生产环境先广播再关机是标准礼仪。**

## shutdown 基本语法

```bash
sudo shutdown [选项] [时间] [消息]
```

- 选项：控制关机行为。
- 时间：指定执行时间，支持多种格式。
- 消息：关机前广播给所有登录用户的自定义提示。

## 选项参数

```bash
sudo shutdown -h now   # -h：halt，立即关闭系统
sudo shutdown -r now   # -r：reboot，立即重启系统
sudo shutdown -c       # -c：取消正在等待或计划的关机操作
```

## 时间参数

```bash
sudo shutdown -h now    # now：立即执行
sudo shutdown -h +10    # +10：10 分钟后关机
sudo shutdown -r +15    # +15：15 分钟后重启
sudo shutdown -h 23:30  # 23:30：晚上 11:30 关机
sudo shutdown -r 06:00  # 06:00：早上 6:00 重启
```

## 广播消息

关机前向所有登录用户发送提示，给足保存工作的时间：

```bash
# 10 分钟后关机，并广播提示
sudo shutdown -h +10 "系统将在 10 分钟后关闭，请保存您的工作！"
```

## 取消关机计划

已设置的计划关机随时可以撤销：

```bash
sudo shutdown -c
```
