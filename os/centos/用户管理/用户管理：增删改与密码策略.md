# 用户管理：增删改与密码策略

*类型：practice ｜ 难度：入门 ｜ 标签：CentOS、useradd、passwd、userdel、id、用户管理*

**CentOS 用户管理四件套：`useradd` 创建（配 `-m` 建家目录、`-s` 指定 shell、`-G` 加附加组）、`passwd` 设置密码与策略（`-e` 强制改密、`-l`/`-u` 锁定解锁）、`userdel` 删除（`-r` 连家目录一起删）、`id` 查看 UID/GID 与所属组。注意 `userdel` 默认不删家目录，`useradd` 创建后必须 `passwd` 设密码才能登录。**

## useradd：创建用户

`useradd` 是创建新用户的低级别工具，可指定主目录、用户组、登录 shell 等信息，通常配合 `passwd` 一起使用。

### 基本语法

```bash
useradd [选项] 用户名
```

### 常用选项

- `-m`：创建主目录（通常位于 `/home/用户名`）。
- `-d`：指定自定义主目录路径。
- `-s`：指定登录 shell（默认 `/bin/bash`）。
- `-g`：指定主组。
- `-G`：指定附加组，多个用逗号分隔。
- `-e`：设置账户过期日期，格式 `YYYY-MM-DD`。
- `-c`：设置注释信息（如全名、部门）。

```bash
sudo useradd -m newuser                       # 创建用户并建主目录
sudo useradd -d /custom/directory newuser     # 指定主目录位置
sudo useradd -s /bin/zsh newuser              # 指定登录 shell
sudo useradd -g developers newuser            # 指定主组
sudo useradd -G wheel,admin newuser           # 加入多个附加组
sudo useradd -e 2025-12-31 newuser            # 设置过期日期
sudo useradd -c "John Doe, Developer" newuser # 设置注释
```

### 组合示例

```bash
sudo useradd newuser                      # 最简创建
sudo useradd -m -s /bin/zsh newuser       # 主目录 + zsh
sudo useradd -m -G wheel,admin newuser    # 主目录 + 附加组
sudo useradd -m -c "Jane Doe, IT Support" newuser  # 主目录 + 注释
sudo useradd -e 2025-12-31 newuser        # 限定期限的账户
```

## passwd：设置密码与策略

`passwd` 设置或更改用户密码。普通用户只能改自己的密码（需知道当前密码）；root 可直接改任何用户的密码，无需旧密码。

### 基本语法

```bash
passwd [选项] [用户名]
```

### 常用选项

```bash
passwd                     # 修改自己的密码（交互式：当前密码 → 新密码 → 确认）
sudo passwd -e username    # 强制下次登录时修改密码
sudo passwd -l username    # 锁定密码，禁止密码登录（不删账户和文件）
sudo passwd -u username    # 解锁密码
sudo passwd -x 30 username # 密码最长使用 30 天，到期强制更改
sudo passwd -n 7 username  # 密码最小有效期 7 天，期内不可再改
sudo passwd -w 7 username  # 到期前 7 天开始警告
```

### 密码策略

密码强度由 PAM（Pluggable Authentication Modules）体系控制，可配置最小长度、字符要求、过期周期等：

- `/etc/login.defs`：密码策略的默认设置。
- `/etc/pam.d/common-password`：PAM 密码策略配置。

## userdel：删除用户

`userdel` 删除用户账户，但**默认不删除**该用户的文件和主目录。

### 基本语法

```bash
userdel [选项] 用户名
```

### 常用选项

```bash
sudo userdel username    # 默认：删除账户，保留 /home/username
sudo userdel -r username # 连同主目录一起删除
sudo userdel -f username # 强制删除（用户已登录或有进程运行时），慎用
```

### 删除注意事项

- 默认只删 `/etc/passwd` 中的记录，家目录、邮箱等文件会遗留，需手动清理或确认。
- 强制删除正在登录的用户可能导致进程与资源问题。
- 删除后检查文件所有权：遗留文件归原 UID 所有，必要时 `chown` 转移或删除。

## id：查看用户信息

`id` 显示用户的 UID、主组 GID 及所有附加组，用于确认身份与权限。

### 基本语法

```bash
id [选项] [用户名]
```

### 常用用法

```bash
id            # 当前用户的 UID、GID、附加组
id username   # 指定用户的身份信息
id -G username  # 所有附加组的 GID
id -g -n username  # 主组名称（-n 显示名称而非数字）
id -u         # 当前用户 UID
id -Gn        # 当前用户所有附加组名
```

选项含义：

- `-u`：显示 UID。
- `-g`：显示主组 GID。
- `-G`：显示所有附加组 GID。
- `-n`：与 `-u`/`-g`/`-G` 连用，显示名称而非数字。
