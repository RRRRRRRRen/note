# 终端操作基础

*类型：practice ｜ 难度：入门 ｜ 标签：Ubuntu、终端、命令行、快捷键*

**终端提示符一行浓缩了四个信息：用户名、主机名、当前目录、权限符号（root 为 `#`，普通用户为 `$`）。命令的通用格式是「命令 + 参数」，参数有短（`-a`）长（`--all`）两种写法；再配上 Tab 补全、`Ctrl+R` 历史搜索、`Ctrl+A/E` 行首尾跳转等快捷键，命令行效率翻倍。**

## 终端提示符

```ini
root@b00363d8639e:~#
```

提示符各部分含义：

- `root`：用户名。
- `b00363d8639e`：主机名。
- `~`：当前所在目录为家目录；root 用户的家目录是 `/root`，普通用户的家目录在 `/home` 下。
- `#`：权限指示符，root 用户为 `#`，普通用户为 `$`。

查看当前用户名与主机名：

```bash
whoami    # 输出：root
hostname  # 输出：b00363d8639e
```

## 命令格式

```bash
command parameters（命令 参数）
```

## 参数写法

- 单个参数：`ls -a`（a 是 all 的缩写，表示「全部」）。
- 多个参数：`ls -al`（全部文件 + 列表形式展示）。
- 单个长参数：`ls --all`。
- 多个长参数：`ls --reverse --all`。
- 长短混合参数：`ls --all -l`。

## 参数值写法

- 短参数：`command -p 10`（例如：`ssh root@121.42.11.34 -p 22`）。
- 长参数：`command --paramters=10`（例如：`ssh root@121.42.11.34 --port=22`）。

## 获取帮助

```bash
command -h
```

## 常用快捷键

- 上下方向键：调取过往执行过的命令。
- `Tab`：命令或参数输入前几位后自动补全。
- `Ctrl + R`：查找使用过的命令（`history` 列出全部历史，`!2` 可直接执行编号为 2 的历史命令）。
- `Ctrl + L`：清屏并将当前行移到页面顶部。
- `Ctrl + C`：中止当前正在执行的命令。
- `Ctrl + U`：从光标位置剪切到行首。
- `Ctrl + K`：从光标位置剪切到行尾。
- `Ctrl + W`：剪切光标左侧的一个单词。
- `Ctrl + Y`：粘贴 `Ctrl + U/K/W` 剪切的内容。
- `Ctrl + A`：光标跳到命令行开头。
- `Ctrl + E`：光标跳到命令行结尾。
- `Ctrl + D`：关闭 Shell 会话。
