# 用户与权限

*类型：practice ｜ 难度：入门 ｜ 标签：Ubuntu、用户、群组、chmod、chown、权限*

**Linux 是多用户系统：每个用户属于一个群组，root 拥有最高权限；每个文件有所有者和群组，权限按「所有者 u、群组 g、其他 o」三元组管理，读 r=4、写 w=2、执行 x=1，三位数字（如 640）就是三组权限的和。管用户用 `useradd`/`userdel`/`usermod`，管文件归属用 `chown`/`chgrp`，管权限用 `chmod`。**

## 基本概念

### 用户

Linux 是多用户操作系统，理论上可创建无数用户。`root` 是特殊的超级用户，拥有最高权限。

### 群组

每个用户都属于一个特定群组；不设置时默认创建与用户名同名的群组并把用户划归其中。

## 用户管理

### 添加用户

```bash
useradd ren    # 添加用户 ren
```

- `-m`：添加用户后同时创建主目录 `/home/xxx`。
- 需要 root 权限。

`adduser` 是更友好的交互式版本：提供详细的交互设置，并自动创建主目录等内容。

### 设置密码

```bash
passwd ren    # 为 ren 设置密码（交互式）
```

- 需要 root 权限。

### 删除用户

```bash
userdel lion    # 只删用户，不删 /home 下对应目录
```

- `-r`：删除用户的同时删除 `/home` 下的对应目录。
- 需要 root 权限。

### 切换用户

```bash
su       # 切换到 root 用户（方式一）
su -     # 切换到 root 用户（方式二，加载 root 环境）
su ren   # 切换到指定用户
```

## 群组管理

```bash
groupadd friends   # 创建群组
groupdel foo       # 删除群组
groups lion        # 查看用户所在分组
usermod ren        # 修改用户属性
```

`usermod` 常用参数：

- `-l`：对用户重命名（`/home` 下的家目录名不会变，需手动改）。
- `-g`：修改用户所在群组，如 `usermod -g friends lion`。
- `-G`：一次性添加多个群组，如 `usermod -G friends,foo,bar lion`。
- `-a`：追加模式。`-G` 会使用户离开原先群组，加上 `-a`（append）则保留原群组。

## 文件归属管理

### 修改文件群组

```bash
chgrp bar file.txt    # 将 file.txt 的群组改为 bar
```

### 修改文件所有者

```bash
chown lion file.txt        # 转让给 lion 用户
chown lion:bar file.txt    # 所有者改为 lion，群组改为 bar
```

- `-R`：递归设置子目录和子文件，如 `chown -R lion:lion /home/frank`。

## 文件权限管理

### 查看权限

```bash
ls -l
# 输出示例：
# drwxr-xr-x 5 root root 4096 Apr 13  2020 climb
# lrwxrwxrwx 1 root root    7 Jan 14 06:41 hello2.c -> hello.c
# -rw-r--r-- 1 root root  149 Jan 13 06:14 hello.c
```

权限位说明：

- 首字符 `d`：目录；`-`：普通文件；`l`：链接。
- `r`：read，可读。
- `w`：write，可写（一般有写权限就有删除权限）。
- `x`：execute，可执行。
- `-`：无相应权限。

### 字母方式设置权限

```bash
chmod u+rx file           # 所有者增加读和执行权限
chmod g+r file            # 群组用户增加读权限
chmod o-r file            # 其他用户移除读权限
chmod g+r o-r file        # 群组加读，其他用户去读
chmod go-r file           # 群组和其他用户都移除读权限
chmod +x file             # 所有用户增加执行权限
chmod u=rwx,g=r,o=- file  # 所有者 rwx，群组 r，其他用户无权限
```

角色与符号：

- `u`（user）：所有者；`g`（group）：群组用户；`o`（other）：其他用户；`a`（all）：所有用户。
- `+`：添加权限；`-`：去除权限；`=`：分配权限。

### 数字方式设置权限

```bash
chmod 640 hello.c
# 对应文字权限为：- rw- r-- ---
```

数字换算：

- `r` = 4，`w` = 2，`x` = 1。

解析示例 `640`：

- 6 = 4 + 2 + 0：所有者具有 rw 权限。
- 4 = 4 + 0 + 0：群组用户具有 r 权限。
- 0 = 0 + 0 + 0：其他用户无权限。
