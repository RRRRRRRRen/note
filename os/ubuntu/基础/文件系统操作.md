# 文件系统操作

*类型：practice ｜ 难度：入门 ｜ 标签：Ubuntu、文件系统、目录、find、文件操作*

**Ubuntu 文件系统的一切从根 `/` 出发，每个目录有固定职责（etc 配置、var 可变数据、home 用户目录）。日常操作围绕五组命令展开：`pwd`/`which`/`ls` 看位置、`cd` 切目录、`cat`/`less`/`head`/`tail` 看内容、`touch`/`mkdir`/`cp`/`rm`/`ln` 做增删改、`locate`/`find` 找文件。最大的坑是 `rm -rf`——Linux 没有回收站，删了就没了。**

## 系统文件目录结构

```text
bin -> usr/bin    # binary。基本用户命令的二进制文件，如 ls、cp
boot              # 启动加载器和内核相关文件，如 grub 配置、内核镜像
dev               # 设备文件，用于访问硬盘、终端等系统设备
etc               # 系统配置文件和脚本，如 passwd、fstab
home              # 所有用户的主目录，每个用户一个子目录
lib -> usr/lib    # library。共享库文件，支持二进制文件运行
media             # 自动挂载的媒体设备（光盘、U 盘）
mnt               # mount。临时挂载文件系统，通常手动挂载
opt               # optional。附加软件包安装目录，避免与系统包冲突
proc              # 虚拟文件系统，包含进程与系统信息，如 /proc/cpuinfo
root              # 系统管理员（root 用户）的主目录
run               # 系统运行时数据，如进程 ID 文件和锁文件
sbin -> usr/sbin  # system binary。系统管理员命令，如 ifconfig、reboot
srv               # service。系统提供的服务数据，如 Web 服务器数据
sys               # 虚拟文件系统，设备和系统信息接口
tmp               # temporary。临时文件，重启后可能被删除
usr               # unix software resource。用户级程序和数据，含 /usr/bin、/usr/lib
var               # variable。可变数据，如 /var/log、/var/mail、/var/tmp
```

## 查看目录与路径

```bash
pwd        # 查看当前工作目录，输出 /
which ls   # 查看命令可执行文件所在路径，输出 /usr/bin/ls
ls         # 查看文件及目录列表
```

`ls` 常用参数：

- `-a`：显示所有文件和目录（包括隐藏的）。
- `-l`：显示详细列表。
- `-h`：文件大小适合人类阅读。
- `-t`：按最近一次修改时间排序。
- `-i`：显示文件的 `inode`（文件内容的标识）。

## 切换目录

```bash
cd /
# 跳转到根目录
```

常用写法：

- `cd /`：跳转到根目录。
- `cd ~`：跳转到家目录。
- `cd ..`：跳转到上级目录。
- `cd ./home`：跳转到当前目录下的 home 目录。
- `cd /home/lion`：跳转到绝对路径指定目录。
- `cd`：不添加任何参数，回到家目录。

## 查看磁盘占用

```bash
du
# 递归显示当前目录下所有文件的大小
```

常用参数：

- `-h`：适合人类阅读。
- `-a`：同时列出目录下文件的大小。
- `-s`：只显示总计大小。

## 查看文件内容

### cat：全部查看

```bash
cat cloud-init.log
# 打印所有文件内容
```

- `-n`：显示行号。

### less：分页查看

```bash
less xxx.md
```

快捷操作：

- `空格`：前进一页；`b`：后退一页。
- `回车`：前进一行；`y`：后退一行；上下键：前进/后退一行。
- `d`：前进半页；`u`：后退半页。
- `q`：中止读取退出。
- `=`：显示当前页对应的行号范围等详细信息。
- `h`：帮助文档。
- `/`：搜索模式，`n` 跳到下一个匹配，`N` 上一个，支持正则。

### head / tail：头尾查看

```bash
head cloud-init.log        # 开头几行，默认 10 行
head cloud-init.log -n 2   # 指定行数

tail cloud-init.log        # 结尾几行，默认 10 行
tail cloud-init.log -n 2   # 指定行数
tail -f -s 4 xxx.log       # 持续追踪文件更新，每 4 秒检查一次
```

## 操作文件与目录

### 创建

```bash
touch new_file            # 创建空文件
mkdir new_folder          # 创建目录
mkdir -p one/two/three    # 递归创建多级目录
```

### 复制

```bash
cp file file_copy         # 复制并重命名
cp file one               # 复制到 one 目录下，保留原名
cp file one/file_copy     # 复制到目录并重命名
cp *.txt folder           # 通配符批量复制
```

常用参数：

- `-r`：递归拷贝，用于整个目录。
- `-i`：覆盖前提示。
- `-L`：复制符号链接所指向的文件。
- `-p`：保留权限、所有权和时间戳。

行为规则：

- 目标是目录：复制进目录，保留原文件名。
- 目标是文件名：复制并重命名。
- 默认直接覆盖已存在文件；目标目录不存在时会自动创建。

### 删除

```bash
rm new_file      # 删除单个文件
rm f1 f2 f3      # 同时删除多个文件
```

常用参数：

- `-i`：删除前确认。
- `-f`：强制删除。
- `-r`：递归删除目录（`rm -rf`）。

Linux 没有回收站，删除难以恢复，`rm -rf` 务必先核对路径。

### 链接

```bash
ln file1 file2    # 硬链接
ln -s file1 file2 # 软链接
```

- 软链接：指向文件路径。原文件删除后链接失效。
- 硬链接：指向文件实体。原文件删除后链接依然有效，所有硬链接都删除文件才真正被删除。

## 查找文件

### locate：数据库搜索

```bash
updatedb          # 更新文件数据库
locate fil*.txt   # 从数据库中查找
```

`locate` 查的是文件数据库而非全磁盘，新建文件未入库时搜不到，先执行 `updatedb`。

### find：磁盘遍历搜索

基本语法：

```bash
find <何处> <何物> <做什么>
```

按文件名查找：

```bash
find -name "file.txt"              # 当前目录及子目录
find / -name "syslog"              # 整个硬盘
find /var/log -name "syslog"       # 指定目录
find /var/log -name "syslog*"      # 通配符匹配前缀
find /var/log -name "*syslog*"     # 通配符匹配包含
```

按大小查找：

```bash
find /var -size +10M   # 超过 10M
find /var -size -50k   # 小于 50k
find /var -size +1G    # 超过 1G
find /var -size 1M     # 等于 1M
```

按访问时间查找：

```bash
find -name "*.txt" -atime -7   # 近 7 天内访问过的 .txt 文件
```

只查目录或文件：

```bash
find . -name "file" -type f    # 仅文件
find . -name "file" -type d    # 仅目录
```

对查找结果执行操作：

```bash
# 按 %p - %u 格式打印：文件名 - 所有者
find -name "*.txt" -printf "%p - %u\n"

# 删除所有 .jpg 文件，无提示，慎用
find -name "*.jpg" -delete

# 对每个 .c 文件执行 chmod，{} 代表查到的文件，\; 是必须的结尾
find -name "*.c" -exec chmod 600 {} \;

# 同上，但每个操作前有确认提示
find -name "*.c" -ok chmod 600 {} \;
```
