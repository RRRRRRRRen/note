# 常用工具类

*类型：knowledge ｜ 难度：入门 ｜ 标签：yudao、工具类、Hutool、集合工具、字符串工具*

**yudao 项目的通用工具层沉淀在 `util` 包与框架组件中：对象转换用 BeanUtils、字符串与集合判断用 Spring 的 StringUtils/CollectionUtils 或 Hutool、断言校验用 Assert/Preconditions 思路的封装。该主题的专题源码笔记暂为空，本篇梳理常用工具类的分布与选型原则，避免重复造轮子。**

## 工具类在项目中的定位

- 工具类是「无状态、静态方法、跨模块复用」的逻辑收拢点，yudao 按模块拆分 util 包，避免单文件无限膨胀。
- 选型原则：JDK 原生优先（`Objects`、`Collections`、`Comparator`），Spring 自带次之（`StringUtils`、`CollectionUtils`、`BeanUtils`），第三方库（Hutool、Guava）按项目已引入的依赖选择，团队内保持一致。
- 工具类规范：私有化构造器防止实例化，方法不持有可变共享状态。

```java
public final class ServiceExceptionUtil {

    // 工具类不允许实例化
    private ServiceExceptionUtil() {
    }

    public static ServiceException exception(ErrorCode errorCode) {
        return new ServiceException(errorCode);
    }
}
```

## 常用工具速查

### 对象转换与拷贝

| 需求 | 工具 | 说明 |
| --- | --- | --- |
| VO ↔ DO 属性拷贝 | `BeanUtils.toBean(source, Target.class)` | 项目封装，底层基于反射/BeanCopier |
| 列表批量转换 | `BeanUtils.toBean(list, Target.class)` | 同上，列表版 |
| 字段名不一致的复杂转换 | 手写 Convert 类 | 显式映射，见「项目通用问题和设计」篇 |

对象转换收敛在 convert 层或统一工具，避免散落在控制器和服务中。

### 字符串与集合判断

```java
// 字符串判空：null、"" 都返回 true（注意与 isBlank 的区别：blank 还认空白串）
StringUtils.isEmpty(str);
StringUtils.hasText(str);   // Spring 风格：非 null 且含非空白字符

// 集合判空：null 和空集合都返回 true，避免裸调 size() 前的 NPE
CollectionUtils.isEmpty(list);
CollectionUtils.isEmpty(map);
```

- 判空统一走工具方法，禁止 `str != null && !str.isEmpty()` 这类散落写法。
- 对外返回集合时优先返回空集合而不是 null（`Collections.emptyList()`），见「Java 约定与习惯」篇。

### 断言与前置校验

```java
// 参数前置校验：不满足立即失败，避免无意义的下游调用
Assert.isTrue(id > 0, "id 必须大于 0");
Assert.notNull(user, "用户不存在");
```

- 入参校验优先用 Bean Validation 注解（见「参数校验」篇），断言工具用于内部方法的前置防御。
- 业务性校验失败抛项目统一的业务异常，携带 ErrorCode。

### JDK 工具类

项目高频使用的 JDK 原生工具（详见「Java 约定与习惯」篇）：

- `Collections`：singleton、emptyList、unmodifiableXxx、sort、binarySearch。
- `Comparator`：comparing、thenComparing、nullsLast 链式排序。
- `Objects`：equals、isNull、requireNonNull。
- `Optional`：以 `map`/`orElse` 链式替代嵌套 null 判断。

## 使用原则

- 先查项目内已有工具，再查 JDK/Spring，最后才考虑引入新第三方依赖。
- 工具方法保持「一个方法做一件事」，超过三个分支参数时考虑改为策略或独立的领域方法。
- 与时间、金额相关的转换优先收口到专门工具（时间用 `LocalDateTime` + `DateTimeFormatter`，金额用 `BigDecimal` 并显式指定 RoundingMode）。
- 工具类的方法必须有 Javadoc，说明 null 入参的行为语义（见「文档注释」篇）。
