# 函数

*类型：knowledge ｜ 难度：入门 ｜ 标签：Python、函数、参数 ｜ 更新：2026-09-22*

**函数用 `def` 定义，首行文档字符串通过 `help()` 可查；实参传递分位置实参（按顺序对应）与关键字实参（按名传值、顺序无关）；把列表传给函数有被修改的风险，传副本 `lst[:]` 可保护原数据；`*args` 与 `**kwargs` 让函数接收任意数量的位置 / 关键字实参，函数内部它们分别是元组和字典。**

## 函数定义

`def` 定义函数，函数体缩进表示。首行用 `"""..."""` 写文档字符串，通过 `help()` 或 `__doc__` 查看：

```python
def greet(name):
    """返回问候语"""
    return f"Hello, {name}!"

print(greet("Tom"))     # Hello, Tom!
print(greet.__doc__)    # 返回问候语
```

## 实参传递

- **位置实参**：按参数顺序一一对应，顺序不可颠倒 —— `greet("Tom")`
- **关键字实参**：按参数名传值，顺序无关，须写在位置实参之后 —— `greet(name="Tom")`

```python
def intro(name, age):
    print(f"{name}, {age}")

intro("Tom", 18)             # 位置实参：顺序决定对应关系
intro(age=18, name="Tom")    # 关键字实参：顺序无关
intro("Tom", age=18)         # 混用：位置实参必须在前
```

## 列表参数保护

函数内对列表的修改会直接影响原列表；传副本可保护原数据：

```python
def process(items):
    items.append("new")      # 修改的是调用方传入的同一个列表

my_list = [1, 2]
process(my_list[:])          # 传切片副本，my_list 不受影响
```

- `process_list(my_list[:])` 传副本，而非 `process_list(my_list)` 直接暴露原列表
- 副本策略的代价是复制开销，大列表且确认无需保护时可直接传引用

## 任意数量实参

- `*args`：收集任意数量的位置实参，函数内部是一个元组
- `**kwargs`：收集任意数量的关键字实参，函数内部是一个字典

```python
def make_pizza(*toppings):
    """*toppings 收集所有位置实参为元组"""
    for t in toppings:           # toppings 是 ('mushrooms', 'pepperoni', 'cheese')
        print(f"- {t}")

make_pizza("mushrooms", "pepperoni", "cheese")
```

- 形参名 `*args` / `**kwargs` 中的 args、kwargs 只是惯例，`*` 与 `**` 才是语法本体
