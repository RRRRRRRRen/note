# 循环与遍历

*类型：knowledge ｜ 难度：入门 ｜ 标签：Python、for、while、range ｜ 更新：2026-09-22*

**Python 循环只有两种：`for` 遍历可迭代对象（配 `range()` 生成序列），`while` 条件为真就持续执行；`break` 立即退出整个循环，`continue` 跳过本轮进入下一轮；`min()` / `max()` / `sum()` 覆盖最常见的数值统计。**

## for 循环

`for item in iterable:` 遍历可迭代对象，循环体用缩进表示归属：

```python
langs = ["python", "go", "rust"]
for lang in langs:
    print(lang)    # 缩进的代码属于循环体，每轮执行一次
```

## range 生成序列

- `range(stop)`：`0` 到 `stop-1`
- `range(start, stop)`：`start` 到 `stop-1`
- `range(start, stop, step)`：指定步长生成

```python
print(list(range(3)))         # [0, 1, 2]
print(list(range(1, 4)))      # [1, 2, 3] —— 含头不含尾
print(list(range(0, 10, 2)))  # [0, 2, 4, 6, 8] —— 步长 2
```

## while 循环

条件为真时持续执行，注意在循环体内推进条件，避免死循环：

```python
n = 3
while n > 0:
    n -= 1        # 每轮修改条件变量，否则永远为真
```

## break 与 continue

- `break`：立即退出当前整个循环
- `continue`：跳过本轮剩余代码，直接进入下一轮

```python
for i in range(10):
    if i == 3:
        continue   # 跳过 3，继续后面的轮次
    if i == 6:
        break      # 到 6 直接终止整个循环
    print(i)       # 输出 0 1 2 4 5
```

## 数值统计

`min()` / `max()` / `sum()` 直接作用于数字列表，分别返回最小值、最大值与求和：

```python
nums = [4, 11, 7]
print(min(nums), max(nums), sum(nums))   # 4 11 22
```
