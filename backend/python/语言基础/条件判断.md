# 条件判断

*类型：knowledge ｜ 难度：入门 ｜ 标签：Python、if、布尔、运算符 ｜ 更新：2026-09-22*

**条件判断由三层组成：比较与逻辑运算符产生布尔值；`if` / `if-else` / `if-elif-else` 三种结构分支执行；Python 有一组固定假值——`0`、空字符串、空容器、`None` 在条件中均视为 `False`，其余一切为真，可直接 `if lst:` 判空。**

## 比较运算符

- `==` / `!=`：相等 / 不等
- `>` `<` `>=` `<=`：大小比较

```python
print(3 == 3.0)   # True —— 数值比较
print("a" != "b") # True
```

## 逻辑运算符

- `and` / `or`：逻辑与 / 或
- `in` / `not in`：成员检测，判断值是否在序列中

```python
age = 20
print(age > 18 and age < 60)   # True
print("py" in "python")        # True —— 成员检测也适用于列表、元组
```

## 条件语句

三种结构：单分支 `if`、双分支 `if-else`、多分支 `if-elif-else`，分支体用缩进表示：

```python
score = 85
if score >= 90:
    print("A")
elif score >= 80:
    print("B")        # 命中此分支，后续分支不再检查
else:
    print("C")
```

## 假值判断

以下值在条件中一律视为 `False`，其余一切为真：

- `0`（含 `0.0`）
- 空字符串 `''` / `""`
- 空容器 `[]` / `()` / `{}`
- `None`

```python
lst = []
if lst:                    # 空列表为假，无需写成 len(lst) == 0
    print("有数据")
else:
    print("列表为空")
```
