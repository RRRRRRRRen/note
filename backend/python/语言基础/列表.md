# 列表

*类型：knowledge ｜ 难度：入门 ｜ 标签：Python、列表、切片、列表推导式 ｜ 更新：2026-09-22*

**列表是有序可变序列：方括号声明，正负索引访问；增删靠 append / insert / del / pop / remove；排序区分原地 `sort()`（改原列表、返回 None）与新建 `sorted()`（返回新列表）；切片左闭右开，`[::-1]` 反转、`[:]` 复制；列表推导式一行完成「循环 + 过滤 + 构建」。**

## 声明与访问

方括号 `[]` 声明，索引从 `0` 开始；负索引从 `-1` 开始表示倒数：

```python
nums = [10, 20, 30, 40]
print(nums[0])    # 10 —— 正向索引从 0 开始
print(nums[-1])   # 40 —— 负向索引 -1 表示最后一个
```

## 常用方法

- `.append(x)`：末尾添加元素
- `.insert(i, x)`：在索引 `i` 处插入元素
- `del lst[i]`：删除指定索引元素，无返回值
- `.pop(i)`：弹出并返回元素，默认弹出最后一个
- `.remove(x)`：按值删除第一个匹配项（只删第一个）
- `.sort()`：原地排序，直接修改原列表，返回 `None`
- `sorted(lst)`：返回排序后的新列表，不修改原列表
- `.reverse()`：反转列表
- `len(lst)`：返回列表长度

```python
langs = ["python", "go", "rust"]
langs.append("java")       # 末尾追加
langs.insert(1, "c++")     # 索引 1 处插入
last = langs.pop()         # 弹出末尾元素，可继续使用
langs.remove("go")         # 删除第一个 "go"
del langs[0]               # 直接删除，无返回值

nums = [3, 1, 2]
nums.sort()                              # 原地排序 → [1, 2, 3]
desc = sorted(nums, reverse=True)        # 新列表倒序，原列表不动
```

- `del` 与 `pop` 的区别：`del` 删完即丢，`pop` 删除的同时返回该元素供继续使用
- `sort()` 与 `sorted()` 均支持 `reverse=True` 倒序

## 列表推导式

一行完成循环与列表创建，可附加 `if` 条件过滤：

```python
squares = [x**2 for x in range(1, 6)]        # [1, 4, 9, 16, 25]
evens = [x for x in range(10) if x % 2 == 0] # [0, 2, 4, 6, 8] —— 带 if 过滤
```

## 切片

语法 `lst[start:stop:step]`，左闭右开，省略即取到边界：

```python
nums = [0, 1, 2, 3, 4, 5]
print(nums[1:4])   # [1, 2, 3] —— 区间切片，含头不含尾
print(nums[::2])   # [0, 2, 4] —— 步长为 2
print(nums[::-1])  # [5, 4, 3, 2, 1, 0] —— 步长 -1 即反转
print(nums[:])     # 整份拷贝得到新列表，避免多个变量共享同一引用
```
