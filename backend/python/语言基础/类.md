# 类

**类用 `class` 定义、类名大驼峰；`__init__` 在创建实例时自动执行初始化，`self` 指向实例本身，属性通过 `self.属性名` 挂载；子类以 `class Child(Parent):` 继承父类，定义同名方法即可重写，`super()` 用于复用父类的初始化逻辑。**

## 类定义

`class` 关键字定义类，类名使用大驼峰命名法（PascalCase）。`__init__` 为初始化方法，每次创建实例时自动调用；`self` 指向实例本身，属性通过 `self.属性名` 定义：

```python
class Dog:
    """一次模拟小狗的简单尝试"""

    def __init__(self, name, age):
        self.name = name   # 实例属性：每个实例各自一份
        self.age = age

    def sit(self):
        print(f"{self.name} is now sitting.")

my_dog = Dog("Willie", 6)   # 创建实例，__init__ 自动执行
my_dog.sit()                # Willie is now sitting.
```

- 调用方法时无需手动传 `self`，Python 自动把实例传入

## 继承与方法重写

子类继承父类：`class Child(Parent):`，自动获得父类全部方法。子类定义与父类同名的方法即覆盖父类实现；`super()` 在子类中调用父类方法，常用于 `__init__` 复用初始化逻辑：

```python
class ElectricCar(Car):
    def __init__(self, make, model, year, battery_size=75):
        super().__init__(make, model, year)   # 调用父类 __init__，避免重复写初始化代码
        self.battery_size = battery_size      # 再扩展子类自己的属性
```

## 编码风格

- 类名大驼峰：`ElectricCar`
- 类内方法之间空一行分隔
- 模块中类与类之间空两行分隔
