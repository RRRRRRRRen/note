# 集合

*类型：knowledge ｜ 难度：入门 ｜ 标签：Python、集合、去重 ｜ 更新：2026-09-22*

**集合是无序且不重复的容器：`set(iterable)` 或 `{a, b, c}` 创建，核心用途就是自动去重与成员检测——把列表传进 `set()` 一行完成去重，代价是丢失原有顺序。**

## 创建与去重

`set(iterable)` 从任何可迭代对象创建，或用花括号直接列出元素。自动去重、无序存储：

```python
langs = {"python", "go", "python", "rust"}
print(langs)                    # {'python', 'go', 'rust'} —— 重复项消失，顺序不保证
nums = set([1, 2, 2, 3])        # {1, 2, 3} —— 从列表去重的标准写法
empty = set()                   # 空集合必须用 set()，{} 创建的是空字典
```

- `{}` 空花括号留给字典，空集合只能写 `set()`
- 无序意味着不支持索引访问，需要按下标取值就先 `sorted()` 或转列表
