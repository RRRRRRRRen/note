# 字典

*类型：knowledge ｜ 难度：入门 ｜ 标签：Python、字典、dict ｜ 更新：2026-09-22*

**字典是键值对集合：`{}` 声明，键直接索引增删改，Python 3.7+ 保留插入顺序；访问分两派——`d[key]` 键不存在直接报错，`d.get(key, default)` 安全访问返回默认值；遍历的三条通道是 `keys()`、`values()`、`items()`。**

## 基本操作

`{}` 声明，键值对写作 `key: value`。赋值语句「键存在则修改、不存在则新增」，`del` 删除指定键值对：

```python
user = {"name": "Tom", "age": 18}
user["city"] = "Hangzhou"   # 键不存在 → 新增
user["age"] = 19            # 键已存在 → 修改
del user["city"]            # 删除键值对
```

- Python 3.7+ 字典保留插入顺序，遍历顺序与插入顺序一致

## 访问

- `d[key]`：直接访问，键不存在抛 `KeyError`
- `d.get(key, default)`：安全访问，键不存在返回默认值（缺省为 `None`）

```python
user = {"name": "Tom"}
print(user["name"])            # Tom
print(user.get("email"))       # None —— 键不存在不报错
print(user.get("email", "N/A"))# N/A —— 指定默认值
```

## 遍历

- `for k in d`（等价 `d.keys()`）：遍历键
- `d.values()`：遍历值
- `for k, v in d.items()`：同时遍历键与值

```python
user = {"name": "Tom", "age": 18}
for k in user:                    # 默认遍历键
    print(k, user[k])
for v in user.values():           # 只取值
    print(v)
for k, v in user.items():         # 键值对一起拿，最常用
    print(f"{k}: {v}")
```
