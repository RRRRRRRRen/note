# 异常处理

*类型：knowledge ｜ 难度：入门 ｜ 标签：Python、异常、try-except ｜ 更新：2026-09-22*

**异常处理的标准结构：`try` 块放可能出错的代码，`except` 按类型捕获异常，`else` 块仅在无异常时执行，`pass` 可静默忽略错误——捕获具体异常类型（如 `ValueError`、`FileNotFoundError`）而不是放任程序崩溃。**

## try-except 结构

`try` 块编写可能出错的代码，`except` 捕获指定异常类型；`else` 块在无异常时执行，`pass` 静默忽略错误：

```python
try:
    num = int(input("输入数字: "))   # 转换失败会抛 ValueError
except ValueError:
    print("输入无效")                 # 只有捕获到对应异常才执行
else:
    print(f"你输入了: {num}")         # 仅无异常时执行
```

- `except` 必须指明异常类型，裸 `except:` 会把所有错误连 bug 一起吞掉，难以排查
- `else` 的价值是把「可能出错的」与「成功后才做的」分开，失败路径一目了然

对文件不存在这类「可预期、无需处理」的情况，`pass` 静默跳过即可：

```python
try:
    with open("missing.txt") as f:
        content = f.read()
except FileNotFoundError:
    pass    # 文件不存在就当无事发生，程序继续往下走
```
