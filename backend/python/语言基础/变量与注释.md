# 变量与注释

*类型：knowledge ｜ 难度：入门 ｜ 标签：Python、变量、注释 ｜ 更新：2026-09-22*

**Python 变量无需声明类型，赋值即创建；逗号分隔可一行给多个变量同时赋值，同一语法还能优雅地交换变量；`#` 是单行注释，可独立成行或跟在代码尾部，注释解释「为什么」而非复述代码。**

## 多变量赋值

逗号分隔，一行同时给多个变量赋值，右侧值按位置一一对应：

```python
x, y, z = 1, 2, 3   # x=1, y=2, z=3
x, y = y, x         # 同一语法可直接交换两个变量，无需临时变量
```

## 注释

`#` 表示单行注释，可独立成行或写在行尾：

```python
# 满分减去已用量，得到剩余量
remain = total - used   # 行尾注释：说明这行在做什么
```

- 独立成行的注释放在被描述代码的上一行
- 行尾注释与代码之间至少隔两个空格，只写必要信息
