# 数字与运算

*类型：knowledge ｜ 难度：入门 ｜ 标签：Python、数字、运算符 ｜ 更新：2026-09-22*

**Python 数字运算的几个关键点：`/` 相除恒返回浮点数、`**` 是幂运算、`%` 取余数；下划线可作数字分位符提升可读性；常量没有语言级支持，靠全大写命名约定表达；`int()` 做类型转换，失败直接报错。**

## 算数运算符

- `+` `-` `*` `/` `**`：加减乘除与幂运算，`**` 表示乘方
- 任意两数相除（`/`）结果恒为浮点数，即使能整除
- 操作数中只要含浮点数，结果就是浮点数

```python
print(4 / 2)    # 2.0 —— 能整除也返回浮点数
print(2 ** 10)  # 1024 —— 幂运算
print(1 + 2.0)  # 3.0 —— 含浮点数则结果为浮点数
```

## 求模运算符

`%` 返回两数相除的余数，常用于奇偶判断与周期分组：

```python
print(5 % 2)   # 1 —— 5 除以 2 余 1
# 奇偶判断：n % 2 为 0 即偶数
```

## 增强赋值运算符

`+=` `-=` `*=` `/=`：先运算再赋值给自身，简化「基于原值更新」的写法：

```python
count = 0
count += 1   # 等价于 count = count + 1
```

## 数字分位

下划线作为数字分隔符提升可读性，不影响数值本身：

```python
big_num = 1_000_000
print(big_num)   # 1000000 —— 下划线只用于书写，打印时消失
```

## 常量约定

Python 没有内置常量机制，习惯用全大写加下划线表示「不应修改」的量：

```python
MAX_CONNECTIONS = 100    # 约定为常量，代码中不应再对其赋值
```

## 类型转换

`int()` 将字符串或浮点数转为整数，无法转换则报错：

```python
print(int("42"))    # 42 —— 字符串转整数
print(int(3.14))    # 3 —— 浮点转整数直接截断，不四舍五入
print(int("abc"))   # ValueError: invalid literal for int() with base 10: 'abc'
```
