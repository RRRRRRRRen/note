# 文件与路径

*类型：knowledge ｜ 难度：入门 ｜ 标签：Python、pathlib、文件读写 ｜ 更新：2026-09-22*

**推荐用 `pathlib.Path` 对象处理路径：相对路径、绝对路径都是 `Path("...")`，`path.exists()` 先检查存在性再读；读写只有两个核心方法——`read_text()` 读全部内容为字符串（文件不存在报错），`write_text()` 写入字符串（不存在自动创建、已存在整体覆盖）。**

## Path 对象

`from pathlib import Path` 导入。相对路径相对当前工作目录解析，绝对路径从根目录写起：

```python
from pathlib import Path

rel = Path("data/note.txt")           # 相对路径
absolute = Path("/Users/ren/note.txt")# 绝对路径

if rel.exists():                      # 检查路径是否存在，返回布尔值
    content = rel.read_text()
```

- `path.exists()` 先判断再操作，是避免读文件报错的第一道防线

## 读写文件

- `path.read_text()`：读取全部内容为字符串，文件不存在则报错
- `path.write_text(str)`：写入字符串，文件不存在则自动创建，已存在则整体覆盖

```python
from pathlib import Path

path = Path("data/note.txt")
path.write_text("hello\nworld")       # 不存在会自动创建；已存在则覆盖全部内容
content = path.read_text()

lines = content.splitlines()          # 按行分割为列表：['hello', 'world']
print("world" in content)             # True —— 用 in 检查子串是否出现
```

- 读取结果配合 `splitlines()` 按行分割为列表，配合 `"keyword" in content` 检查子串
