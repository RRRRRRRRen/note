# 字符串

*类型：knowledge ｜ 难度：入门 ｜ 标签：Python、字符串、f-string ｜ 更新：2026-09-22*

**字符串是最常用的文本类型：单双引号完全等价，可按内容灵活选择以避免转义；f-string 把变量或表达式直接嵌入字符串；常用方法负责大小写转换与空白清理——注意字符串本身不可变，所有方法都返回新字符串。**

## 引号

字符串支持单引号 `'...'` 和双引号 `"..."`，两者完全等价，根据内容灵活选择外层引号即可避免转义：

```python
msg = "I'm learning Python"    # 内容含单引号，外层用双引号
reply = 'He said "hi"'         # 内容含双引号，外层用单引号
```

## f-string 格式化

在字符串前加 `f`，用 `{}` 嵌入变量或表达式，`{}` 内可以直接运算：

```python
name, age = "Tom", 12
print(f"Hello, {name}!")                # Hello, Tom!
print(f"{name} is {age + 1} next year") # {} 内可执行表达式
```

## 常用方法

- `.title()`：每个单词首字母大写
- `.upper()` / `.lower()`：全部转大写 / 小写
- `.strip()` / `.rstrip()` / `.lstrip()`：去除两端 / 右侧 / 左侧空白
- `.removeprefix(prefix)`：移除指定前缀（Python 3.9+）

```python
s = " hello world "
print(s.title())                  #  Hello World  —— 每个单词首字母大写
print(s.strip().upper())          # HELLO WORLD —— 先去空白再转大写，方法可链式调用
file = "test_backup.py"
print(file.removeprefix("test_")) # backup.py —— 移除指定前缀
```
