# 模块与导入

*类型：knowledge ｜ 难度：入门 ｜ 标签：Python、模块、import ｜ 更新：2026-09-22*

**导入只有两种基本形态：`import 模块` 导入整个模块（调用需前缀），`from 模块 import 名称` 只导入特定函数或类（调用无需前缀）；`as` 设置别名简化长名称；`from 模块 import *` 会污染命名空间，不推荐；模块文件顶部、import 之前的文档字符串描述模块用途。**

## import 基本语法

- `import 模块`：导入整个模块，调用时必须带模块前缀
- `from 模块 import 名称`：导入特定函数或类，直接按名调用

```python
import math
print(math.sqrt(16))               # 4.0 —— 必须带 math. 前缀

from math import sqrt, ceil        # 只导入需要的名称
print(sqrt(16))                    # 4.0 —— 无需前缀
```

## 别名与批量导入

- `as` 给模块或名称设置别名，常用于缩短长名称
- `from 模块 import *` 导入所有公开名称，可能覆盖已有名称、污染命名空间，不推荐

```python
import numpy as np                    # 模块别名：社区通用惯例
from math import sqrt as sq           # 名称别名
print(sq(9))                          # 3.0
```

## 模块级文档字符串

模块文件顶部、`import` 之前使用 `"""..."""` 编写模块文档字符串，描述模块用途，`help(模块名)` 时首先展示：

```python
"""一个用于处理坐标转换的工具模块。"""

import math
```

## 导入类

导入语法对函数和类完全通用：

```python
from car import Car, ElectricCar          # 从模块导入多个类
from car import ElectricCar as EC         # 给类设置别名

my_car = EC("tesla", "model s", 2024)
```
