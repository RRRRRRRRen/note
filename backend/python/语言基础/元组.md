# 元组

*类型：knowledge ｜ 难度：入门 ｜ 标签：Python、元组、不可变 ｜ 更新：2026-09-22*

**元组是不可变序列：圆括号声明，支持索引和切片访问，但声明后不能增删改元素；单元素元组必须带逗号——`(1,)` 是元组，`(1)` 只是加了分组括号的整数。**

## 不可变序列

`()` 声明元组。与列表一样支持索引和切片，但不支持任何修改操作，适合存放不应被改动的数据：

```python
t = (1, 2, 3)
print(t[0])     # 1 —— 索引访问与列表相同
print(t[1:])    # (2, 3) —— 切片返回的仍是元组
t[0] = 9        # TypeError: 'tuple' object does not support item assignment
```

- 不可变性是语法层面的保护：误改数据的企图会直接报错，而不是悄悄生效

## 单元素元组

单元素元组必须加逗号，否则括号只是普通的分组符号：

```python
t = (1,)   # 元组
n = (1)    # 只是整数 1，括号被当作运算符分组
print(type(t), type(n))   # <class 'tuple'> <class 'int'>
```
