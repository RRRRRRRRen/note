# 面向对象程序设计概述

*类型：knowledge ｜ 难度：入门 ｜ 标签：Java、面向对象、类、对象、封装 ｜ 更新：2026-09-22*

**面向对象程序设计以类为模板构造对象：类制定如何构造对象，对象由行为、状态、标识三个特性刻画；数据和行为封装在一起并对使用者隐藏实现细节；类之间只存在依赖、聚合、继承三种关系。**

## 核心术语

- 类（class）：类制定了如何构造对象
- 实例（instance）：由一个类构造对象的过程称为创建这个类的一个实例
- 封装（encapsulation）：将数据和行为组合在一个包中，并对对象的使用者隐藏具体实现细节
- 实例字段（instance field）：对象中的数据
- 方法（method）：操作数据的过程
- 状态（state）：一个特定对象的一组特定实例字段值的集合，就是对象的当前状态
- 继承（inheritance）：通过扩展一个类得到另一个类

## 对象的三个主要特性

- 对象的行为（behavior）：能对对象施加哪些操作，即方法
- 对象的状态（state）：施加方法时对象如何响应，即实例字段的当前值
- 对象的标识（identity）：如何辨别具有相同行为与状态的不同对象

## 识别类

识别类的简单经验：在分析问题的过程中寻找名词，而方法对应动词。

- 名词（订单、账户、商品）通常对应类
- 动词（添加、结算、取消）通常对应方法

## 类之间的关系

| 关系 | 含义 | 示例 |
| --- | --- | --- |
| 依赖（uses-a） | 一个类的方法使用或操作另一个类的对象 | Order 使用 Customer |
| 聚合（has-a） | 包含关系，A 的对象包含 B 的对象 | Order 包含 Item |
| 继承（is-a） | A 建立在 B 的基础上，A 继承 B | Manager 继承 Employee |

- 依赖关系应当尽量减少（低耦合），类设计的目标之一是最小化类之间的依赖
