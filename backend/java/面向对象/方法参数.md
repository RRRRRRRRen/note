# 方法参数

*类型：knowledge ｜ 难度：入门 ｜ 标签：Java、按值调用、参数传递 ｜ 更新：2026-09-22*

**Java 只有按值调用：方法得到的是参数值的副本。因此方法不能修改基本类型参数，可以修改对象参数的状态（副本与原变量指向同一对象），但绝不能让对象参数指向一个新对象——这证明 Java 不是引用传递。**

## 按值调用

- Java 程序设计语言总是采用按值调用（call by value）
- 方法得到的是所有参数值的一个副本，方法不能修改传递给它的任何参数变量的内容

## 三条规则

方法不能修改基本数据类型的参数：

```java
public static void tripleValue(double x) {
    x = 3 * x; // 只修改了副本，原变量不变
}

double percent = 10;
tripleValue(percent); // percent 仍然是 10
```

方法可以改变对象参数的状态（字段值），因为副本引用与原引用指向同一个对象：

```java
public static void tripleSalary(Employee e) {
    e.raiseSalary(200); // 通过共享的对象引用修改了对象本身
}

Employee harry = new Employee("Harry", 50000);
tripleSalary(harry); // harry 的工资已被修改
```

方法不能让对象参数引用一个新对象，交换方法注定失效：

```java
public static void swap(Employee a, Employee b) {
    Employee temp = a;
    a = b;   // 只是交换了两个副本引用
    b = temp; // 对调用者的变量毫无影响
}

Employee x = ...;
Employee y = ...;
swap(x, y); // x、y 原封不动
```

## 结论

- 「方法能让对象参数状态改变」与「方法不能让对象参数指向新对象」这两条事实共同证实：Java 对对象传递的是「对象引用的值」，本质仍是按值调用，不是引用传递
- 想要在方法外获得多个结果，只能通过返回值或修改共享对象状态实现
