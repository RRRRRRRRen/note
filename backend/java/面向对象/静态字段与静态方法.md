# 静态字段与静态方法

*类型：knowledge ｜ 难度：入门 ｜ 标签：Java、static、静态常量、工厂方法、main ｜ 更新：2026-09-22*

**static 成员属于类而不属于单个对象：静态字段被所有实例共享，静态方法没有 this、不能访问实例字段；静态常量用 static final 修饰；工厂方法是用静态方法代替构造器造对象的惯用法。**

## 静态字段

- 静态字段属于类，不属于任何单个对象，所有实例共享同一份
- 直接通过类名访问：

```java
class Employee {
    // 每个对象都有唯一的 id，nextId 由全类共享，用于分配下一个 id
    private static int nextId = 1;
}

int id = Employee.nextId;
```

- 即使没有任何实例，静态字段也存在（属于类）

## 静态常量

用 `static final` 设置一个类常量，final 禁止修改：

```java
public class System {
    public static final PrintStream out = ...;
}
```

- `System.out` 就是静态常量的典型例子，可以直接用类名访问

## 静态方法

- 静态方法没有隐式参数，即没有 this，不能访问实例字段、不能调用实例方法
- 推荐使用类名调用静态方法，而不是通过对象调用

适合写成静态方法的两种情况：

- 方法不需要访问对象状态（所有参数都来自显式参数）
- 方法只需要访问类的静态字段

```java
public static int getNextId() {
    return nextId; // 只访问静态字段
}
```

## 工厂方法

- LocalDate、NumberFormat 这类类使用静态工厂方法代替构造器构造对象：

```java
NumberFormat currencyFormatter = NumberFormat.getCurrencyInstance();
LocalDate date = LocalDate.now();
```

静态工厂相比构造器的优势：

- 方法名可以表意，描述正在构造的对象
- 可以返回子类或缓存的共享实例，不受类本身的限制

## main 方法

- main 方法是静态的，不对任何对象进行操作
- 每一个类都可以有一个 main 方法，常用来对该类做单元测试：

```java
class Employee {
    // ...字段、构造器、方法

    // 类自带的自测入口，不影响正常使用
    public static void main(String[] args) {
        Employee e = new Employee("Harry", 50000);
        System.out.println(e.getName());
    }
}
```
