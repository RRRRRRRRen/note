# 自定义类与封装
*类型：knowledge ｜ 难度：入门 ｜ 标签：Java、类、封装、构造器、访问权限 ｜ 更新：2026-09-22*

**自定义类按「字段 -> 构造器 -> 方法」组织：实例字段用 private 保证封装，构造器与类同名无返回值；一个方法可以访问本类所有对象的私有数据（基于类的访问权限）；不要让访问器返回可变对象的引用。**

## 类的定义形式

```java
class ClassName {
    field1
    field2
    ...
    constructor1
    constructor2
    ...
    method1
    method2
}
```

- 一个源文件中只能有一个公共类，但可以有任意数目的非公共类
- 习惯将各个类放在单独的源文件中；javac 编译时会自动查找并编译引用的类

## 字段与封装

用 `private` 定义实例字段，确保只有类本身的方法能访问，其他类的方法不能读写：

```java
class Employee {
    private String name;
    private double salary;
}
```

封装的经典结构：私有实例字段 + 公共访问器方法（getter）+ 公共更改器方法（setter）：

```java
private String name;
private double salary;

public String getName() {
    return name;
}

public void setSalary(double s) {
    this.salary = s;
}
```

封装的优点：

- 内部实现可以自由改变，不影响外部调用者
- 更改器方法可以执行错误检查，而公共字段做不到

注意事项：

- 不要编写返回可变实例对象引用的访问器方法，确实需要时应先克隆再返回

## 构造器

```java
class Employee {
    private String name;
    private double salary;

    // 构造器：与类同名、无返回值、配合 new 调用
    public Employee(String n, double s) {
        name = n;
        salary = s;
    }
}
```

特征：

- 构造器与类同名
- 每个类可以有一个以上的构造器（重载）
- 构造器可以有任意个数的参数，没有返回值
- 构造器总是结合 `new` 操作符一起调用

注意事项：

- 在所有方法中都不要使用与实例字段同名的变量名（避免混淆）

## 隐式参数与显式参数

- 隐式参数：方法指向的实例对象，即 this，推荐显式使用 this 指明
- 显式参数：方法名后括号中的参数

```java
public void raiseSalary(double byPercent) {
    double raise = this.salary * byPercent / 100;
    this.salary += raise;
}
```

## 基于类的访问权限

一个类的方法可以访问**这个类的所有对象**的私有数据，但访问不了其他类的私有数据：

```java
class MyClass {
    private int data;

    public MyClass(int data) {
        this.data = data;
    }

    // 可以访问另一个 MyClass 对象的私有字段
    public void showOtherObjectData(MyClass other) {
        System.out.println("Other object's data: " + other.data);
    }
}
```

跨类访问私有字段则直接编译错误：

```java
class ClassA {
    private int dataA = 10;

    public void showDataB(ClassB objB) {
        System.out.println(objB.dataB); // 错误：无法访问 ClassB 的私有字段
    }
}
```

## 用 var 声明局部变量

Java 10 起局部变量可用 var，类型由右值推断（仅限局部变量，不能用于字段与参数）：

```java
Employee harry = new Employee("Harry Jack");
// 简化为
var harry = new Employee("Harry Jack");
```

## null 引用的处理

对 null 引用调用方法会产生 NullPointerException，构造器中可选两种容错策略：

宽容处理，为 null 时自动替换为默认值：

```java
this.name = Objects.requireNonNullElse(n, "unknown");
```

严格处理，为 null 时立刻抛出带明确信息的异常：

```java
this.name = Objects.requireNonNull(n, "The name cannot be null");
```

## 私有方法

实现私有方法只需将 public 改为 private，用于拆分内部逻辑，可随实现自由增删。

## final 实例字段

- 定义为 final 的实例字段必须在构造对象时初始化，之后不允许修改
- 适合存放一旦确定就不变的值
