# 使用预定义类
*类型：knowledge ｜ 难度：入门 ｜ 标签：Java、对象、引用、LocalDate、访问器 ｜ 更新：2026-09-22*

**对象变量是引用，必须先用 new 调用与类同名的构造器构造对象；方法分为只读的访问器方法和会修改对象状态的更改器方法；对象变量可显式置为 null 表示不引用任何对象。**

## 对象与对象变量

- 想使用对象必须先构造对象，并指定其初始状态
- 使用构造器（constructor）构造新实例，构造器与类同名：

```java
Date rightNow = new Date();
```

- 任何对象变量的值都是一个引用，指向存储在另一个地方的某个对象
- 可以显式将对象变量设置为 null，表示这个变量目前没有引用任何对象：

```java
Date deadline = null;
```

- 对 null 引用调用方法会抛 NullPointerException

## Java 类库中的 LocalDate 类

- 时间用距离一个固定时间点的偏移量表示，这个时间点称为纪元：UTC 时间 1970-01-01 00:00:00
- 类库设计者将「保存时间」与「给时间命名」分开：LocalDate 内部只保存距纪元的日期值，世纪、年月日等由类方法计算得出：

```java
LocalDate.now();                    // 当前日期
LocalDate.of(1999, 12, 31);         // 指定日期
newYearsEve.plusDays(1000);         // 推算 1000 天后的新日期，返回新对象
newYearsEve.getYear();              // 获取年份
```

## 更改器方法与访问器方法

- 访问器方法（accessor）：只访问对象而不修改对象，如 `getYear()`
- 更改器方法（mutator）：会修改对象状态，如 `plusDays` 的对应物 `addDays`
- 不可变类（如 LocalDate）只提供访问器方法，调用修改类的方法会返回新对象
