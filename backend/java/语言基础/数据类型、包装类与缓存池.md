# 数据类型、包装类与缓存池

*类型：knowledge ｜ 难度：入门 ｜ 标签：Java、数据类型、包装类、装箱拆箱、缓存池 ｜ 更新：2026-09-22*

**Java 有 8 种基本类型（4 整型、2 浮点、char、boolean），引用类型存的是对象地址；包装类是基本类型的对象封装，装箱走 valueOf，-128~127 范围内命中缓存池导致 `==` 恰好为 true，超出范围则是 false，比较一律用 equals。**

## 基本数据类型

### 整型

表示没有小数部分的数，可以是负数：

| 类型 | 占用空间 | 表数范围 | 默认值 | 注意 |
| --- | --- | --- | --- | --- |
| byte | 1 Byte | -2^7 ~ 2^7-1（-128 ~ 127） | 0 | |
| short | 2 Byte | -2^15 ~ 2^15-1 | 0 | |
| int | 4 Byte | -2^31 ~ 2^31-1 | 0 | 常用 |
| long | 8 Byte | -2^63 ~ 2^63-1 | 0L | 字面量需后缀 `L`：`long x = 123456789L;` |

各进制表示法：

- 十六进制：前缀 `0x` 或 `0X`，例如 `0xCAFE`
- 八进制：前缀 `0`，例如 `010`
- 二进制：前缀 `0b` 或 `0B`，例如 `0b1001`

数字加下划线方便阅读，编译器会忽略：`1_000_000`、`0b1111_0110_0010`。

### 浮点类型

表示有小数部分的数值：

| 类型 | 占用空间 | 表数范围 | 默认值 | 注意 |
| --- | --- | --- | --- | --- |
| float | 4 Byte | 约 -3.4E38 ~ 3.4E38 | 0.0f | 字面量需后缀 `F` / `f`：`float x = 123.23F;` |
| double | 8 Byte | 约 -1.8E308 ~ 1.8E308 | 0.0d | 不带后缀默认 double，可加后缀 `D` / `d` |

三种特殊浮点值：

```java
Double.POSITIVE_INFINITY  // 正无穷
Double.NEGATIVE_INFINITY  // 负无穷
Double.NaN                // 非数字
```

- 所有 `NaN` 彼此都不相等，判断要用 `Double.isNaN(x)`

### 字符类型

char 表示单个字符，占 2 Byte，字面量用单引号：`char c = 'A';`

六种赋值方式：

| 方式 | 示例 | 说明 |
| --- | --- | --- |
| 字符字面量 | `char c = 'A';` | 最常见，直接写一个字符，必须用单引号 |
| Unicode 转义符 | `char c = '\u4E2D';` | 用 Unicode 十六进制码点赋值（这里是「中」） |
| 整数（十进制） | `char c = 65;` | 直接赋整数，对应 Unicode 字符（65 = 'A'） |
| 整数（十六进制） | `char c = 0x41;` | 十六进制赋值（0x41 = 65 = 'A'） |
| 强制类型转换 | `char c = (char) 97;` | 将整数强转为 char（97 = 'a'） |
| 表达式运算结果 | `char c = 'A' + 1;` | 常量表达式结果在 char 范围内可自动转换（'B'） |

```java
char a = 'A';        // 字符
char b = '\u4E2D';   // Unicode：中
char c = 65;         // 整数表示 A
char d = 0x41;       // 十六进制表示 A
char e = (char) 97;  // 强制类型转换，97 = 'a'
char f = 'A' + 1;    // 表达式结果 = 'B'
```

转义序列：

| 转义序列 | 名称 |
| --- | --- |
| `\b` | 退格 |
| `\t` | 制表 |
| `\n` | 换行 |
| `\r` | 回车 |
| `\f` | 换页 |
| `\"` | 双引号 |
| `\'` | 单引号 |
| `\\` | 反斜杠 |
| `\s` | 空格 |

转义符词源：

- `\b` 退格：b 来源于 back（向后），将光标移到当前字符左边并覆盖原字符，源于早期键盘的退格键设计
- `\t` 制表：t 来源于 tabulation（制表），跳到下一个制表位用于文本对齐，是传统打印机和打字机的标准排版功能
- `\n` 换行：n 来源于 newline（新行），光标移动到下一行起始位置，在 Unix 类系统中作为行尾标志
- `\r` 回车：r 来源于 return（回车），将光标移回当前行开头，源于打字机把打印头退回行最左边的动作
- `\f` 换页：来源于 form feed（换页），行为取决于终端设置，支持分页的环境（打印机模拟器等）会把内容显示在不同的页上

各转义符的演示：

```java
public class ControlCharactersDemo {
    public static void main(String[] args) {
        // 退格（\b）：退格覆盖 "o"，显示 "HellWorld"
        System.out.println("Hello\bWorld");

        // 换行（\n）："Line 2" 输出到下一行
        System.out.println("Line 1\nLine 2");

        // 制表（\t）：两列之间插入一个制表符（水平跳动）
        System.out.println("Column1\tColumn2");

        // 回车（\r）：光标回到行首覆盖 "Hello"
        System.out.println("Hello\rWorld");

        // 换页（\f）：插入换页符，支持分页的环境会把 "Page 2" 显示在下一页
        System.out.println("Page 1\fPage 2");
    }
}
```

注意事项：

- char 可表示十六进制值 `\u0000` ~ `\uFFFF`；Unicode 转义 `\u` 会在解析代码之前执行，甚至可以在注释中使用
- 超出 65535 的字符（如 emoji）需要一对 char（代理对）表示，`length()` 返回 2
- 强烈不建议在程序中直接使用 char 类型，过于底层

代理对示例，emoji 的 Unicode 是 U+1F600（十进制 128512），超出 char 范围被拆成高低两个代理 char：

```java
public class CharBeyond65535 {
    public static void main(String[] args) {
        String emoji = "😀";

        System.out.println("长度： " + emoji.length());  // 2 个 char，因为是代理对

        char high = emoji.charAt(0);  // 高代理
        char low = emoji.charAt(1);   // 低代理
        System.out.printf("高位代理: 0x%04X\n", (int) high);  // D83D
        System.out.printf("低位代理: 0x%04X\n", (int) low);   // DE00

        // 正确获取完整码点的方式
        int codePoint = emoji.codePointAt(0);
        System.out.println("完整码点（十进制）: " + codePoint);        // 128512
        System.out.printf("完整码点（十六进制）: U+%04X\n", codePoint); // U+1F600
    }
}
```

回车与换行的区别：

- `\r`（回车）：光标回到当前行行首，不换行
- `\n`（换行）：光标移到下一行行首
- Windows 行结束符是 `\r\n`，Unix/Linux 与现代 macOS 是 `\n`

### 布尔类型

boolean 只有两个值 `true`、`false`，用于判定逻辑条件。

整型值和布尔值不能相互转换：

```java
if (0) { } // 编译报错：int 类型无法转换为 boolean 类型
```

## 引用数据类型

引用类型保存的是对象的引用（地址），不是实际的值：

| 类型 | 示例 |
| --- | --- |
| 类（Class） | `String name = "Tom";` |
| 接口（Interface） | `Runnable r = new Thread();` |
| 数组（Array） | `int[] arr = new int[3];` |
| 枚举（Enum） | `Day day = Day.MONDAY;` |
| 注解（Annotation) | `@Override` |

## 包装类与装箱拆箱

每种基本类型都有对应的包装类，位于 java.lang 包，属于引用类型：

| 基本类型 | 包装类 |
| --- | --- |
| byte | Byte |
| short | Short |
| int | Integer |
| long | Long |
| float | Float |
| double | Double |
| char | Character |
| boolean | Boolean |

为什么需要包装类：

- 集合类只能存对象（ArrayList 不能放 int，只能放 Integer）
- 需要使用类的方法（如 `Integer.parseInt()`）
- 泛型参数不能是基本类型
- 包装类可以为 null

自动装箱与拆箱，编译器自动调用 valueOf / intValue：

```java
Integer obj = 10;  // 自动装箱，等价于 Integer.valueOf(10)
int b = obj;       // 自动拆箱，等价于 obj.intValue()

List<Integer> nums = new ArrayList<>();
nums.add(1);          // 自动装箱
int x = nums.get(0);  // 自动拆箱
```

拆箱陷阱：包装类为 null 时拆箱抛 NullPointerException：

```java
Integer a = null;
int b = a; // 运行时 NullPointerException
```

## 缓存池

Java 为避免频繁创建包装类对象，对一定范围内的值复用同一个缓存对象：

| 包装类 | 缓存范围 | 是否可配置 |
| --- | --- | --- |
| Boolean | true / false | 固定 |
| Byte | -128 ~ 127 | 固定 |
| Short | -128 ~ 127 | 固定 |
| Integer | -128 ~ 127 | 可通过 JVM 参数调上限，下限固定 |
| Long | -128 ~ 127 | 固定 |
| Character | 0 ~ 127 | 固定 |
| Float | 无缓存 | 不支持 |
| Double | 无缓存 | 不支持 |

原理：自动装箱时调用 valueOf，命中缓存直接返回，否则新建对象：

```java
public static Integer valueOf(int i) {
    if (i >= -128 && i <= 127) {
        return IntegerCache.cache[i + 128]; // 返回缓存对象
    }
    return new Integer(i); // 超出范围，创建新对象
}
```

缓存池导致的比较陷阱：

```java
Integer a = 100;
Integer b = 100;
System.out.println(a == b); // true：落在缓存范围内，是同一个对象

Integer x = 1000;
Integer y = 1000;
System.out.println(x == y); // false：超出范围，各自新建对象
```

结论：包装类比较值一律用 `equals()`，不要用 `==`：

```java
Integer a = 200;
Integer b = 200;
System.out.println(a.equals(b)); // true
```
