# 数据类型、包装类与缓存池
*类型：knowledge ｜ 难度：入门 ｜ 标签：Java、数据类型、包装类、装箱拆箱、缓存池 ｜ 更新：2026-09-22*

**Java 有 8 种基本类型（4 整型、2 浮点、char、boolean），引用类型存的是对象地址；包装类是基本类型的对象封装，装箱走 valueOf，-128~127 范围内命中缓存池导致 `==` 恰好为 true，超出范围则是 false，比较一律用 equals。**

## 基本数据类型

### 整型

表示没有小数部分的数，可以是负数：

| 类型 | 占用空间 | 表数范围 | 默认值 | 注意 |
| --- | --- | --- | --- | --- |
| byte | 1 Byte | -2^7 ~ 2^7-1（-128 ~ 127） | 0 | |
| short | 2 Byte | -2^15 ~ 2^15-1 | 0 | |
| int | 4 Byte | -2^31 ~ 2^31-1 | 0 | 常用 |
| long | 8 Byte | -2^63 ~ 2^63-1 | 0L | 字面量需后缀 `L`：`long x = 123456789L;` |

各进制表示法：

- 十六进制：前缀 `0x` 或 `0X`，例如 `0xCAFE`
- 八进制：前缀 `0`，例如 `010`
- 二进制：前缀 `0b` 或 `0B`，例如 `0b1001`

数字加下划线方便阅读，编译器会忽略：`1_000_000`、`0b1111_0110_0010`。

### 浮点类型

表示有小数部分的数值：

| 类型 | 占用空间 | 表数范围 | 默认值 | 注意 |
| --- | --- | --- | --- | --- |
| float | 4 Byte | 约 -3.4E38 ~ 3.4E38 | 0.0f | 字面量需后缀 `F` / `f`：`float x = 123.23F;` |
| double | 8 Byte | 约 -1.8E308 ~ 1.8E308 | 0.0d | 不带后缀默认 double，可加后缀 `D` / `d` |

三种特殊浮点值：

```java
Double.POSITIVE_INFINITY  // 正无穷
Double.NEGATIVE_INFINITY  // 负无穷
Double.NaN                // 非数字
```

- 所有 `NaN` 彼此都不相等，判断要用 `Double.isNaN(x)`

### 字符类型

char 表示单个字符，占 2 Byte，字面量用单引号：`char c = 'A';`

转义序列：

| 转义序列 | 名称 |
| --- | --- |
| `\b` | 退格 |
| `\t` | 制表 |
| `\n` | 换行 |
| `\r` | 回车 |
| `\f` | 换页 |
| `\"` | 双引号 |
| `\'` | 单引号 |
| `\\` | 反斜杠 |
| `\s` | 空格 |

注意事项：

- char 可表示十六进制值 `\u0000` ~ `\uFFFF`；Unicode 转义 `\u` 会在解析代码之前执行，甚至可以在注释中使用
- 超出 65535 的字符（如 emoji）需要一对 char（代理对）表示，`length()` 返回 2
- 强烈不建议在程序中直接使用 char 类型，过于底层

回车与换行的区别：

- `\r`（回车）：光标回到当前行行首，不换行
- `\n`（换行）：光标移到下一行行首
- Windows 行结束符是 `\r\n`，Unix/Linux 与现代 macOS 是 `\n`

### 布尔类型

boolean 只有两个值 `true`、`false`，用于判定逻辑条件。

整型值和布尔值不能相互转换：

```java
if (0) { } // 编译报错：int 类型无法转换为 boolean 类型
```

## 引用数据类型

引用类型保存的是对象的引用（地址），不是实际的值：

| 类型 | 示例 |
| --- | --- |
| 类（Class） | `String name = "Tom";` |
| 接口（Interface） | `Runnable r = new Thread();` |
| 数组（Array） | `int[] arr = new int[3];` |
| 枚举（Enum） | `Day day = Day.MONDAY;` |
| 注解（Annotation) | `@Override` |

## 包装类与装箱拆箱

每种基本类型都有对应的包装类，位于 java.lang 包，属于引用类型：

| 基本类型 | 包装类 |
| --- | --- |
| byte | Byte |
| short | Short |
| int | Integer |
| long | Long |
| float | Float |
| double | Double |
| char | Character |
| boolean | Boolean |

为什么需要包装类：

- 集合类只能存对象（ArrayList 不能放 int，只能放 Integer）
- 需要使用类的方法（如 `Integer.parseInt()`）
- 泛型参数不能是基本类型
- 包装类可以为 null

自动装箱与拆箱，编译器自动调用 valueOf / intValue：

```java
Integer obj = 10;  // 自动装箱，等价于 Integer.valueOf(10)
int b = obj;       // 自动拆箱，等价于 obj.intValue()

List<Integer> nums = new ArrayList<>();
nums.add(1);          // 自动装箱
int x = nums.get(0);  // 自动拆箱
```

拆箱陷阱：包装类为 null 时拆箱抛 NullPointerException：

```java
Integer a = null;
int b = a; // 运行时 NullPointerException
```

## 缓存池

Java 为避免频繁创建包装类对象，对一定范围内的值复用同一个缓存对象：

| 包装类 | 缓存范围 | 是否可配置 |
| --- | --- | --- |
| Boolean | true / false | 固定 |
| Byte | -128 ~ 127 | 固定 |
| Short | -128 ~ 127 | 固定 |
| Integer | -128 ~ 127 | 可通过 JVM 参数调上限，下限固定 |
| Long | -128 ~ 127 | 固定 |
| Character | 0 ~ 127 | 固定 |
| Float | 无缓存 | 不支持 |
| Double | 无缓存 | 不支持 |

原理：自动装箱时调用 valueOf，命中缓存直接返回，否则新建对象：

```java
public static Integer valueOf(int i) {
    if (i >= -128 && i <= 127) {
        return IntegerCache.cache[i + 128]; // 返回缓存对象
    }
    return new Integer(i); // 超出范围，创建新对象
}
```

缓存池导致的比较陷阱：

```java
Integer a = 100;
Integer b = 100;
System.out.println(a == b); // true：落在缓存范围内，是同一个对象

Integer x = 1000;
Integer y = 1000;
System.out.println(x == y); // false：超出范围，各自新建对象
```

结论：包装类比较值一律用 `equals()`，不要用 `==`：

```java
Integer a = 200;
Integer b = 200;
System.out.println(a.equals(b)); // true
```
