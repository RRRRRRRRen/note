# 运算符与类型转换
*类型：knowledge ｜ 难度：入门 ｜ 标签：Java、运算符、类型转换、位运算 ｜ 更新：2026-09-22*

**算术运算遵循整数除法与浮点除法的区分；数值类型转换分自动（小转大）与强制（大转小，可能丢精度）；复合赋值运算符自带隐式强制转换；位运算中 `&` `|` 不短路，`>>>` 是无符号右移。**

## 算术运算符

| 运算符 | 运算 | 注意 |
| --- | --- | --- |
| `+` `-` `*` | 加减乘 | |
| `/` | 除 | 两个操作数都是整数才用整数除法返回整数；否则浮点除法。浮点除法可以除 0，整数除法不可以 |
| `%` | 取余 | `7 % 5` 结果为 2 |
| `++` `--` | 自增自减 | 前缀先运算后取值，后缀先取值后运算，不导致类型变化 |
| `+` | 字符串连接 | `"Hel" + "lo"` 得 `"Hello"` |

自增示例：

```java
int a = 2, b;
b = ++a; // 先自增再取值：a=3, b=3
b = a++; // 先取值再自增：a=3, b=2
```

## 数学函数与常量

```java
double x = 4;
double y = Math.sqrt(x);  // 求平方根
double z = Math.pow(x, 2); // 幂运算
```

- `import static java.lang.Math.*;` 后可不加 `Math` 前缀直接使用
- `Math` 用浮点运算，不同平台结果可能不同；需要跨平台确定值用 `StrictMath`
- 普通整数运算溢出不报错，可用 `Math.addExact` 等方法捕获溢出错误

## 关系、逻辑与条件运算符

- 相等 `==`、不等 `!=`、逻辑非 `!`
- 比较：`>`、`<`、`<=`、`>=`
- `&&`、`||` 按短路方式求值；位运算的 `&`、`|` 用于布尔值时不短路
- 条件运算符：`x < y ? x : y`，条件必须为 boolean 类型

## 位运算符

| 符号 | 名称 | 备注 |
| --- | --- | --- |
| `<<` | 左移 | |
| `>>` | 右移 | 符号位跟随 |
| `>>>` | 无符号右移 | 高位补 0 |
| `&` | 与 | 不会短路 |
| `\|` | 或 | 不会短路 |
| `^` | 异或 | |
| `~` | 取反 | |

## 赋值

```java
x += 4; // 等价于 x = x + 4;
```

- 赋值也是表达式，有返回值，返回所赋的值
- 复合赋值运算符会自动进行隐式强制转换：

```java
byte b = 50;
b *= 2;               // 编译通过
// 等价于 b = (byte)(b * 2);
```

## 自动类型转换

容量小的与容量大的运算时，自动转换为容量大的类型（容量指数据范围而非内存占用）：

```text
byte → short → int → long → float → double
                ↑
          char（char → int）
```

二元运算中的提升规则：有 double 按 double，否则有 float 按 float，否则有 long 按 long，否则一律按 int。

特殊情况：

- byte、short 之间相互运算的结果要用 int 接收
- char、byte、short 混合运算也要用 int 接收
- boolean 不能与其他基本类型运算

典型示例：

```java
long x = 123;    // 自动提升：int → long
long y = 123123123123123; // 编译报错：字面量超出 int 范围，需加 L

float f = 12.3;  // 编译报错：double 字面量不能自动转 float，需 12.3F

byte b = 10;
int r = b + 1;        // 整型与常量运算，结果必须 int 接收
double d = b + 12.3;  // 浮点与常量运算，结果必须 double 接收
```

常量表达式的编译期转换：常量表达式在编译期计算，结果落在目标类型范围内时允许直接赋值：

```java
byte a = 50;       // 合法：50 在 byte 范围内
byte b2 = 50 + 30; // 合法：常量表达式结果 80 在 byte 范围内
byte c = 128;      // 编译错误：128 超出 byte 范围
char e = 'A' + 1;  // 合法：结果 66 在 char 范围内
```

## 强制类型转换

语法：`(targetType) expression`，用于大范围转小范围：

```java
double x = 12.9;
int y = (int) x; // 12：截断小数部分，不是四舍五入
```

需要舍入用 `Math.round`，它返回 long：

```java
double x = 9.993;
int nx = (int) Math.round(x); // 10
```

风险：

- 值超出目标类型范围时发生溢出（如 int 转 byte 变为意外负数）
- 浮点转整数丢失全部小数部分
- 对象强转类型不兼容会抛 ClassCastException：

```java
Object obj = new Integer(100);
String str = (String) obj; // 运行时 ClassCastException
```

## 运算符优先级

- 同一级别的运算符按从左到右的次序计算
- 例外是右结合运算符，如 `+=`
- 不确定时用括号明确优先级
