# 控制流程
*类型：knowledge ｜ 难度：入门 ｜ 标签：Java、if、switch、循环、break、continue ｜ 更新：2026-09-22*

**块决定作用域，嵌套块中不能声明同名变量；switch 的 case 支持 char/byte/short/int、枚举与字符串，箭头 `->` 形式无直通行为；break 退出循环（带标签可跳多层），continue 跳过本轮剩余部分。**

## 块作用域

- 块（由一对大括号括起来）确定了变量的作用域
- 不能在嵌套的两个块中声明同名变量

## 条件语句

条件必须用小括号括起来，推荐始终使用大括号：

```java
int a = 12;
int b = 13;
if (a > b) {
    System.out.println(a);
} else {
    System.out.println(b);
}
```

- else 子句与最邻近的 if 构成一组
- 可反复使用 `if ... else if ...` 链

## while 与 do while

while 先判断条件，为 true 时执行循环体：

```java
while (balance < goal) {
    balance += payment;
    double interest = balance * interestRate / 100;
    balance += interest;
    years++;
}
```

do while 先执行一次循环体再判断，循环体至少执行一次：

```java
do {
    balance += payment;
    years++;
} while (balance < goal);
```

## for 循环

三部分：计数器初始化、每轮循环前检测的条件、更新计数器：

```java
for (int i = 10; i > 0; i--) {
    // ...
}
```

- for 第一部分声明的变量作用域只延伸到 for 循环末尾
- 循环体内部定义的变量只能在循环体中使用

## switch 语句

case 标签可以是：char、byte、short、int 的常量表达式、枚举常量、字符串字面量，多个字符串用逗号分隔。

直通（fall through）形式：case 以冒号 `:` 结束，从匹配项开始一直执行到 break 或 switch 结束：

```java
int day = 2;
switch (day) {
    case 1:
        System.out.println("Monday");
        // 没有 break，直通到下一个 case
    case 2:
        System.out.println("Tuesday");
    case 3:
        System.out.println("Wednesday");
        break;
    default:
        System.out.println("Another day");
}
```

无直通形式：case 以箭头 `->` 结束，只执行匹配分支。

switch 表达式：switch 可以作为表达式生成一个值；块形式用 `yield` 终止并给出值：

```java
String season = switch (x) {
    case 0 -> "A";
    case 1 -> "B";
    default -> "C";
};
```

特性：

- 没有匹配的 case 时执行 default 子句（如果有）
- 使用整数或 String 操作数的 switch 表达式必须有 default，因为表达式必须生成一个值
- 使用枚举常量时不需要为标签提供枚举名，default 非必须

## break 与 continue

不带标签的 break 退出当前循环：

```java
while (year <= 100) {
    balance += payment;
    if (balance >= goal) break;
    year++;
}
```

带标签的 break 跳出指定标签的循环，可用于跳出多层嵌套：

```java
outerLoop: // 定义外层循环标签
for (int i = 0; i < 5; i++) {
    for (int j = 0; j < 5; j++) {
        if (j == 3) {
            break outerLoop; // j 为 3 时直接终止外层循环
        }
        System.out.println("i = " + i + ", j = " + j);
    }
}
```

continue 越过本轮循环体的剩余部分，直接跳到循环首部进入下一轮：

```java
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue; // 跳过 3，继续下一轮
    }
    System.out.println(i);
}
```
