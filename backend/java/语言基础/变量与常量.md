# 变量与常量
*类型：knowledge ｜ 难度：入门 ｜ 标签：Java、变量、常量、final、enum ｜ 更新：2026-09-22*

**变量先声明类型再声明名字，必须显式初始化后才能使用；常量用 final 修饰、只能赋值一次、习惯全大写；枚举把变量取值限定在一组命名常量内。**

## 声明变量

语法：先指定变量类型，再指定变量名：

```java
double x;
```

变量名的要求：

- 由字母、数字、货币符号、标点连接符组成，一般只用 `a~Z`、`0~9`、`_`
- 区分大小写
- 不能使用 Java 关键字

可以一行声明多个变量，但不推荐：

```java
int i, j;
```

## 初始化变量

- 声明后必须用赋值语句显式初始化，使用未初始化的变量会编译报错

```java
int a;
a = 12;
```

声明的同时直接初始化：

```java
int a = 12;
```

类型推断初始化：能从右值直接推断类型时可用 `var`（Java 10+）：

```java
var x = 12;       // int
var y = 12.3;     // double
var name = "ren"; // String
```

## 常量

用关键字 `final` 修饰，表示这个变量只能赋值一次：

```java
final double CM_PER_INCH = 2.54;
```

- 习惯上常量名使用全大写
- 类常量使用 `static final`，属于类而不属于单个对象：

```java
public static final double CM_PER_INCH = 2.54;
```

## 枚举类型

```java
enum Size { SMALL, MEDIUM };
Size s = Size.SMALL;
```

- 枚举变量的取值只能是声明中列出的值，或者 `null`
