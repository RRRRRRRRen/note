# 大数

*类型：knowledge ｜ 难度：入门 ｜ 标签：Java、BigInteger、BigDecimal ｜ 更新：2026-09-22*

**基本类型范围不够用时用大数：BigInteger 表示任意精度整数，BigDecimal 表示任意精度浮点数；大数不能用算术运算符计算，只能调用 add、multiply 等方法；BigDecimal 必须用字符串构造。**

## 构造大数

值在常规范围内用静态方法 `valueOf` 转换：

```java
BigInteger a = BigInteger.valueOf(100);
```

超长数字用字符串构造：

```java
BigInteger big = new BigInteger("2020200202020202020202002020202020");
```

BigDecimal 总是应当使用字符串参数构造，避免 double 字面量先引入误差：

```java
BigDecimal d = new BigDecimal("0.1");
```

## 计算

- 大数不能使用 `+`、`-`、`*` 等算术运算符，需要使用提供的方法
- 方法都不改变原对象，运算结果是新对象：

```java
BigInteger a = BigInteger.valueOf(100);
BigInteger b = a.add(a);         // 200，加法
BigInteger c = a.multiply(a);    // 10000，乘法
BigInteger d = a.subtract(BigInteger.valueOf(30)); // 70，减法
```

- BigDecimal 同理使用 add / subtract / multiply / divide
