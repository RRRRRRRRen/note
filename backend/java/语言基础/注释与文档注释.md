# 注释与文档注释
*类型：knowledge ｜ 难度：入门 ｜ 标签：Java、注释、javadoc ｜ 更新：2026-09-22*

**Java 有三种注释：`//` 单行、`/* */` 多行（不能嵌套）、`/** */` 文档注释；只有文档注释能被 javadoc 抽取生成 HTML API 文档，且只为 public 和 protected 成员生成。**

## 三种注释

| 类型 | 写法 | 用途 |
| --- | --- | --- |
| 单行注释 | `//` | 对某一行代码做简单说明 |
| 多行注释 | `/* ... */` | 大段说明、临时屏蔽代码块 |
| 文档注释 | `/** ... */` | 配合 javadoc 自动生成 API 文档 |

单行注释，从 `//` 开始到本行结束：

```java
int age = 18; // 定义年龄变量
```

多行注释，用 `/*` 与 `*/` 把一段较长的注释括起来，不能嵌套：

```java
/*
  以下是用户信息变量定义
  包括姓名、年龄、邮箱等
*/
String name = "张三";
```

文档注释，专用于类、接口、方法、字段的说明：

```java
/**
 * 这个类演示了文档注释
 * @author Ayan Amhed
 * @version 1.2
 */
public class DocDemo {
}
```

## javadoc 生成文档

- javadoc 只为 public 和 protected 修饰的字段、方法、类生成文档
- 文档注释中可嵌入 HTML 标记（如 `<p>`、`<a>`），但不要用标题标记（如 `<h1>`），javadoc 会插入自己的标题，容易冲突
- 常用标签：

| 标签 | 作用 |
| --- | --- |
| `@param` | 方法参数说明 |
| `@return` | 返回值说明 |
| `@throws` | 可能抛出的异常 |
| `@author` | 作者 |
| `@version` | 版本号 |
| `@see` | 引用相关类或方法 |
| `@deprecated` | 标记已过时 |
| `@since` | 自哪个版本开始支持 |

方法注释示例：

```java
/**
 * 方法描述：计算两个整数的和。
 *
 * @param a 第一个整数
 * @param b 第二个整数
 * @return 两个整数的和
 */
public int add(int a, int b) {
    return a + b;
}
```

命令行生成 HTML 文档，输出到 docs 目录，浏览器打开 index.html 查看：

```bash
javadoc -d ./docs User.java
```

- 也可以在 IDEA 中 Tools -> Generate JavaDoc 自动生成

## 注释约定

- 类、字段、方法必须使用文档注释，IDE 悬浮提示可提高编码效率
- 抽象方法和接口必须用文档注释，说明方法做什么、实现什么功能
- 所有的类添加创建者和创建日期，枚举字段用文档注释说明每个数据项的用途
- 代码修改的同时，注释要同步修改
