# 输入与输出
*类型：knowledge ｜ 难度：入门 ｜ 标签：Java、Scanner、printf、文件 IO ｜ 更新：2026-09-22*

**读取输入用 Scanner 包装 System.in；格式化输出用 printf（遵循格式化语法）；文件输入用 Scanner + Path.of 并显式指定字符集，文件输出用 PrintWriter。**

## 读取输入

```java
Scanner scan = new Scanner(System.in);
String str = scan.nextLine(); // 读一行字符串
int number = scan.nextInt();  // 读一个整数
```

- Scanner 的每个读取方法都会阻塞等待用户输入

## 格式化输出

printf 遵循格式化语法，占位符按顺序对应参数：

```java
int age = 19;
String name = "AAA";
System.out.printf("Hello %s, Next year, you'll be %d", name, age);
// Hello AAA, Next year, you'll be 19
```

- `%s` 字符串、`%d` 整数、`%f` 浮点数，可加宽度与精度控制如 `%8.2f`

## 文件输入与输出

文件输入，显式指定字符集：

```java
Scanner in = new Scanner(Path.of("myFile.txt"), StandardCharsets.UTF_8);
```

文件输出：

```java
PrintWriter out = new PrintWriter("myFile.txt", StandardCharsets.UTF_8);
```

注意事项：

- 生成文件的相对位置取决于虚拟机、shell 运行所在目录或 IDE 的控制
- 推荐使用绝对路径名
- Windows 路径中每个反斜线之前需要再加一个反斜线转义
