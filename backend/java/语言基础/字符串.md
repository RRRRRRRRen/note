# 字符串

*类型：knowledge ｜ 难度：入门 ｜ 标签：Java、String、StringBuilder、文本块 ｜ 更新：2026-09-22*

**String 对象不可变，比较内容必须用 equals 而不是 ==；拼接频繁时用 StringBuilder（单线程）；字符串按 UTF-16 编码，length 返回代码单元数而非码点数；JDK 15 起支持文本块。**

## 子串与拼接

提取子串，参数为起始下标（含）与结束下标（不含）：

```java
String greeting = "Hello";
String s = greeting.substring(0, 3); // "Hel"
```

使用 `+` 拼接，字符串与非字符串拼接时后者会自动转成字符串：

```java
String s1 = "Hello ";
String s2 = "world";
String msg = s1 + s2; // "Hello world"
```

使用分隔符拼接：

```java
String all = String.join(" / ", "aa", "bb"); // "aa / bb"
```

## 不可变性

- String 类的对象不可变，修改字符串实际是先提取再拼接生成新对象：

```java
String greeting = "hello";
greeting = greeting.substring(0, 3) + "p"; // "help"，指向了新的 String 对象
```

- 不可变的优点：编译器可让字符串共享，也保证了 hashCode 的稳定性

## 检测相等

内容比较用 equals；== 比较的是引用位置，字符串可能共享，结果不可靠：

```java
String a = "hello";
a.equals("hello");              // true
a.equalsIgnoreCase("Hello");    // true，不区分大小写
```

## 空串与 null

检测空串与检测 null 是两件事，通常一起判断：

```java
if (str != null && str.length() != 0) { }
// 或
if (str != null && !str.equals("")) { }
```

## 码点与代码单元

- Java 字符串是 char 值序列，char 是 UTF-16 编码表示 Unicode 码点的一个代码单元
- 常用字符占 1 个代码单元，辅助字符（如 emoji）占 2 个（代理对）
- `length()` 返回代码单元个数，`codePointCount()` 返回码点个数：

```java
String s = "😊";
s.length();                  // 2：两个代码单元
s.codePointCount(0, s.length()); // 1：一个码点
```

按代码单元访问 charAt，代理对会被拆开得到无意义的 char：

```java
String string = "A😊A";
string.charAt(0); // 'A'
string.charAt(1); // ？：高位代理，无意义
string.charAt(3); // 'A'
```

按码点访问，先求码点所在下标再取码点值：

```java
String string = "A😊A";
int index = string.offsetByCodePoints(0, 1); // 1
int cp = string.codePointAt(index);          // 128522
```

遍历所有码点或由码点数组构建字符串：

```java
int[] codePoints = string.codePoints().toArray(); // [65, 128522, 65]
String str = new String(codePoints, 0, codePoints.length); // "A😊A"
```

## 构建字符串

频繁拼接时用 StringBuilder 避免产生大量中间对象；单线程用 StringBuilder，多线程用 StringBuffer：

```java
StringBuilder builder = new StringBuilder();
builder.append('A');
builder.append("BBC");
String str = builder.toString(); // "ABBC"
```

## 文本块

JDK 15 支持多行字符串：

```java
String str = """
    Hello
    World
    """;
```

- 以 `"""` 开头后跟换行符，以 `"""` 结尾
- 行尾 `\` 会拼接下一行
- 行结束符标准化为 `\n`
- 自动去除公共缩进
