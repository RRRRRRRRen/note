# 继承

**继承通过 extends 扩展已有类：子类复用父类的字段与方法并可新增或覆盖；多态让同一个方法调用在运行期动态绑定到实际类型的实现；super 调用父类构造器必须是子类构造器的第一条语句；子类方法访问权限不能低于父类。**

## 基本语法

用 `extends` 声明继承，Java 只支持单继承：

```java
public class Manager extends Employee {
    private double bonus;

    public double getSalary() {
        // super 调用父类方法，不能直接写 getSalary() 会变成递归
        return super.getSalary() + bonus;
    }
}
```

- 父类（超类）：被扩展的类；子类：扩展出来的类
- 子类可以新增字段和方法，也可以覆盖（override）父类方法
- Java 中所有类都直接或间接继承 Object

## 覆盖与 super

- 覆盖要求方法签名相同；子类方法的访问权限不能低于父类
- `super.method()` 调用父类的实现，用于在扩展逻辑中复用原行为

## 子类构造器

- `super(...)` 调用父类构造器必须是子类构造器的第一条语句
- 不显式调用时编译器自动插入 `super()`（父类需有无参构造器）：

```java
public Manager(String name, double salary, double bonus) {
    super(name, salary); // 先构造父类部分
    this.bonus = bonus;
}
```

## 多态与动态绑定

- 父类引用可以指向子类对象：`Employee e = new Manager(...);`
- 调用被覆盖的方法时，JVM 按对象实际类型在运行期选择实现（动态绑定）
- 不能通过父类引用调用子类独有的方法，需要时先做类型检查再强制转换：

```java
if (e instanceof Manager m) {
    m.setBonus(1000); // 转换后才能调用子类方法
}
```

## final 与继承

- `final class` 禁止被继承，`final method` 禁止被子类覆盖
- 好的设计：只把真正的通用行为放进继承树，避免为复用几行代码而深挖继承层次
