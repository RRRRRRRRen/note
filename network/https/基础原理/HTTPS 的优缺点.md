# HTTPS 的优缺点

*类型：knowledge ｜ 难度：入门 ｜ 标签：HTTPS、安全、性能、SSL 证书*

**HTTPS 用安全换成本：优点是身份认证、加密传输、大幅抬高中间人攻击门槛；缺点是加解密消耗服务器资源、握手增加加载耗时、证书要花钱且一张证书绑定一个 IP。HTTP 明文裸奔的风险——窃听、篡改、劫持——在 HTTPS 下全部被堵住。**

## 优点

- 身份认证，确保数据发送到正确的服务器
- 加密传输，防止数据被篡改或窃取
- 大幅增加中间人攻击成本

## 缺点

- 加解密过程消耗更多服务器资源
- 握手阶段耗时，增加页面加载时间
- SSL 证书需要付费，功能越强费用越高
- SSL 证书需绑定 IP，同一 IP 不能绑定多个域名

## 权衡一览

| 维度 | HTTP | HTTPS |
| --- | --- | --- |
| 数据传输 | 明文 | TLS 加密 |
| 身份验证 | 无 | 证书认证 |
| 连接建立 | TCP 握手 1 次 | TCP 握手 + TLS 握手 |
| 服务器开销 | 低 | 加解密消耗 CPU |
| 额外成本 | 无 | 证书费用与运维 |
